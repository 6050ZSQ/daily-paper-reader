## 摘要
语义记忆检索可以被概念化为在概念空间中的导航。我们通过使用言语流畅性数据，比较了人类与三种大型语言模型（GPT-4o、Gemini-2.5-Pro、Claude-Sonnet-4.5）之间的语义搜索动态。通过将基于轨迹的自然语言处理指标应用于82名人类参与者生成的条目以及八个温度设置下的LLM输出，我们量化了三个互补维度：熵（步长可预测性）、到下一个的距离（连续语义步长）以及到质心的距离（全局分散度）。人类在所有LLM中表现出更高的熵、更大的语义步长和更宽的分散度，表明搜索更具变异性和探索性。温度调控仅产生部分对齐，因为个体指标在特定设置下与人类匹配，但没有任何配置能再现完整的人类特征（在所有维度上）。这些发现表明，人类语义搜索实现了局部利用与全局探索之间的独特平衡，而当前的模型架构无法再现这种平衡。

## Abstract
Semantic memory retrieval can be conceptualized as navigation through conceptual space. We compared semantic search dynamics between humans and three large language models (GPT-4o, Gemini-2.5-Pro, Claude-Sonnet-4.5) using verbal fluency data. By applying trajectory-based NLP metrics to the items generated by 82 human participants and LLM output across eight temperature settings, we quantified three complementary dimensions: entropy (step size predictability), distance to next (successive semantic steps), and distance to centroid (global dispersion). Humans exhibited higher entropy, larger semantic steps and broader dispersion than all LLMs, indicating more variable and exploratory search. Temperature tuning produced only partial alignments, as individual metrics matched between humans and LLMs at specific settings, but no configuration reproduced the complete human profile (in all dimensions). These findings suggest that human semantic search implements a distinctive balance between local exploitation and global exploration that current model architectures fail to reproduce.

## 2. 论文提出的方法论

### 核心思想
- 将每个流畅性任务中的响应序列视为一条**语义轨迹**，使用**累积上下文嵌入**（cumulative embedding）表示每一步的语义状态，以模拟人类工作记忆的累积效应。
- 基于嵌入向量定义三个互补的轨迹指标，分别刻画**局部跳跃幅度**、**步长可预测性**和**全局分散程度**。

### 关键技术细节
1. **嵌入模型**：使用OpenAI `text-embedding-3-large` 将每个项目（单词或短语）映射为高维向量。同时用其他嵌入系统（商业和开源）验证鲁棒性。
2. **累积嵌入**：在第 \(t\) 步，将第1到第 \(t\) 个项目的本文连接后编码，得到向量 \(x_t\)，代表截至当前步的累积语义状态。
3. **三个指标**（来源：Toro-Hernández et al., 2026）：
   - **Distance to Next（语义步长）**：计算相邻累积嵌入 \(x_t\) 与 \(x_{t+1}\) 的余弦距离，取所有步长的平均值。值越大表示语义跳跃越大。
   - **Entropy（步长熵）**：将每个步长二值化（高于/低于该轨迹中位数），得到二进制序列，计算其归一化Shannon熵，反映步长大小的可预测性。熵越高表示步长模式越不可预测。
   - **Distance to Centroid（全局分散度）**：使用**非累积嵌入**，计算每个唯一项目的嵌入与所有项目平均嵌入（质心）的余弦距离，取均值。值越大表示响应在语义空间中越分散。
4. **统计分析**：使用广义线性混合模型（GLMM）比较人类与各LLM（不同温度）之间的指标差异，以参与者/试验ID为随机效应，采用Tukey事后检验校正多重比较。

### 算法流程（文字说明）
- 输入：人类或LLM生成的动物名称序列。
- 对每个序列：
  - 生成每一步的累积嵌入 → 计算连续的余弦距离 → 得到步长序列 → 计算平均步长和步长熵。
  - 对所有唯一项目计算非累积嵌入 → 计算质心 → 计算每个项目到质心的距离 → 取均值。
- 输出：三个指标值。
- 对不同组进行GLMM对比，报告差异和p值。

## 6. 论文的主要结论与发现

1. **人类 vs. LLM整体差异**：人类在**熵、语义步长、全局分散度**三个指标上均显著高于所有LLM（所有p<0.01）。表明人类搜索更具探索性和不可预测性，而LLM更偏向局部、高概率的延续。
2. **LLM之间的差异**：
   - Claude-sonnet-4.5：局部步长最小（最“粘滞”），全局分散中等。
   - GPT-4o：全局分散最小（最聚焦于质心），步长居中。
   - Gemini-2.5-pro：处于中间位置，但整体仍显著低于人类。
3. **温度调控效果有限**：
   - 某些温度能使LLM在**单个指标**上接近人类水平（如Claude在T=0.75/0.90时熵和步长匹配；Gemini在T=0/0.60等匹配步长；GPT-4o在T=0/0.45/0.60匹配步长）。
   - 但**没有温度设置能同时匹配所有三个指标**，尤其是GPT-4o在任何温度下全局分散度均显著低于人类。
   - 温度对全局分散度影响很小，说明LLM的语义广度受深层架构限制。
4. **对LLM作为认知模型的质疑**：当前LLM（尤其是经过RLHF微调的）无法复现人类语义搜索的完整特征，将其视为“硅基参与者”需谨慎。
5. **对人类语义搜索的启示**：人类在局部利用与全局探索之间实现了独特平衡，高熵和大步长符合Lévy游走模型，且可能依赖工作记忆监控和战略切换。

## 7. 优点

1. **方法创新**：使用**累积嵌入**模拟工作记忆累积效应，比传统逐词距离更能反映动态搜索过程。
2. **多维度量化**：同时覆盖局部跳跃、全局分散和步长可预测性，提供比单一指标更全面的视图。
3. **系统比较**：涵盖三种先进LLM，并系统变化温度参数，揭示架构特异性行为。
4. **统计严谨**：使用GLMM和多重比较校正，控制了个体差异和多次比较风险。
5. **鲁棒性验证**：采用多种嵌入系统（含开源）复现结果，减少对单一嵌入模型的依赖。
6. **实验控制**：通过角色扮演提示和长度匹配，减少了LLM输出中常见的列表化倾向和长度差异。

## 8. 不足与局限

1. **类别单一**：仅使用动物类别，不同类别（如水果、国家）可能因内部结构（层次性、密度）不同而得出不同结论。
2. **嵌入偏差**：使用的嵌入模型可能不完全反映人类语义结构，尤其是跨领域或抽象概念。
3. **LLM闭源性**：无法访问模型内部表示和训练细节，温度参数对生成的具体影响机制不透明，限制了对差异来源的解释。
4. **任务不对等**：
   - 人类有3分钟时间限制，LLM无时间限制（但通过长度匹配），可能忽略时间因素对搜索策略的影响。
   - 人类可能使用多种策略（如字母线索、视觉想象），而LLM仅依赖语言统计。
5. **忽略重复项处理**：虽然去重用于质心计算，但人类和LLM在避免重复上的差异未被深入分析。
6. **缺少行为基准**：未与传统语义搜索模型（如随机游走、Lévy游走）的模拟数据进行对比，无法判定LLM的行为比随机模型更糟或更接近人类。
7. **样本量**：人类82人，LLM每个温度30个序列（30个角色），统计功效可能不足检测更细微的差异，尤其是温度×模型交互效应。
8. **实际应用限制**：结论仅适用于语义流畅性任务，不能直接推广到其他认知任务（如归纳推理、概念学习）。
