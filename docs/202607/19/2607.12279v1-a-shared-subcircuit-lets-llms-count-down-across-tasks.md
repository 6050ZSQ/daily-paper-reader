## 摘要
写出恰好十二个单词的句子；在正确的密码子处结束DNA序列；格式化ASCII表格。这些都是语言模型能够完成的任务，需要追踪目标前还剩多少个词元。在这项工作中，我们在Llama-3.1-70B-Instruct中识别出一个执行这些任务的通用机制：一个“倒计时子电路”，它将当前位置与目标长度进行比较，并估计剩余时间。我们首先在受控环境中分离出倒计时子电路，该环境要求模型写出一个以指定单词结尾的固定长度句子。然后我们研究了该子电路所使用表示的几何结构，发现该子电路使用了一个先前在另一任务上于前沿大语言模型中发现过的相同基序，从而表明这个基序在模型间共享。最后，我们在自然语言数据集上使用无监督探针，发现了多种其他使用该子电路的任务，包括目标长度从上下文推断而非明确给出的任务。我们的工作表明，逆向工程子电路使我们能够理解行为如何从单个示例泛化到许多不同任务甚至模型。

## Abstract
Writing a sentence of exactly twelve words; ending a DNA sequence at the right codon; formatting an ASCII table. These are all tasks that language models can do that requires tracking how many tokens remain before a target. In this work, we identify in Llama-3.1-70B-Instruct a general mechanism for performing these tasks: a "countdown subcircuit" that compares the current position to a goal length and estimates the time remaining until then. We first isolate a countdown subcircuit in a controlled setting, in which the model is tasked with writing a fixed-length sentence ending in a specified word. We then investigate the geometry of the representations used by the subcircuit, and find that the subcircuit uses an identical motif previously identified in a frontier LLM on a separate task, thus suggesting that this motif is shared across models. Finally, we use unsupervised probing on a natural language dataset to find a variety of other tasks where this subcircuit is used, including tasks where the goal length is inferred from context rather than explicitly stated. Our work suggests that reverse-engineering subcircuits allows us to understand how behaviors generalize from a single example to many different tasks and even models.

- **整体含义**：证明存在一个可复用的子电路机制，使 LLM 能在不同上下文中追踪到目标长度的剩余距离。这一发现有助于理解 LLM 行为的泛化性，并为自动化子电路发现提供思路。

## 2. 方法论

### 核心思想
采用**自底向上**的逆向工程路径：先在受控任务（定长句子写作）中隔离出倒计时子电路，再通过几何分析和无监督探针揭示其跨任务、跨模型的通用性。

### 关键技术细节

1. **句子规划任务**  
   - Prompt 格式：`Write a <N>-word sentence ending in the word "<word>"`  
   - 模型需输出恰好 N 个单词，并以指定单词结尾。

2. **残差流修补（Residual Stream Patching）**  
   - 选取一对 prompt，目标长度不同（nsrc < ndst），且输出前 nsrc-1 个单词相同。  
   - 在目标长度 token 或长度单位 token（如"-word"）处，将源 prompt 的激活替换到目标 prompt 的对应位置。  
   - 若修补后模型输出句子长度变为 nsrc（即目标词 logit 升高），则说明该层信息对长度决策因果重要。  
   - 结果发现：长度信息在层 18 的长度单位 token 处最后被使用。

3. **注意力头定位**  
   - 计算层 18 所有注意力头从长度单位 token 到下游 token 的输出范数。  
   - 识别出三个“倒计时头”：**L18H24、L18H28、L18H30**，它们的输出总和在靠近目标长度时单调增加。

4. **几何分析**  
   - 将倒计时头的 key 激活（存储目标长度）和 query 激活（编码当前位置）投影到主成分空间。  
   - 发现 key 和 query 位于相似的弯曲流形上，且最高余弦相似度出现在 query 位置等于 key 对应目标长度时。  
   - 该几何结构与 Claude 3.5 Haiku 在换行任务中的发现完全一致，表明跨模型共享同一基序。

5. **无监督探针构建**  
   - 利用倒计时头在句子规划任务中的输出，构造代表“距离句子结尾 1 个/2 个词”的探针向量。  
   - 计算探针向量与 Pile / LMSYS-1M 语料中每个 token 处注意层输出的点积，筛选高出激活的示例。  
   - 无需人工标注即可发现多种使用该子电路的场景（如嵌入式推文、DNA 序列、哈希值、俳句、数字舍入、ASCII 表格等）。

## 6. 主要结论与发现

1. **存在共享的倒计时子电路**：在 Llama-3.1-70B-Instruct 中，层 18 的三个注意力头（L18H24, L18H28, L18H30）构成一个“倒计时子电路”，持续追踪当前位置到目标长度的距离。  
2. **子电路利用隐式目标长度**：当目标长度未明确给出时，模型会从上下文（如之前字符串的长度、结尾分隔符）推断隐式目标长度，并同样使用该子电路。  
3. **跨模型共享几何基序**：该子电路中 key 和 query 的表示位于对齐的弯曲流形上，与 Claude 3.5 Haiku 在换行任务中发现的几何结构完全相同，表明该计数基序跨模型普遍存在。
