## 摘要
稀疏自编码器（SAEs）将语言模型激活分解为稀疏特征，但标准SAEs独立编码每个token，无法揭示跨序列持续存在的信息。我们引入了持久稀疏自编码器（Persistent SAEs），通过为每个特征学习一个持久系数来扩展标准SAEs，使模型能够学习哪些特征应该持久以及持续多久。实验表明，它们在学习特征时间尺度谱的同时保持了有竞争力的重建质量：快速特征表现为局部可解释检测器，而慢速特征则将主题级信息集中在持久状态中。此外，如提示注入监控案例研究所示，慢速特征在长上下文中保持检测信号并保持因果有效性。这些结果表明，Persistent SAEs通过持久语义表示为解释和监控语言模型开辟了新的机会。

## Abstract
Sparse autoencoders (SAEs) decompose language model activations into sparse features, but standard SAEs encode each token independently and do not expose information that persists across a sequence. We introduce Persistent Sparse Autoencoders (Persistent SAEs), which extend standard SAEs by learning a persistence coefficient for each feature, allowing the model to learn which features should persist and for how long. Our experiments show that they retain competitive reconstruction quality while learning a spectrum of feature timescales: fast features behave as locally interpretable detectors, whereas slow features concentrate topic-level information in a persistent state. Moreover, as shown in a prompt-injection monitoring case study, slow features preserve detection signals and remain causally effective over long contexts. These results suggest that Persistent SAEs open up new opportunities for interpreting and monitoring language models through persistent semantic representations.

## 2. 方法论：核心思想、关键技术细节、公式/算法流程
### 2.1 核心思想
- 在标准BatchTopK SAE编码器之上增加一个 **对角线递归状态**，每个特征维护一个持久状态变量，由 token 级稀疏证据更新，并通过一个 **学习到的持久系数 λ_j** 控制证据的保留时长。
- 模型通过重建损失自动优化 λ_j：若携带特征 j 的状态有助于重建后续 hidden state，则 λ_j 倾向于变大（慢速）；否则 λ_j 变小（快速衰减）。

### 2.2 关键技术细节
1. **编码器结构**：沿用BatchTopK（全局选择 top-k 非负激活），输出 token-specific 证据 \( a_t \in \mathbb{R}^m_{\ge 0} \)。
2. **递归状态更新**（公式5）：
   \[
   h^{(j)}_t = \lambda_j \, h^{(j)}_{t-1} + (1-\lambda_j) \, a^{(j)}_t
   \]
   其中 \( \lambda_j \in (0, \lambda_{\max}) \)，\( \lambda_{\max}=0.999 \)。小 λ 对应快速特征（近 token 独立），大 λ 对应慢速特征（长期记忆）。
3. **解码器**（公式6）：
   \[
   \hat{x}_t = W_{\text{dec}} h_t + b_{\text{dec}}
   \]
4. **持久系数参数化**：\( \lambda_j = \sigma(l_j) \cdot \lambda_{\max} \)，通过 sigmoid 确保范围，与模型一起端到端优化。
5. **训练目标**：标准重建 MSE + 辅助死特征损失，无额外时序监督或预定义分区。

## 6. 主要结论与发现
1. **特征时间尺度自然涌现**：Persistent SAE 学到从快速到慢速的宽广 λ 谱系，大部分特征为快速（局部检测器），少部分为慢速（持久主题状态）。
2. **重建质量保持竞争性**：Persistent SAE 的 FVE 和余弦相似度与最强基线相当或略低，但保留了两类特征的有益分离。
3. **快速特征可解释性强**：低 λ 特征在自动解释评分上达到甚至超过标准 SAE；慢速特征的可解释性较低，但适合以组的形式评估。
4. **慢速特征形成紧凑语义状态**：在 MMLU 主题探测中，仅用 top 1% 慢速特征即可达到接近监督选择的 AUC（0.81），且 t-SNE 显示清晰的学科簇。
5. **监控与因果有效性**：在提示注入监控中，慢速特征在注入信号消失后仍保持高检测准确率，且因果干预表明其方向与监控判决对齐，而快速特征仅在注入时刻有效。

## 7. 优点

- **互补角色分离**：系统性地展示了快速特征（局部检测器）与慢速特征（持久语义状态）的协同作用，为模型可解释性提供新的分解视角。
