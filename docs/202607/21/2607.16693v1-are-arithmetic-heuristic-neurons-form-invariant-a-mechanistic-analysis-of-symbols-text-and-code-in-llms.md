## 摘要
大型语言模型通常在一种问题的表述上成功，而在等价表述上失败。这些失败是由不同的内部电路还是共享电路的不同激活状态引起的仍然未知。最近的机制可解释性研究表明，LLM中的算术来自一个“启发式包”，由一组稀疏的MLP神经元编码，这些神经元代表不同的算术策略。我们研究了算术启发式神经元在三种Llama-3模型中是否在符号算术、自然语言单词问题和Python代码中形式不变。在每种格式中，我们使用结合归因修补和激活修补的两阶段流程识别算术启发式神经元。一组紧凑的神经元在所有三种格式中共享，针对性的干预表明这个共享电路对于后期算术计算既是必要的也是充分的。将共享神经元的激活从一种格式的成功执行转移到另一种格式的失败执行，可以恢复大多数错误预测，加法和减法超过97%，表明跨格式失败源于激活状态而非不同电路。此外，共享神经元在不同格式中始终属于相同的启发式家族，表明LLM中的算术计算在神经元层面很大程度上是形式不变的。

## Abstract
Large language models often succeed on one formulation of a problem while failing on an equivalent formulation. Whether these failures arise from distinct internal circuits or different activation states of a shared circuit remains unknown. Recent mechanistic interpretability studies suggest that arithmetic in LLMs emerges from a "bag of heuristics," encoded by a sparse set of MLP neurons that represent distinct arithmetic strategies. We investigate whether arithmetic heuristic neurons are form-invariant across symbolic arithmetic, natural language word problems, and Python code in three Llama-3 models. In each format, we identify arithmetic heuristic neurons using a two-stage pipeline combining attribution patching and activation patching. A compact set of neurons is shared across all three formats, and targeted interventions show this shared circuit is both necessary and sufficient for late-layer arithmetic computation. Transferring the shared neurons' activations from a successful execution in one format to a failed execution in another recovers most incorrect predictions, exceeding 97% for addition and subtraction, indicating that cross-format failures arise from activation states rather than distinct circuits. Moreover, shared neurons consistently belong to the same heuristic families across formats, demonstrating that arithmetic computation in LLMs is largely form-invariant at the neuron level.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：大型语言模型（LLM）在不同表述形式（符号算术、自然语言文字题、Python 代码）下解决等价算术问题时常出现不一致表现——同一算术计算在一种格式上成功，在另一种格式上失败。这种跨格式失败是源于模型调用了**不同的内部电路**，还是源于**共享电路的不同激活状态**？
- **背景动机**：近期机制可解释性研究表明，LLM 的算术能力源于一组稀疏的 MLP 神经元实现的“启发式包”（bag of heuristics），不同神经元编码不同的算术策略。但这些研究几乎完全基于规范化的符号表达式，尚未探索神经元层面的计算是否在不同输入格式间保持**形式不变性**（form-invariance）。
- **研究意义**：理解这种形式不变性有助于揭示 LLM 算术推理的底层机制，为模型鲁棒性提升、跨格式泛化能力改进以及更复杂的推理任务分析提供基础。

## 2. 方法论

### 核心思想
设计两阶段流水线，在三种格式（符号算术、文字题、代码）中独立识别因果重要的算术启发式神经元，然后比较其重叠、因果必要性/充分性，并通过跨格式激活转移实验验证失败根源。

### 关键技术细节
1. **神经元重要性排序（两阶段）**  
   - **第一阶段：归因修补（Attribution Patching）**  
     用一阶泰勒展开近似每个神经元的间接效应（Indirect Effect），快速筛选出每层 top‑2000 候选神经元。公式：
     \[
     IE \approx (a_{\text{corrupt}} - a_{\text{clean}}) \cdot \frac{\partial m}{\partial a}
     \]
     其中 \(m\) 为间接效应目标。重要性分数为 μ+σ（均值+标准差），以兼顾平均效应和一致性。
   - **第二阶段：激活修补（Activation Patching）**  
     对 top‑2000 候选神经元进行精确的激活替换干预（将激活替换为破坏样本的对应值），重新计算间接效应，最终保留每层 top‑200 神经元。

2. **电路忠实度评估**  
   - **保持唯一（Keep‑Only）**：仅保留共享电路神经元，其余 MLP 神经元被均值消融（替换为预计算的均值缓存）。测试被保留电路恢复性能的程度。
   - **敲除（Knockout）**：仅消融共享电路神经元，其余保持不变。测试移除共享电路后性能下降的程度。
   - **忠实度指标**：基于归一化 logit（正确答案 token 的 logit 与最大 logit 之比）计算电路恢复的性能比例：
     \[
     \text{Faithfulness} = \frac{nl_{\text{circuit}} - nl_{\text{bad}}}{nl_{\text{good}} - nl_{\text{bad}}}
     \]
     其中 good 为未修改模型，bad 为完全均值消融，circuit 为仅保留电路。

3. **跨格式激活转移**  
   - 对于每种运算符和格式对（donor→target），选取在 donor 格式成功但在 target 格式失败的提示对（最多 600 对）。
   - 将 donor 成功执行时共享神经元的激活（仅在最终 token 位置）替换到 target 失败执行中，其余激活保持不变。
   - 比较三种条件：**匹配 donor**（相同操作数）、**不匹配 donor**（不同操作数）、**随机对照组**（随机选取等量神经元进行修补）。

4. **神经元启发式家族分类**  
   应用 Nikankin et al.（2025）的方法，根据神经元最高激活输入的模式（操作数范围、结果模数、结果值、数字模式等）将其分类到特定启发式家族。使用 0.6 的匹配阈值。

## 5. 实验数量与充分性

### 主要实验组
1. **线性探针实验**：每种模型/格式各训练一个 pooled‑operator 线性探针，观察答案可解码性层数。
2. **神经元重叠分析**：对每层 top‑k 神经元（k 从 10 到 2000）计算三种格式的三路 Jaccard 重叠（四个运算符分别计算）。
3. **因果忠实度实验**：
   - 保持唯一（Sufficiency）：在不同的 k 值下测量忠实度，每个运算符/格式组合都有。
   - 敲除（Necessity）：同样在不同 k 值下测量。

6. **跨模型规模验证**：Llama‑3.2‑3B 和 Llama‑3.2‑1B 复现上述主要实验，证明趋势一致。

## 6. 主要结论与发现

1. **紧凑的共享电路**：在每层约 50‑100 个神经元时，三种格式的 top‑k 神经元三路 Jaccard 重叠达到峰值（非单调曲线），表明存在一个紧凑的共享核心电路，且其被一致地用于不同格式的算术计算。
2. **共享电路的必要性与充分性**：  
   - **充分性**：保持共享电路（消融所有非共享 MLP 神经元）可恢复大部分性能，加法和减法在约 100‑500 个神经元/层时忠实度接近完整模型上限。  
   - **必要性**：仅移除共享电路（敲除）导致忠实度急剧下降，而移除等量随机神经元效应微弱。
3. **跨格式失败由激活状态差异引起**：将共享神经元在成功格式（donor）中的激活转移到失败格式（target）中，可恢复**超过 97% 的加法/减法错误预测**，乘法达 80‑85%，除法较弱但仍有明显改善。随机对照组几乎无改善。说明失败并非因为调用了不同电路，而是同一共享电路处于不同的激活状态。
4. **共享神经元保持机制一致性**：在三种格式中，共享神经元被分配到相同的启发式家族（如操作数范围检测器、结果值/模数/模式神经元），平均成对 Jaccard 相似度 0.75，三路 Jaccard 相似度 0.64，置换检验显著高于随机（p<10⁻⁴）。
5. **整体结论**：LLM 的算术计算在神经元层面是**形式不变的**——不同输入格式调用同一组因果上必要的启发式神经元，跨格式性能差异主要源于这些神经元激活状态的差异，而非不同电路的参与。

## 7. 优点（方法或实验设计上的亮点）

- **两阶段神经元筛选策略**：先利用计算高效的归因修补筛选候选，再用精确激活修补重排序，在保持排序质量的同时大幅降低计算成本。

- **跨格式激活转移实验设计**：直接测试“激活状态差异”假说，并设置不匹配 donor 和随机对照，有效控制混淆变量，证明恢复效果特异性于共享神经元的激活模式。
- **启发式家族跨格式一致性分析**：从功能层面验证共享神经元的机制一致性，而非仅停留在位置重叠计数，增加了结论的深度。
- **跨模型规模验证**：在 1B、3B、8B 三个不同规模的 Llama‑3 系列模型上复现主要结论，增强了结果的鲁棒性。

## 8. 不足与局限

- **任务范围有限**：仅涉及简单整数算术（加、减、乘、除，结果 ≤999），无法直接推广到更复杂的数学推理（如代数、多步问题）或非算术的语言理解任务。
- **模型范围有限**：仅使用了基础版 Llama‑3 系列，未覆盖指令微调模型（如 Llama‑3-Instruct）或其他架构（如 GPT、Mistral），形式不变性是否普遍存在需进一步验证。
- **组件聚焦单一**：因果干预和启发式分析仅关注 MLP 神经元在最终 token 位置的激活，未系统分析注意力头的角色。虽然引用其他工作表明注意力头负责操作数路由，但这部分是否也具有形式不变性未被研究。
- **数据构建偏差**：仅使用模型正确回答的提示来识别电路，可能遗漏了某些仅在失败情境中被激活的电路。虽然跨格式转移实验一定程度上处理了成功/失败差异，但未对完全随机的、未筛选的提示分布进行分析。
- **除法特殊性**：由于整数除法的有效单位数答案多样性低，导致除法实验的数据量相对较小，结果解释需更谨慎。
- **未报告算力消耗**：缺少对计算资源（GPU 数量、训练/推理时间）的详细说明，不利于复现和成本评估。
