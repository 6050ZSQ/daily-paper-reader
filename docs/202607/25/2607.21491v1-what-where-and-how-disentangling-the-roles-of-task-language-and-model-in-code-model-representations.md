## 摘要
独立训练的语言模型是否以相同的方式表征相同的事物？我们针对代码回答此问题，将近期引入的概念电路提取方法扩展至2×2设计——Python和Rust分别搭配Qwen2.5-Coder-7B与DeepSeek-Coder-V1-6.7B——并对所有四个单元格中相同的语法概念（58个Python概念、57个Rust概念）进行完整测量：这是能够分离任务、语言和模型各自影响的最小设计。答案分为三部分。哪些概念获得专用电路由任务决定：模型在哪些概念上拥有电路方面达成一致（Python Spearman ρ = 0.638，Rust ρ = 0.673，均为p < 10⁻⁷）。这些电路位于何处由模型决定：Qwen在约L17-19的后期频带处理概念，DeepSeek在L6-7处理概念，且对两种语言一致。电路如何跨层生长也由模型决定：Qwen为其原子概念提供早期峰值，而DeepSeek则没有。因此，“电路是否通用？”没有单一答案：对于“什么”是肯定的，对于“在哪里”和“如何”则是否定的——通用性是表征内容的属性，而非计算组织的属性。这些结构均非预先固定。一致性可能介于独立与同一之间；实际结果为ρ ≈ 0.65。在两种模型中，Rust结构比Python对应结构多获得2-3倍的概念特定电路。两种模型在语言间共享神经元（配对结构分别为6/7和7/7），DeepSeek的共享程度是Qwen的1.94倍——这一方向无先前结果可预测。Qwen将Rust的类型和特质机制中的九个关键词绑定到一个紧密的神经元簇中（Jaccard指数0.535 vs 零假设0.112，p < 0.001），这是表面语法中不可见的语义维度。消融实验和线性探针证实了这些电路的功能性。所有结论仅限于此2×2设计；每模型的轮廓是否可预测第三个模型是设计的下一个测试。

## Abstract
Do independently trained language models come to represent the same thing in the same way? We answer for code, extending a recently introduced concept-circuit extraction method to a 2x2 design -- Python and Rust crossed with Qwen2.5-Coder-7B and DeepSeek-Coder-V1-6.7B -- and measuring a complete inventory of grammatical concepts (58 Python, 57 Rust) identically in all four cells: the smallest design that separates what depends on the task, the language, and the model.   The answer splits into three parts. What earns dedicated circuitry is set by the task: the models agree on which concepts receive circuits (Spearman $ρ$ = 0.638 for Python, 0.673 for Rust, both p < $10^{-7}$). Where those circuits sit is set by the model: Qwen processes concepts in a late band (~L17-19), DeepSeek at L6-7, for both languages. How circuits grow across layers is also set by the model: Qwen gives its atomic concepts an early spike that DeepSeek does not. "Are circuits universal?" thus has no single answer: yes for What, no for Where and How -- universality is a property of representational content, not of computational organisation.   None of this structure was fixed in advance. The agreement could have landed anywhere between independence and identity; it lands at $ρ\approx 0.65$. Rust constructs receive 2-3x more concept-specific circuitry than their Python equivalents, in both models. Both models share neurons between the languages (6/7 and 7/7 paired constructs), DeepSeek 1.94x more than Qwen -- a direction no prior result predicts. And Qwen binds nine keywords of Rust's type-and-trait machinery into one tight neuron cluster (Jaccard 0.535 vs null 0.112, p < 0.001), a semantic dimension invisible in surface syntax. Ablation and linear probes confirm the circuits are functional.   All claims are scoped to this 2x2; whether the per-model profile predicts a third model is the designed next test.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- 核心问题：当两个代码模型（如 Qwen2.5-Coder-7B 和 DeepSeek-Coder-V1-6.7B）分别在不同数据上独立训练后，它们是否以相同的方式表征相同的语法概念？更广泛地说，“电路是否具有普遍性？”本文旨在回答该问题，并将普遍性分解为三个维度：**什么（What）**——哪些概念获得专用电路；**在哪里（Where）**——电路位于哪些层；**如何（How）**——电路如何随层数增长。
- 研究动机：以往电路发现方法（如激活修补）每次只能追踪一种行为、一个模型，无法直接跨模型比较；稀疏自编码器（SAE）的特征是每模型独立学习，缺乏天然对应。本文需要一种可在任意模型和语言上完全一致测量的方法，从而分离任务、语言、模型三个因素的独立作用。
- 整体含义：表示内容（What）具有跨模型普遍性（Spearman ρ ≈ 0.65），而计算组织（Where/How）则因模型而异，因此“电路是否普遍”没有单一答案，应为：普遍性是表示内容的属性，而非计算组织的属性。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：对每种语法概念（如 Python 的 `for`、Rust 的 `for`），生成一组“概念提示”（该概念处于结构角色中）和一组“检查提示”（该概念的关键词出现在字符串、注释等非结构角色中）。通过前向钩子记录所有层 MLP 输出的最后一词位置，对每个神经元二值化，取概念提示中所有提示的激活神经元**交集**，即该概念的概念电路；类似地，检查提示交集得到检查电路。最终概念专用电路 = 概念电路 \ 检查电路。
- **关键技术细节**：
  - **二值化**：设定阈值 ε = 0.5，神经元激活绝对值 > ε 即视为活跃。
  - **交集边缘化**：每个概念生成 50 个提示（通过词汇、结构、填充等维度注入变化），交集中洗掉与具体实例相关的偶然特征，保留核心概念对应的神经元。
  - **概念分数**：概念专用神经元数量 / 概念电路总神经元数，作为每概念的核心测量指标。
  - **流程**：提示生成 → 提取（一次运行保存制品） → 二值化 → 边缘化 → 分解（概念专用 / 共享 / 仅令牌）。
- **没有显式公式或复杂算法**，而是基于神经元交集的集合操作，以及后续用 Spearman 相关、Ward 聚类、置换检验、因果消融、逻辑回归探针等标准工具分析结果。

### 6. 论文的主要结论与发现

- **What（内容）是任务决定的**：两模型在哪些概念获得更多专用电路上高度一致（Python ρ = 0.638，Rust ρ = 0.673，p < 10⁻⁷），该排名取决于语言和预测任务，而非模型。
- **Where（位置）是模型决定的**：Qwen 概念处理集中在后期层（约 L17-19），DeepSeek 在早期层（L6-7），差距达 12-13 层，且对两种语言一致。
- **How（增长方式）也是模型决定的**：Qwen 的原子概念在早期（L2-3）出现尖锐峰值，DeepSeek 则从 L10 逐渐上升，无早期峰值。
- **语言设计影响表征强度**：Rust 概念获得的专用电路量是 Python 的 2-3 倍（Qwen 2.91×，DeepSeek 2.07×），削弱了 Python 中出现的三层等级（模块化关键词 > 非模块化控制流 > 内建函数）。
- **跨语言神经元共享**：两种模型都共享等价结构的神经元（DeepSeek 7/7，Qwen 6/7 通过），但 DeepSeek 共享程度是 Qwen 的 1.94 倍。
- **语义聚类**：Qwen 在 Rust 中将 9 个类型-特质关键词绑定为紧密簇（Jaccard 0.535 对比零假设 0.112，p < 0.001），发现了表面语法不可见的语义维度。
- **验证**：因果消融在 Qwen × Python 上实现了 4 个概念的双分离；线性探针准确率 97.6%-99.7%，且探针方向余弦与神经元交集 Jaccard 中度相关（峰值 r = 0.645）。

### 7. 优点

1. **创新性分解**：将电路普遍性拆分为三个正交维度（What/Where/How），这是对以往“是非题”式普遍性讨论的重要细化。
2. **可复现的测量框架**：方法定义与模型、语言无关，使得跨模型、跨语言的结构化比较成为可能，且全部制品开源。
3. **跨语言发现**：首次在代码模型中测量跨语言神经元共享，并发现共享程度是模型属性，而非语言属性。
4. **语义聚类**：通过神经元聚类发现了类型-特质机制这类抽象语义簇，表明方法能超越表面语法捕捉高层次概念。
5. **因果验证**：部分概念通过零消融双分离验证，增强了提取电路的因果可靠性。
6. **低维模式**：六项独立测量一致地将两模型区分为“晚期-尖锐”和“早期-平滑”两种处理风格，显示了跨模型变化的低维性。

### 8. 不足与局限

1. **仅两个模型**：所有结论局限于 Qwen 和 DeepSeek。无法确证归因是训练数据、体系结构还是初始化造成；需要第三个模型来检验处理风格的可预测性。
2. **因果验证范围小**：仅对 Qwen × Python 一个单元格进行了因果消融，跨模型结论主要基于相关指标。
3. **亚阈值结构缺失**：二进制方法只捕获高激活神经元，漏掉分布式的亚阈值信息（线性探针表明可解码但低于阈值神经元）。
4. **语言覆盖有限**：仅测试命令式语言（Python、Rust），未涉及声明式语言或证明助手。
5. **层数不匹配**：两模型层数不同（28 vs 32），文中部分分析使用绝对层索引，部分使用相对深度。
