## 摘要
提示压缩可以缩短大语言模型的输入，从而降低推理成本，但现有方法通过语言模型的正向传递来对token重要性进行评分。这种细致且高成本的token选择是否必要仍存疑问。压缩需要识别信息内容，而语言学研究早已通过可操作化为确定性规则的线索来解决这一问题。因此我们提出疑问：仅凭语言规则本身，能否在不依赖基于语言模型的评分的情况下，成为有效的提示压缩器？针对这一问题，我们通过离线进化搜索，在词汇、句法、语义和篇章种子中寻找具有竞争力的规则组合。由此产生的语言压缩器在部署时无需进行语言模型前向传递，仅使用CPU端处理即可完成压缩。我们采用双路径协议对其进行评估，以平衡压缩质量和重建保真度。在短文本、多文档推理和对话记忆问答数据集上，进化出的压缩器实现了与最近先进的提示压缩策略相似的性能。在轻度到中度压缩下性能最强，随着压缩程度加剧而下降，同时直接路径和重建路径表现出不同的模式。进化分析表明，有效的压缩融合了跨语言层次的信号，并且随着压缩比的增加，规则从token剪枝转向句子提取。

## Abstract
Prompt compression shortens LLM input to reduce inference cost, yet existing methods score token importance through LM forward passes. It remains questionable whether such nuanced, costly token selection is necessary. Compression requires identifying informative content, a problem that linguistic research has long addressed through cues that can be operationalized as deterministic rules. We therefore ask: can \textbf{linguistic rules alone} serve as effective prompt compressors, without LM-based scoring at compression time?   To address this, we conduct offline evolutionary search over lexical, syntactic, semantic, and discourse seeds to find competitive rule combinations. The resulting linguistic compressor requires no LM forward pass at deployment and uses only CPU-side processing for compression. We evaluate it with a dual-path protocol to balance compression quality and reconstruction fidelity.   Across short passages, multi-document reasoning, and dialogue-memory QA datasets, evolved compressors achieve performance similar to that of recent advanced prompt-compression strategies. Performance is strongest under light-to-moderate compression and degrades as compression becomes more aggressive, while the Direct and Reconstruction paths exhibit distinct patterns. Evolutionary analysis reveals that effective compression fuses signals across linguistic levels and, as the compression ratio increases, rules shift from token pruning to sentence extraction.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有提示压缩方法（如 LLMLingua、Selective Context）依赖大语言模型（LLM）的前向传播来对 token 重要性进行评分，计算成本高、延迟大，且 token 级剪枝可能破坏句法依赖和语义连贯性。本文质疑：**是否可以不依赖任何 LM 评分，仅用确定性语言学规则实现有效的提示压缩？**
- **研究背景**：语言学长期研究识别信息性内容（如内容词与功能词区分、论元结构、否定/量词范围、话语连接等），这些可转化为低成本、可解释的确定性规则。但尚无系统工作探索纯语言学规则在提示压缩中的潜力。现有仅有的语法树方法（如 PartPrompt）仍使用 LM 评分选择节点。
- **整体含义**：证明轻量级、可解释的语言学规则压缩器可以在许多长文档场景下达到与先进 LM 评分方法相似的性能，首次展示了无需 LM 前向传播的可行路径。

## 2. 论文提出的方法论

### 核心思想
- 用 **离线进化搜索**（基于 AlphaEvolve 框架）自动发现最优的跨层次语言学规则组合，生成纯 Python 压缩程序。部署时完全无需 LM 推理，仅依赖 spaCy 等轻量级 NLP 管道。

### 关键技术细节
- **种子构建**：初始种群包含 42 个种子，覆盖四个层次：
  - **词汇（10个）**：基于词性、命名实体、词频等选择/去除 token。
  - **句法（12个）**：基于依存树提取核心论元三元组、剪除关系从句/修饰语等。
  - **语义（6个）**：强制保留否定词、情态动词、量词等意义关键标记。
  - **话语（9个）**：通过句子位置、连接词、实体链等选择句子。
  - **复合管道（5个）**：级联多个层次的规则。
- **进化搜索**：
  - 使用 **MAP-Elites** 存档，根据代码复杂度和压缩比将候选分类到 48 个单元。
  - **变异操作**：LLM 变异器（GPT-5.4-mini、DeepSeek-V4-Pro、GPT-5.5 三档集成）对父代码的“进化块”进行搜索-替换编辑。
  - **三级级联筛选**：
    - 第1级：格式检查（输出是否为空、是否为字符串、压缩比是否在目标窗口）。
    - 第2级：用 1/6 样本评估直接和重建准确率，阈值放宽（α<1）。
    - 第3级：用 1/2 样本严格评估，阈值严格。
    - 最终全样本重评分。
  - **岛屿迁移**：6 个独立岛屿每 3 代迁移 15% 的最优个体。
- **双路径评估与适应度**：
  - **直接准确性 (D)**：压缩文本直接输入接收器 LLM 回答问题。
  - **重建准确性 (R)**：压缩文本先通过重建 LLM 恢复原文，再输入接收器 LLM。
  - **适应度 f = min(D, R)**，聚焦较弱路径。
- **部署**：仅 CPU，使用 spaCy 进行分词、词性标注、依存分析、命名实体识别等，无任何 LM 前向传播。

## 6. 论文的主要结论与发现

1. **语言学规则压缩器无需 LM 前向传播即可达到竞争性能**：在三个长文档数据集（Qasper、Multi-doc QA、LongMemEval）的很多设置下，性能与先进方法相似；在 RACE 短文本上较弱。
2. **性能最强于轻到中度压缩**：1.5x 和 2.5x 下排名靠前，4x 和 6x 下显著下降。
3. **进化融合多层级规则**：最佳压缩器始终使用跨词汇、句法、语义、话语层的组合，而非单层规则。
4. **压缩单元从 token 剪枝转向句子提取**：低压缩比时使用 token 级评分；高压缩比时先选句子再剪枝。
5. **低跨模型变异性**：在多文档 QA 和 RACE 上，我们的方法具有最低的变异系数（CV）。
6. **压缩比可控性强**：实际压缩比接近目标值，而许多基线会偏离（过压缩或欠压缩）。
