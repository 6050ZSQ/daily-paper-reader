## 摘要
可解释性方法旨在揭示大型语言模型（LLM）内部表示的特征。许多现有方法从人类定义概念的标记示例开始，这些示例可能反映人类偏见，然后识别该概念在模型中的表示方式，例如在其激活空间中或通过其他分解方法。我们提出了一种名为“基于激活几何的挖掘”（MAG）的简单无监督框架，通过向每个输入p前置相同的自然语言指令Q，从模型激活中提取推理特征，其中Q定义了感兴趣的推理特征，例如“这个物体能在沙漠中找到吗？”或“这个提示是恶意的吗？”我们在单个读出点使用m(Q ∣ p) - m(p)来衡量指令如何改变模型的内部表示。我们探索了八种不同的MAG。提取的推理特征可以预测模型自身对世界的理解和判断，并且可以近似为一个单一的激活方向。我们发现有些特征是更线性表示的，而有些则不那么线性。这种线性表示（即向量引导）可以通过注入推理特征进行激活引导来改变LLM的决策。最后，我们使用相同的方法为提示注入分类器探针选择最佳训练数据集：虽然普通激活之间的相似性与下游性能几乎无关，但基于RFD的相似性达到了94.7%的Top-1和100%的Top-2准确率。

## Abstract
Interpretability methods aim to reveal the features represented inside large language models (LLMs). Many existing methods begin with labeled examples of a human-defined concept that may reflect human biases, and then identify how that concept is represented within the model, for example in its activation space or through other decomposition methods. We introduce \emph{Mining via Activation Geometry} (MAG), a simple unsupervised framework for extracting reasoning features from model activations by prepending the same natural-language instruction $Q$ to every input $p$, where $Q$ defines the reasoning feature of interest, such as ``Can this object be found in the desert?'' or ``Is this prompt malicious?'' We measure how the instruction changes the model's internal representation using $m(Q \mid p) - m(p)$ at a single readout point. We explore eight different MAGs. The extracted reasoning features predict the models' own world understanding and judgment, can be approximated into a single activation direction, we found that some features are more linearly represented and some less, this linear representation, which is vector steering, can change the LLMs' decisions through activation steering by injecting reasoning features. Finally, we use the same method to select the best training datasets for prompt-injection classifier probes: while similarity between ordinary activations is almost unrelated to downstream performance, RFD-based similarity achieves $94.7\%$ Top-1 and $100\%$ Top-2 accuracy.

### 2. 论文提出的方法论

#### 核心思想
- **固定自然语言指令** \( Q \) 前置到每个输入 \( p \)，形成 \( Q \| p \)。
- 在最后一层最后一个 token 读出残差流激活 \( m(x) \)。
- 计算指令引起的激活变化：  
  \[
  \Delta_Q(p) = m(Q\|p) - m(p)
  \]
  该变化被视为**推理特征**的载体。

#### 关键技术细节
- **八个 MAG 算子**（表1）：
  - `Direct`: \( m(p) \)（无指令基线）
  - `Prefixed`: \( m(Q\|p) \)
  - `Answered`: \( m(Q\|p\|y_M(p)) \)（加入模型自回答）
  - `QuestionDelta`: \( m(Q\|p) - m(Q) \)
  - `InputDelta`: \( m(Q\|p) - m(p) \)（即 \( \Delta_Q(p) \)）
  - `Interaction`: \( m(Q\|p) - m(Q) - m(p) + m(\emptyset) \)
  - `Verdict`: \( m(y_M(p)) \)（仅答案 token）
  - `FewShot`: \( m(E\|Q\|p) \)（增加固定示例）
- **模型自标签**：\( y_M(p) = \mathbf{1}[ \Pr(\text{yes}|Q\|p) > \Pr(\text{no}|Q\|p) ] \)（对比前缀为肯定/否定），完全由模型决定。
- **线性度评估**：
  - 平均前缀偏移方向：\( v_Q = E_p[\Delta_Q(p)] \)
  - 归一化重建误差 \( \epsilon_Q \)（0=完美重建，1=无效果）
  - 余弦相似度测量重建方向与真值的对齐。
- **行为引导（steering）**：
  - 类均值方向：\( u_Q = v_Q^- - v_Q^+ \)（按 \( y_M \) 分组）
  - 校准强度 \( \alpha(\tau) = \tau \|A_{\text{prefixed}}\|/\|d\| \)，使干预幅度为残差幅度的固定比例。
- **数据集选择预测**：
  - 对候选数据集 \( C_i \) 和目标 \( T \)，计算 MAG 算子下的几何相似度（如余弦、CKA、Wasserstein 距离等），然后与真实迁移收益 \( \Delta(C_i,T) \) 排序比较。

#### 公式/算法流程（文字说明）
1. 选定需要的指令 \( Q \)（如“能在沙漠中找到吗？”）。
2. 对于每个输入 \( p \)，分别计算 \( m(p) \) 和 \( m(Q\|p) \)。
3. 可选地计算八个算子之一作为特征向量。
4. 按模型自标签 \( y_M \) 将样本分为 \( P^- \) 和 \( P^+ \)。
5. 计算类均值方向或全平均方向，用于线性重建或引导。
6. 在读出点注入方向并测度行为变化（如探针回答翻转）。
7. 数据集选择：对每个候选 \( C_i \) 和目标 \( T \)，在 MAG 算子下计算几何相似度，排序选最高者。

### 3. 实验设计

#### 数据集与场景
- **提示注入（PI）语料**：18 个数据集（AdvBench, HarmBench, InjecAgent, BIPIA, WildJailbreak, Mosscap, Gandalf, Deepset PI, Qualifire PI, SoftAge, Yanismiraoui, Jayavibhav, SafeGuard, LLMail, Dolly-15k, OpenOrca, Enron, PromptsRanked-10k）。每数据集 ~100（§3）或 500（§4）条。
- **80 物体概念集**：20 个沙漠物体、20 个海洋物体、40 个中性物体（如钢琴、日历等）。
- **前缀（指令）**：\( Q_{PI} \)（提示注入判断）、\( Q_{desert} \)、\( Q_{ocean} \)、\( Q_{Bob} \)（含完整上下文）。
- **模型**：主实验 Llama-3.1-8B-Instruct、Gemma-2-9B-it；压力条件 Qwen-2.5-32B-Instruct。
- **场景**：
  - **可读性（Readability）**：用 MAG 算子训练逻辑回归预测模型自标签 \( y_M \)，对比原始激活。
  - **线性度**：单层 vs. 逐层重建误差。
  - **引导**：在 12 个中性物体上使用类均值方向，看 yes/no 回答翻转。
  - **组合性**：Bob 方向是否与 desert 方向正交，且在 held-out 物体上仍有效。
  - **数据集选择**：从 18 个数据集中随机划分基础池、候选池、目标池，预测迁移增益。

#### 基准（Baseline）
- 原始未前置激活（`Direct`）的 ROC/Accuracy。
- 原始激活的质心余弦相似度用于数据集选择。
- 随机选择（1/6 = 16.7% Top-1）作为底线。

#### 对比方法
- 八个 MAG 算子相互比较。
- 不同度量：余弦、欧氏距离、相关距离、RBF-MMD、Wasserstein-1d、线性 CKA、类条件余弦等。
- 类条件 vs. 全栈组合。

### 6. 论文的主要结论与发现

1. **MAG 特征超越原始激活**：在所有概念集上（LODO/LOO），`Prefixed` 或 `InputDelta` 算子预测模型自标签的 ROC 优于 `Direct`（e.g., desert 从 0.909→0.940；ocean 0.969→0.988）。
2. **MAG 反映模型判断而非数据集标签**：当模型自标签与数据集标签不一致时，MAG 分类器以 69–74% 的概率支持模型判断（Wilson CI 不包含 50%）。
3. **前缀效应近似线性**：单读出点注入 \( v_Q \) 的重建误差 \( \epsilon_Q \) 在 0.59–0.97 之间（概念前缀比 PI 更线性）；最终层引导优于逐层引导。
4. **类均值方向可翻转二分类回答**：在匹配格式的探针测试中，向中性物体注入 \( u_Q \) 可翻转 11–12/12 的 yes/no；PI 前缀则几乎无法翻转（方向更固化）。
5. **上下文前缀产生独特方向**：Bob 方向与 desert 方向在 Llama 上几乎正交（cos=-0.04），在 Gemma 上部分重叠；两者均在 held-out 物体上有效（AUC >0.83）。
6. **MAG 几何可预测数据集迁移**：原始激活的质心余弦与下游性能无关（ρ≈0.01–0.05），而 MAG 算子（Y3,Y5,Y8）的类条件组合达到 94.7% Top-1/100% Top-2（在有效 shuffle 上）；全集最好对达到 62% Top-1。
7. **Centroid 稳定性**：仅需 64 条 prompt 即可达到稳定预测（Top-3 100%）。

### 7. 优点

- **完全无监督**：无需标注、无需模型微调、无需人工定义特征向量。
- **模型相对**：自动对齐模型的真实判断，而非数据集偏见。
- **简单通用**：只需前置指令并记录激活，可应用于任意自回归 Transformer。
- **多用途**：同时支持特征读取、行为控制和迁移预测，且方向可被复用和组合。
- **几何洞察**：通过线性度、余弦、类条件等几何量揭示了特征性质（线性/非线性、可引导性）。
- **实用性强**：在数据集选择任务上大幅超越随机基线，且仅需少量样本即可稳定。

### 8. 不足与局限

- **迁移任务单一**：数据集选择仅针对固定下游分类器，不同目标可能产生不同排序。
- **统计代表性受限**：最强三重组合的结果仅来自 19 个 shuffle（因为需要类条件 centroid），可能不反映全部 50 个 shuffle 的真实分布。作者已承认需独立验证。
- **乐观偏置**：最佳组合是在同一数据上评估并选择的，可能高估其真实泛化能力。
- **开放式引导控制弱**：虽然匹配格式探针中翻转效果好，但在开放式生成中效果不稳定（香草关键词计数增益有限）。
- **提示注入方向不线性**：PI 前缀 \( \epsilon_Q \) 高（~0.97），且无法引导中性 prompt 为恶意，说明该特征不是简单的读出方向。
- **未揭示机制**：尽管展示了行为效应，但未分析模型内部计算机制（如注意力头、MLP 的作用），仍属“特征挖掘”而非“机制解释”。
- **双用途风险**：MAG 可被攻击者用于探测和削弱安全相关表征（作者已指出）。
- **算力未报告**：缺乏资源细节，难以复现成本估算。
