## 摘要
大型语言模型（LLM）的显著能力常常因其不稳定性而受到削弱。即使提示中细微且语义无关的变化也可能导致性能剧烈波动，这种现象被称为提示敏感性。以往的研究通常通过比较提示变化时LLM的最终输出来评估提示敏感性，然而这种粗粒度的指标无法解释提示敏感性的内在原因。在本文中，我们引入交互作为细粒度工具来分析LLM的提示敏感性。具体来说，我们将LLM的输出分数分解为一组交互，每个交互表示涉及一组输入变量的非线性关系。我们发现，对提示的细微变化可能触发交互的严重不稳定，即使LLM的输出保持不变。为此，我们通过量化对提示引入细微变化时交互的变化，提出了一种基于交互的提示敏感性（IPS）度量。我们将IPS度量应用于50个开源LLM，并揭示了降低LLM提示敏感性的四个因素，包括监督微调、模型规模增大、密集架构和少样本学习。更为关键的是，我们发现了这四个因素降低提示敏感性的共同机制：所有四个因素都倾向于降低低阶交互（即涉及少量输入变量的交互）的提示敏感性。

## Abstract
The remarkable capabilities of large language models (LLMs) are often undermined by their instability. Even subtle and semantically irrelevant changes in prompts can cause dramatic fluctuations in performance, a phenomenon known as prompt sensitivity. Previous studies typically evaluate prompt sensitivity by comparing the LLM's final outputs when prompts change. However, such coarse-grained metrics fail to explain the internal reasons for prompt sensitivity. In this paper, we introduce interactions as a fine-grained tool to analyze prompt sensitivity of LLMs. Specifically, we decompose the output score of the LLM into a set of interactions. Each interaction represents a nonlinear relationship involving a set of input variables. We discover that subtle changes to prompts can trigger severe instability in interactions, even when the outputs of the LLM remain the same. To this end, we propose an Interaction-based Prompt Sensitivity (IPS) metric by quantifying changes in interactions when we introduce subtle changes to prompts. We apply the IPS metric to 50 open-source LLMs and uncover four factors that reduce the prompt sensitivity of LLMs, including supervised fine-tuning, increased model scales, dense architectures, and few-shot learning. More crucially, we discover a common mechanism by which these four factors reduce prompt sensitivity: all four factors tend to reduce the prompt sensitivity of low-order interactions (i.e., interactions involving few input variables).

## 论文核心问题与整体含义

大型语言模型（LLM）在众多自然语言处理任务中表现卓越，但其输出稳定性令人担忧。即使用户对提示语（prompt）进行细微甚至语义完全无关的修改（如改变字母大小写 "Answers" 变为 "ANSWERS"），模型性能也可能出现剧烈波动，该现象被称为**提示敏感性**。

现有评估提示敏感性的研究大多采用**粗粒度指标**，通过比较 LLM 在提示变化前后的最终输出（如任务准确率、输出一致性）来量化敏感性。这类指标只能揭示"结果发生了什么变化"（例如模型回答从正确变为错误），却无法解释"为什么发生这种变化"、"模型内部哪些推理逻辑变得不稳定"。因此，论文旨在引入一种**细粒度的交互分析框架**，从模型内部推理模式层面深入理解提示敏感性的来源与机制。

## 论文方法论

### 核心思想

论文将 LLM 的标量输出（如生成正确答案的对数几率）分解为一组**交互（interactions）**。每个交互表示多个输入变量（如词）之间的非线性联合关系。例如，句子 *"He is a green hand"* 中，"green" 与 "hand" 两个词共同出现时触发特定语义效应（初学者），该项效应即对应一个交互。通过分析交互在提示变化前后的稳定性，可以精确定位模型内部不稳定的推理模式，从而评估提示敏感性。

### 理论保障

- **普遍匹配定理（Universal Matching Property）**：对任意随机遮蔽输入 $x_T$，通过设置合适的交互权重 $I_S$（由 Möbius 变换给出），逻辑模型 $\phi(x)$ 可精确重构 LLM 的原始输出 $v(x)$，即 $v(x_T) = \phi(x_T) = \sum_{S \subseteq N} I_S$。
- **稀疏性性质**：LLM 只编码少数显著的交互，大量交互的效应可忽略不计。实验证明，仅使用前 3%-5% 的显著交互即可高精度拟合 LLM 的全部输出，这保证了交互分析的可信度与可操作性。

### IPS 指标

论文提出 **Interaction-based Prompt Sensitivity（IPS）** 指标，计算方式为：

$$IPS \triangleq \mathbb{E}_x \left[ \mathbb{E}_{T,\hat{T}} \left[ \frac{1}{|\Omega_{union}|} \sum_{S \in \Omega_{union}} \frac{|e_{I_S}(x|T) - e_{I_S}(x|\hat{T})|}{ \frac{|e_{I_S}(x|T)| + |e_{I_S}(x|\hat{T})|}{2} } \right] \right]$$

其中 $\Omega_{union}$ 为两套提示模板下显著交互集合的并集，该指标度量显著交互效应在提示变化时的对称平均绝对百分比误差。此外，论文将交互按其阶数（涉及输入变量的数量）分为低阶（≤ n/3）、中阶（n/3 ~ 2n/3）和高阶（> 2n/3），分别计算 IPS，以剖析不同类型交互的稳定性。

### 丰富性验证

论文针对不同 LLM 使用了特定的 mask 令牌（如 `<unk>` 或 `<pad>`）实现输入变量遮蔽，并设计了 5 套仅含格式差异的提示语模板进行两两组合评估。

- **主实验**：50 个 LLM × 2 个基准数据集（ARC、MMLU）× 5 套提示模板 × 两两组合
- **少样本实验**：13 个 LLM 的 0/1/2/3-shot 对比
- **阶数分析**：按低/中/高阶交互分别计算 IPS
- **消融实验**：阈值 τ 的敏感性分析（16 个阈值从 0.05 到 0.20）
- **泛化验证**：开放任务（Dolly-15k）、更复杂的提示扰动（语义改写、指令重排序）
- **控制变量实验**：在相近激活参数下对比 MoE 与稠密架构（附录 I）

### 充分性与客观性

实验设计较为充分和客观：

- **阈值鲁棒性**：τ 扫描显示 IPS 排名高度一致（Spearman 相关系数 0.9905，Pearson 相关系数 0.9957），证明结论不依赖特定超参数
- **跨数据集一致性**：ARC 与 MMLU 上结论一致
- **跨场景泛化**：从多选题扩展到开放域任务、从模板修改扩展到语义改写与指令重排，结论均保持稳定
- **控制混淆变量**：针对 MoE 与稠密模型对比时进行了激活参数的控制变量分析，排除了模型规模因素的干扰
- **与传统指标对齐**：IPS 与输出一致性呈负相关，说明新指标与直觉一致，同时提供更细粒度的信息

## 主要结论与发现

1. **IPS 分布差异显著**：50 个 LLM 的 IPS 值从 1.268（Qwen2.5-72B-Instruct）到 1.752（Mistral-7B-v0.3）不等，但没有任何模型家族全面胜出，提示敏感性受多因素共同影响。

2. **四个降低提示敏感性的因素**：
   - **监督微调**：Instruct/Chat 模型普遍比 Base 模型敏感性更低。原因可能是微调使模型更精确理解提示模板的功能并聚焦于任务相关信息。
   - **模型规模**：同一系列内，参数量越大，提示敏感性越低。
   - **稠密架构优于 MoE**：MoE 模型通常比同系列稠密模型更敏感（控制激活参数后结论仍成立），这可能与 MoE 的动态路由机制导致不同提示输入被分配到不同专家处理有关。
   - **少样本学习**：相比 0-shot，加入少量上下文示例后提示敏感性显著降低，其中 0-shot 到 1-shot 的降幅最大。

3. **共同机制**：这四个因素降低提示敏感性的共同途径是**主要降低低阶交互的不稳定性**。实验表明低阶交互天然最稳定，而这些因素进一步稳定了本已稳定的低阶交互；相比之下，高阶交互本就最不稳定，这些因素却对其改善甚微。这说明让 LLM 学会稳定高阶交互是更具挑战性的任务。

4. **潜在不稳定的发现**：即使在 LLM 最终输出相同的情况下，其交互模式仍可能剧烈变化（60%-80% 的显著交互不稳定），说明输出层面的评估会遗漏重要的内部不稳定信号。

## 优点

1. **细粒度分析新范式**：突破了传统仅关注最终输出的粗粒度评估，首次将交互框架引入提示敏感性分析，提供了透视模型内部推理稳定性的新视角。
2. **理论严谨性**：交互分解具有严格的数学保障（普遍匹配定理），并经过稀疏性实证验证，保证了分析工具的可信度。
3. **丰富的实验验证**：覆盖 6 大家族 50 个模型、多个数据集、多种提示扰动类型，并进行了阈值敏感性分析、控制变量分析和跨场景验证，结论可靠性强。
4. **深刻的机制发现**：不仅识别出降低提示敏感性的四个因素，还揭示了其共同作用机制（低阶交互稳定化），为后续模型设计和训练方法改进提供了明确方向。
5. **揭示隐性风险**：发现 LLM 在输出不变时内部交互仍可能高度不稳定，揭示了传统评估方法无法捕捉的潜在可靠性风险。
6. **对比分析深刻**：与隐层表示相似度等替代指标的系统对比（附录 H），阐明了交互框架在解释力和保真度上的独特价值。

## 不足与局限

1. **计算成本高**：交互计算需要对 $2^n$ 个遮蔽输入进行评估，复杂度随输入词数指数增长。虽然论文讨论了选择关键词、短语级聚合和近似计算等方法，但大规模长文本场景下计算开销仍是实际部署的瓶颈。
2. **主要面向判别式输出**：IPS 以生成正确答案的概率的对数几率作为分解对象，本质上更适合分类/多选题任务，对开放式生成任务的分析虽然做了验证，但整体方法设计仍偏判别式视角。
3. **阈值依赖**：显著交互的筛选依赖阈值 τ，虽然实验表明结果在较宽范围内保持一致，但理论上仍存在对超参数的选择依赖。
4. **模型覆盖范围有限**：虽然涵盖了主流的 50 个开源模型，但未包括 GPT-4、Claude 等闭源 SOTA 模型，结论对前沿闭源模型的适用性未知。
5. **提示扰动类型有限**：主实验主要利用语义等价的格式变化（大小写、分隔符、括号样式），虽然附录中补充了语义改写和指令重排，但未涵盖对抗性提示、恶意提示等场景。
6. **阶数划分标准存在任意性**：低/中/高三阶的划分采用固定比例（n/3 与 2n/3），未对不同序列长度下该划分的合理性进行深入讨论。
7. **因素交互作用未深入分析**：四个因素（微调、规模、架构、少样本）分别被独立分析，但未充分探讨它们之间的交互效应（例如更大规模的 MoE 模型是否能在稳定性上接近稠密模型）。
