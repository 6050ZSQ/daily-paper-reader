## 摘要
大多数多项选择题（MCQ）基准仅通过模型是否选择正确答案来评估大型语言模型（LLM）。这种二元评分将所有错误回答等同对待，尽管LLM在错误选项之间的偏好可能包含关于其行为和能力的系统性且有用的信息。我们提出了LLM名义响应模型（LLM-NRM），这是一种选项感知的心理测量框架，它建模答案选择的完整分布，以联合估计LLM能力和选项级项目特征，同时分离模型特定的响应校准锐度、位置偏好和依赖难度的回退行为。在来自14个基准的189个LLM和31,554个项目上，LLM-NRM预测留出LLM-项目交互的准确性优于二元项目响应模型和常规名义响应基线，其能力估计与外部人类偏好Arena.ai Elo排行榜实现了0.920的最强Spearman相关性。干扰项身份每个项目贡献了超过正确性101%的额外Fisher信息，仅错误回答就能以Spearman 0.943恢复全信息能力估计。学习的项目参数还实现了高效基准测试，其中41个选定项目以Kendall相关性0.85保留了全库排名，相当于减少了770倍。总之，我们表明错误回答携带独特且有用的测量信息，而非代表等效的错误。

## Abstract
Most multiple-choice question (MCQ) benchmarks evaluate Large Language Models (LLMs) only by whether they select the correct answers. This binary scoring treats all incorrect responses alike, even though an LLM's preferences among incorrect options may contain systematic and useful information about its behavior and ability. We introduce the LLM Nominal Response Model (LLM-NRM), an option-aware psychometric framework that models the full distribution over answer choices to jointly estimate LLM ability and option-level item characteristics, while separating model-specific response calibration sharpness, positional preference, and difficulty-dependent fallback behavior. Across 189 LLMs and 31,554 items from 14 benchmarks, LLM-NRM predicts held-out LLM-item interactions more accurately than binary Item Response models and conventional nominal-response baselines, and its ability estimates achieve the strongest Spearman correlation of 0.920 with the external human-preference Arena.ai Elo leaderboard. Distractor identity contributes +101% additional Fisher Information per item beyond correctness, and incorrect responses alone recover full-information ability estimates with Spearman 0.943. The learned item parameters also enable efficient benchmarking, where 41 selected items preserve the full-bank ranking with Kendall's correlation 0.85, corresponding to a 770 times reduction. In conclusion, we show that incorrect answers carry distinct and useful measurement information rather than representing equivalent mistakes.

## 论文总结

### 1. 论文的核心问题与整体含义（研究动机和背景）

当前大多数多项选择（MCQ）基准评测中，LLM 的能力仅通过“是否选对正确答案”这一二元结果来衡量。但这种精度指标存在明显局限：

- **信息丢失**：所有错误回答被一视同仁，无法区分“猜错”和“有部分知识的错”——错误选项的内部偏好可能蕴含系统性的行为与能力信息；
- **基准依赖**：准确率受题目组成、难度分布和比较模型集合影响，排名可能在更换基准或评分协议后发生偏移；
- **饱合效应**：顶级模型在现有基准上逐渐接近满分，准确率区分度减弱；
- **缺乏测量不确定性**：单一数值无法反映测评本身的置信度与误差。

论文的核心立场是：**LLM 在选项上的完整概率分布本身就是一种心理测量响应**。通过建模“模型会选哪个错误选项”，而非只关注“选对或选错”，可以提取更多关于模型能力与决策机制的信息。

### 2. 论文提出的方法论（核心思想、技术细节、公式）

论文提出 **LLM 名义响应模型（LLM-NRM）**，是对经典 Bock Nominal Response Model (NRM) 的选项级扩展。核心改进是同时建模**完整选项分布**，并分离 LLM 特有的三类系统行为因素。

**核心公式与结构：**

1. **Bock 基础 NRM：** 每个选项 k 的响应概率为 softmax 形式，其中 $a_{ik}$ 为选项区分度、$c_{ik}$ 为截距、$θ_j$ 为潜在能力；要求对每个题目满足 $\sum a_{ik}=0$、$\sum c_{ik}=0$ 的识别约束。

2. **LLM 的扩展（三项关键机制）：**
   - **校准锐度（Response Sharpness，$s_j$）**：每个模型有独立的逆温度参数，只改变分布浓缩程度而不改变选项排序，将“模型表达自信的程度”与“真实知识水平”解耦；
   - **位置偏好（Positional Bias，$\delta_j$）**：建模与内容无关的选项位置偏好（如偏好 A/B/C/D），通过可学习的向量 $\delta_j$ 在参数估计中一并识别；
   - **难度门控猜测回退（Difficulty-Gated Guessing Fallback，$G_{ji}$）**：用 Logistic 门控函数控制“能力—难度差”对回退策略权重的调节，门控公式为 $G_{ji} = \sigma(w_0 - κ(θ_j - \tilde{b}_i))$，其中难度指数通过 Newton 一步近似从 NRM 参数中导出，不增加额外自由参数。

3. **最终响应分布：** 能力驱动与回退两种过程通过门控权重插值，以 softmax 归一化得到完整选项分布。

4. **参数估计：** 全部参数（每题目 2(K−1) 个 + 每模型 2K_max 个 + 两个全局标量）通过 MAP 估计，使用 Adam 优化器最小化软交叉熵损失，并施加能力先验 $θ_j \sim N(0,1)$。

该模型将经典 NRM 作为特例（当 $s_j=1$、$\delta_j = \rho_j = 0$、$G_{ji}=0$ 时退化为 NRM），保持了模型的可解释性和灵活性的统一。

### 7. 优点（方法或实验设计的亮点）

- **方法创新性强**：首次将名义响应模型系统引入 LLM 评估，将“错误答案等同”的默认假设成功打破，实现了理论心理学模型与 LLM 行为的有效衔接；
- **细致的行为分解**：将校准锐度、位置偏好和难度门控回退分离出来，避免这些非能力因素污染能力估计；三个组件均有消融验证；
- **多维评测体系**：不仅报告预测精度，还从信息论（Fisher 信息）、外部效度（Elo）、数据效率三个角度佐证，论证闭环完整；

- **实际价值明确**：41 题保持 0.85 排名相关和 5 个 LLM 校准即可用的结论，直接降低了评测成本，对实际工程部署有直接指导意义。

### 8. 不足与局限

- **单维能力假设**：所有模型参数（含题目区分度）仅对应一个潜在维度 θ，无法刻画多维能力（如推理、知识、常识的相对差异）；
- **选项概率获取门槛**：方法依赖模型对每个选项的对数概率或完整 logits，很多 API 仅暴露 top-k logits，对不完全暴露的选项处理较为粗糙（直接分配零质量）；
- **零样本单一评测协议**：未测试少样本（few-shot）或开启 CoT 时的表现；温度 T=1 下概率分布是否稳定、不同温度对参数估计的影响未讨论；
- **算力信息缺失**：未能提供训练开销的具体数据，无法评估该方法在更大规模（如数万模型）上的实际可行性；
- **外部效度依赖单一指标**：仅与 Arena.ai 一个人类偏好榜单做对照，未使用其他人类评测（如人工专家评分）或下游任务表现做交叉验证；
- **位置偏置和回退向量的可解释性**：δ 与 ρ 向量虽是模型可辨识参数，但其实际语义是否对应真实现象缺乏更细粒度的验证（如与选项重排实验对照）；
- **题目质量未审计**：未分析题目参数估计是否受基准本身错误、歧义或敏感问题的影响。
