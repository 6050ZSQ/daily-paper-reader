## 摘要
多语言大语言模型在不同语言上表现出显著的性能差异，而现有的自适应方法通常需要参数更新和大量的多语言训练数据。我们提出一种推理时的多语言引导方法，使用预训练的稀疏自编码器来识别和强化与目标语言相关的特征。利用多语言平行句，我们比较不同语言间的SAE激活，并为每个目标语言选择少量特定层特征。这些特征被解码为引导信号，并注入模型的隐藏状态，无需额外训练。在Gemma-3-12B-it上的实验显示，在XCOPA上平均准确率提升10.9个百分点，在XNLI上提升5.3个百分点，在MGSM上提升1.9个百分点。

## Abstract
Multilingual large language models exhibit substantial performance differences across languages, while existing adaptation methods often require parameter updates and considerable multilingual training data. We propose an inference-time multilingual steering method that uses pretrained sparse autoencoders to identify and strengthen target-language-related features. Using multilingual parallel sentences, we compare SAE activations across languages and select a small number of layer-specific features associated with each target language. These features are decoded into steering signals and injected into the model's hidden states without additional training. Experiments with Gemma-3-12B-it show average accuracy improvements of 10.9 percentage points on XCOPA, 5.3 points on XNLI, and 1.9 points on MGSM.

### 1. 论文的核心问题与整体含义

多语言大语言模型（Multilingual LLMs）虽然展现出强大的跨语言处理能力，但其在不同语言上的性能存在显著的不均衡：通常英语等资源丰富语言的表现最强，而低资源语言的表现则明显落后。这一差距主要源于预训练语料中语言分布的极度不平衡。

现有的多语言适配方法（如持续预训练、指令微调、表示对齐等）虽然有效，但普遍需要更新模型参数、依赖大量多语言训练数据，这在低资源场景下代价高昂且难以推广。本文提出了一种**轻量级的推理时转向（inference-time steering）方法**，利用预训练的稀疏自编码器（Sparse Autoencoders, SAEs）识别并强化与目标语言相关的内部特征，从而在不更新任何参数、不依赖大规模训练数据的前提下，显著提升多语言下游任务性能。

其核心研究问题是：**能否通过在推理时仅强化模型内部的目标语言特定特征，来改善多语言任务的准确性？**

### 2. 论文提出的方法论

#### 2.1 核心思想

论文的核心假设是：SAE能够将模型的隐藏状态分解为稀疏的、可解释的潜在特征，其中一部分特征专门编码"语言身份"信息。通过比较平行句中不同语言的SAE激活，可以定位这些语言判别性特征，并直接将它们作为"转向信号"注入回模型的隐藏状态，从而"提醒"模型以更倾向于目标语言的方式处理输入。

#### 2.2 关键技术细节

整体流程分为三个步骤：

**（1）SAE特征编码**
- 使用预训练的、层特定的SAE（本文使用Gemma Scope 2，每层含16,384个潜在特征），将每个token的隐藏状态 $h_{i,t}^{\lambda,l}$ 编码为稀疏特征向量：
  $$z_{i,t}^{\lambda,l} = f^l(h_{i,t}^{\lambda,l})$$
- 模型参数和SAE参数全程冻结。

**（2）语言特定特征识别**
- 使用FLORES-200平行句对（500句），对各语言的token级SAE激活进行平均，得到语言级特征表示 $\mu_l^\lambda$。
- 参考表示（Reference Representation）有两种选择：
  - **多语言质心（Multilingual centroid）**：对所有非目标语言取平均 $\mu_{multi}^l$，视为语言中性的语义基准。
  - **英语基准（English reference）**：直接用英语的激活 $\mu_{en}^l$，用于测试"英语内部空间"假设。
- 计算目标语言与参考表示的激活差异：
  $$\Delta_{l}^{\tau, multi} = \mu_\tau^l - \mu_{multi}^l$$
  或
  $$\Delta_{l}^{\tau, en} = \mu_\tau^l - \mu_{en}^l$$
- 在每层按差异绝对值排序，选取Top-k（k=3）特征作为目标语言特征集 $I_l^{\tau,r}$。

**（3）转向信号构建与注入**
- 构建稀疏SAE码 $s^l$：选中的特征保留其带符号的差异值，未选中的置零：
  $$s_j^l = \begin{cases} \Delta_j^l & j \in I^l \\ 0 & \text{otherwise} \end{cases}$$
- 通过SAE解码器将稀疏码映射回表示空间，得到转向向量：
  $$v^l = g^l(s^l)$$
- 在选定层的**最后一个提示token位置**，将转向向量注入隐藏状态：
  $$\tilde{h}_q^l = h_q^l + \alpha v^l$$
  - $\alpha$ 为转向强度系数，在验证集上搜索选择。
  - 仅干预首个响应token的生成，后续生成位置不做干预。
- 模型继续前向计算，无需任何训练或参数更新。

### 3. 实验设计

#### 3.1 模型与SAE配置
- **模型**：Gemma-3-12B-it（12B参数，48层Transformer，指令微调版本）。
- **SAE**：使用配套的Gemma Scope 2提供的层特定SAE，作用于残差流输出，每层16,384个特征，采用small-L0变体。所有层配置一致。

#### 3.2 数据集与基准
- **特征识别语料**：FLORES-200中的500组平行句对（覆盖实验涉及的全部语言）。
- **下游评估基准**（均进行语言级拆分，验证集调参、测试集报告）：
  - **XCOPA**（常识因果推理）：9种语言（爱沙尼亚语、印尼语、意大利语、斯瓦希里语、泰米尔语、泰语、土耳其语、越南语、中文），500条/语言（100验证+400测试）。
  - **XNLI**（自然语言推断）：9种语言（德语、西班牙语、法语、俄语、斯瓦希里语、泰语、土耳其语、越南语、中文），500条/语言。
  - **MGSM**（数学推理）：4种语言（德语、西班牙语、法语、日语），250条/语言（50验证+200测试）。

#### 3.3 评估设置
- **XCOPA/XNLI**：计算候选标签（A/B或A/B/C）的next-token分数，选最高者为答案。
- **MGSM**：贪心解码生成逐步解答，提取最终数值与参考答案比对。
- **转向系数选择**：在验证集上搜索（XCOPA: 0.0~2.5，XNLI/MGSM: 0.0~1.0，步长0.1），选择最优α固定后用于测试集。

#### 3.4 对比方法（消融与基线）
- **Baseline**：不进行转向干预（α=0）。
- **SAE-based变体**（2×2组合）：
  - 参考表示（多语言质心 vs 英语） × 信号内容（仅语言信息 vs 保留完整语义信息）。
- **非SAE控制方法**：
  - 隐藏状态缩放（Hidden-state scaling）。
  - 直接隐藏维度Top-k转向（Hidden Top-k）。
  - 最小二乘英语投影（Least-squares English projection）。共7种干预策略。

### 6. 论文的主要结论与发现

1. **SAE转向有效提升多语言任务性能**：
   - XCOPA平均准确率从54.5提升至65.8（+11.3个百分点）。
   - XNLI从45.6提升至49.8（+4.1个百分点）。
   - MGSM从80.5提升至81.1（+0.6个百分点）。
   - 摘要中提到的更大增益（10.9/5.3/1.9）来自固定/不同设置下的结果表述差异。

2. **转向强度具有广泛有效区间**：XCOPA上增益在α≈1.4左右达到峰值，多数语言在较大α范围内均保持正增益。

3. **固定的共享系数也能带来整体收益**：α=0.6时，XCOPA、XNLI、MGSM分别平均提升4.75、1.61、2.13个百分点，表明方法不依赖逐语言精细调参。

4. **SAE分解是有效的关键**：直接隐藏维度Top-k转向（+1.5%）远不如SAE-based方法（+11.3%），说明稀疏化特征提取是隔离语言信号的关键。

5. **语义信息是否保留影响因任务而异**：在XCOPA上完整表示更优，在XNLI上语言单独信号更优，说明原始隐藏状态中已有语义信息，转向信号无需重复。

6. **多语言质心与英语基准效果相当**："英语中心"假设并非唯一有效路径，多语言中性基准为更通用的方案。

### 8. 不足与局限

- **模型与SAE通用性受限**：
  - 依赖与模型匹配的高质量SAE（Gemma Scope 2），目前仅少数模型家族具备此类资源，极大限制了方法向其他LLM（如Llama、Qwen、Mistral）的迁移。
- **语言覆盖仍有限**：涉及的低资源语言（斯瓦希里语、泰米尔语等）数量较少，且实验均基于英语为中心的任务模板，对于不使用拉丁/字母书写体系的语言（如阿拉伯语、印地语）仍需验证。
- **性能波动与鲁棒性**：
  - 部分语言出现性能下降（如德语在XNLI中下降2.5个百分点、日语在MGSM中下降0.5），论文未给出解释。
  - 所有实验仅单次运行，无标准差或显著性检验，难以判断结果波动的统计意义。
- **特征选择的语义混淆风险**：
  - 平行句仅在语义层面大致对齐，但不同语言句子的token级激活仍可能受句法差异、标注语料噪声影响，论文未定量评估这种混淆。
- **转向层和k值的通用性**：
  - 干预层（L6/L47）和Top-k（k=3）在XCOPA上选取，但未在XNLI/MGSM上分别调优，可能低估其他任务的最优效果。
- **现实场景适用性**：
  - 对MGSM等长生成任务增益较小（<1个百分点），对需要长链条思维的任务是否有效仍待验证。
