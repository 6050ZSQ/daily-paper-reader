## 摘要
多语言推理评估在很大程度上依赖于翻译英语基准测试，这种做法引入了语言伪影，且未能测试基于文化的推理。我们提出了ADAGE（基于设计的类比难度评估，用于扎根评估），这是一种语言无关的流水线，结合母语者策展与LLM辅助生成，为抽象类比推理构建具有挑战性且无需翻译的基准。我们通过为阿拉伯语、阿姆哈拉语和日语构建基准来验证ADAGE。评估14个开放权重模型，我们发现一致的文化推理差距：在英语谚语推理上表现良好的模型在所有三种母语基准上显著挣扎，准确率相对英语下降12至52个百分点。我们发布了该流水线、所有三个基准以及完整评估套件。

## Abstract
Multilingual reasoning evaluation overwhelmingly relies on translating English benchmarks, a practice that introduces linguistic artifacts and fails to test culturally-grounded reasoning. We introduce ADAGE (Analogical Difficulty-by-design Assessment for Grounded Evaluation), a language-agnostic pipeline that combines native-speaker curation with LLM-assisted generation to construct challenging, translation-free benchmarks for abstract analogical reasoning. We validate ADAGE by constructing benchmarks for Arabic, Amharic, and Japanese. Evaluating 14 open-weight models, we find a consistent cultural reasoning gap: models that perform well on English proverb reasoning struggle substantially on all three native benchmarks, with accuracy dropping by 12--52 percentage points relative to English. We release the pipeline, all three benchmarks, and the full evaluation suite.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：大型语言模型在复杂推理任务上表现出色，但这一进步几乎完全通过英语中心的基准测试来衡量。主流的**多语言评估**方法是机器翻译英语基准，这带来了两个核心问题：
  - **翻译腔（Translationese）**：机器翻译产生不自然的措辞和细微错误，混淆测量结果——模型失败可能反映翻译质量差而非推理能力差。
  - **文化不匹配**：翻译保留了源语言的文化假设，而丢弃了目标文化的推理模式。抽象类比推理（如理解谚语并应用到新情境）本质上无法通过翻译保留，因为其底层文化图式不可迁移。

- **核心概念**：论文提出**文化推理（Cultural Reasoning）**，指使用文化共享的隐喻、规范和语境假设来适当应用抽象意义的能力——这是一种本质上受语言和文化约束的能力。谚语解读是该能力的典型实例。

- **现状问题**：
  - 现有本土基准（MultiNRC、IOLBENCH、Jawaher、ProverbEval等）各有局限：多为单一语言或语言组临时构建，无复现流水线；且多数测试谚语解释或意义检索，而非类比应用——模型能否将谚语的抽象含义映射到新场景。

- **整体含义**：提出一种可复现的、语言无关的流水线来构建文化扎根推理基准，以更真实地评估多语言模型的文化推理能力，揭示翻译基准评估高估多语言能力的真相。

### 2. 论文提出的方法论

- **ADAGE（Analogical Difficulty-by-design Assessment for Grounded Evaluation，基于设计的类比难度评估）流水线**：包含七个阶段，全部自动化（除人类质量审计），除数据获取外均不依赖特定语言：

  1. **数据获取**：收集谚语语料，归一化并去重。
  2. **主题聚类**：三遍聚类过程——
     - Pass 1：LLM为每条谚语分配简短的英文主题标签（如"patience and perseverance"），英文标签仅作中间聚类目标，不会出现在最终基准中；
     - Pass 2：用多语言sentence-transformer嵌入标签，通过Ward凝聚聚类分组，聚类数k在[10,25]区间穷举搜索，最大化加权轮廓系数；
     - Pass 3：LLM为每簇生成描述性名称。
     - 关键设计：对主题标签而非原始谚语文本聚类，避免表面特征干扰。
  3. **场景生成**：用LLM（GPT-OSS-120B）为每条谚语生成10个候选场景——简短、现代的目标语言叙事，通过类比而非释义展现谚语含义。场景轮转10个社会领域（工作场所、家庭、邻里、友谊、商场、教育、政治、旅行、体育、科技）。生成提示词强制执行六条约束：具体性、类比而非释义、与谚语词汇分离、领域多样性、母语输出、结构化JSON格式。
  4. **自动过滤**：语言识别检查（≥70%目标文字字符）、长度约束（10–120词）、关键词重叠检查（≤30%实词重叠）、嵌入相似度检查（≤0.85余弦相似度）。过滤后由母语者进行随机抽样质量审计。
  5. **干扰项选择与MCQ组装**：核心方法是基于主题聚类的**难度设计**干扰项策略。每道题包含1个正确谚语和3个按难度梯度排列的干扰项：
     - **同簇干扰项**：与正确答案来自同一主题簇的谚语，制造主题混淆陷阱（与正确答案嵌入相似度≤0.85，排除近义词）；
     - **跨主题近似匹配**：全池中嵌入最相似的谚语（排除同簇），同样受0.85上限约束，诱捕依赖表面相似性的模型；
     - **随机簇干扰项**：来自不同簇的谚语，作为低合理性对照，建立难度基线。
     - 答案顺序用种子随机数生成器打乱以消除位置偏差。
  6. **多智能体验证**：三个开放权重LLM评审（Gemma 3 27B、Mistral Small 3.2、Aya Expanse 32B），每项按三个评分标准（场景忠实度、自然度、干扰项合理性）用1–5 Likert量表打分。任一笑度均值低于3.0或评审间分歧超过2分则标记。
  7. **数据集策展**：按谚语级别分为训练/开发/测试集（70/15/15），防止谚语-主题关联的记忆。

- **跨语言实例化**：流水线在三种类型学各异的语言上验证——阿拉伯语（Jawaher数据集，822条谚语）、阿姆哈拉语（ProverbEval，484条）、日语（Kotowaza.org，69条）。语言特定适应仅限于Unicode范围、停用词表和形态分析器（日语用Janome），其余阶段完全一致。

### 6. 论文的主要结论与发现

- **文化推理差距一致存在**：在英语谚语推理上表现良好的模型，在三种母语基准上准确率下降12–52个百分点。阿拉伯语最强模型70.1%、阿姆哈拉语41.3%（接近25%随机基线）、日语93.0%。

- **一以贯之的语言能力差异**：模型的多语言性能不是单一能力而由语言特定技能构成。Amharic上所有模型接近随机（最佳41.3%，均匀干扰项梯度、极端位置偏倚、跨模型一致性接近零），表明当前"多语言"模型在真正低资源语言上几乎没有文化扎根推理能力——翻译评估永远无法揭示这一差距。

- **规模扩展并非万能**：规模带来收益因语言而异——阿拉伯语上近乎对数线性增长，日语上收益递减，阿姆哈拉语上几乎无改善。参数数量仅在达到最低语言能力阈值后才起作用。

- **训练数据组成比规模更重要**：Aya Expanse 8B在阿拉伯语上比原版Aya 8B高9.1个百分点，收益接近Gemma家族中参数增加4倍的提升，但在Amharic上无优势。

- **干扰项策略按设计运作**：阿拉伯语和日语上，跨主题近匹配吸引最多错误，随机簇干扰项吸引最少，形成预期难度梯度；梯度随模型能力增强而明晰。Amharic上均匀分布，符合近随机表现预测。

- **错误收敛**：模型错误答案收敛到同一干扰项的程度显著高于均匀基线，表明干扰项设计系统性地暴露了LLM谚语语义表征的共享弱点。

- **翻译评估高估多语言能力**：通过翻译基准衡量的多语言推理能力被大幅高估。

### 7. 优点

- **方法论创新**：主题聚类+难度设计的干扰项策略是核心贡献，创造可控难度梯度，超越简单的主题识别测试。
- **语言无关性**：流水线各阶段处理抽象主题结构而非语言特定特征，可直接迁移到任何有谚语语料的语言。英文主题标签作为中间步骤的设计巧妙，避免暴露最终基准。
- **可复现性**：完整流水线开源发布，社区可为新语言构建基准，打破民族中心主义评估的垄断。
- **严谨验证**：跨三种类型学差异显著的语言验证（两种语系、三种文字、三种资源水平），多智能体验证+人类审计，质量标尺全面。
- **普适性**：覆盖14个模型、多模型家族、大规模跨度，提供规模扩展曲线的详细分析。
- **认识论清晰**：区分语言能力失败与推理能力失败（Amharic vs. Arabic），避免简单归因。

### 8. 不足与局限

- **测试集规模不均**：日语仅100项，限制统计功效应和主题簇覆盖（8簇中仅7簇代表），跨语言比较需谨慎解读。
- **零样本评估**：仅零样本提示，300秒超时导致Qwen 3产生少量不可解析响应（Amharic上最高3.8%，按错误计分）。少样本或思维链可能解锁额外能力，提示性能差距本身就是有价值的诊断信号。
- **仅开放权重模型**：未评估大型专有模型（GPT、Claude、Gemini等），当前前沿全貌不完整。
- **LLM生成与LLM评估依赖**：场景生成和验证均依赖LLM，人类审核仅为轻量抽查（每语言100条）。Amharic上评审可靠性较低（35.3%标记率），系统人工标注将增强信心。
- **翻译质量风险**：日语来源仅提供英文释义（无日语母语解释），测试了流水线在缺元数据时的鲁棒性但有风险。
- **英文基线可比性受限**：ePiC在格式（5 vs. 4选项）、场景来源（众包 vs. LLM生成）和人类基线（未筛MTurk工人70%）方面与CAPR不完全可比。
- **干扰项质量**：同簇干扰项的"主题相似"判定依赖LLM标签质量，存在标签噪声级联风险。
- **文化必然内容**：包含暴力、性别角色、宗教等谚语，未经净化保留以维持推理挑战，英文翻译可能产生脱离语境的不适感。
