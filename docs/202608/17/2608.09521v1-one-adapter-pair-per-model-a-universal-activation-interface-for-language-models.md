## 摘要
基于激活的工具通常与单一模型的固有隐藏空间绑定，导致每次面对新语言模型时，都需要重建或重新发现探针、稀疏自编码器和自然语言解释器。我们提出了一种通用激活总线（Universal Activation Bus），这是一个在兼容语言模型之间提供通用激活接口的框架。利用少量源模型，我们学习一个共享稠密空间，并为每个模型配备一对轻量级线性编码器-解码器适配器。源训练完成后，接口被冻结；新模型只需在未标注的匹配文本上拟合其适配器对即可加入。由此产生的接口使得基于激活的工具能够在相连模型之间共享，包括通用的探针和SAE特征，以及访问原本为不同模型训练的NLA。在五个模型上，语义相关的文本在共享空间中形成一致的邻域，并且接入的模型能够在不重新训练的情况下有效复用这些工具。我们进一步表明，一个模型的中间激活可以被另一个模型的冻结上层用于产生预测。这些结果为跨兼容语言模型的可复用工具建立了一种稳定的、模型层面的激活契约。

## Abstract
Activation-based tools are usually tied to one model's native hidden space, requiring probes, sparse autoencoders, and natural-language interpreters to be rebuilt or rediscovered for each new language model. We present a Universal Activation Bus, a framework that provides a common activation interface across compatible language models. Using a small set of source models, we learn a shared dense space together with one lightweight linear encoder--decoder adapter pair per model. After source training, the interface is frozen; a new model joins by fitting only its adapter pair on unlabeled matched text. The resulting interface allows activation-based tools to be shared across connected models, including common probes and SAE features as well as access to an NLA originally trained for a different model. Across five models, semantically related texts form consistent neighborhoods in the shared space, and an onboarded model reuses these tools effectively without retraining them. We further show that an intermediate activation from one model can be used by another model's frozen upper layers to produce predictions. These results establish a stable, model-wise activation contract for reusable tools across compatible language models.

## 2. 方法论

### 2.1 总体架构

每个模型 m 有一个编码器 E_m 和一个解码器 D_m，将模型的原生激活空间映射到共享空间 Z（维度 D=3072），再映射回去。共享空间由两个小型残差 MLP（Φ_in 和 Φ_out）组织，模型特有部分为线性适配器 A_enc_m 和 A_dec_m。

### 2.2 关键技术细节

1. **跨分词器匹配激活**：由于不同模型的分词器不同，论文通过选取所有源模型共享的字节级前缀端点，确保同一文本前缀在各模型中对应同一最终 token 位置的激活。
2. **归一化激活统计**：每个模型先做逐维度 z-score 标准化，再施加正则化 ZCA 白化变换（W_m），以平衡坐标尺度并减小维度间相关性。统计量一次性估计后冻结。
3. **完整编解码定义**：
   - E_m(h) = Φ_in(A_enc_m(N_m(h)))
   - D_m(z) = N_m⁻¹(A_dec_m(Φ_out(z)))
   - 交叉路径 D_n(E_m(h_m(x))) 可将模型 m 的状态翻译给模型 n，无需成对的特定连接器。
4. **训练目标**（三项损失相加）：
   - 自重建损失 L_self（保证原生信息保留）
   - 交叉重建损失 L_cross（保证模型 n 可读取模型 m 写入的表示）
   - 对比对齐损失 L_nce（InfoNCE，以匹配前缀为正样本、批内其他为负样本，防止表示坍缩）
5. **新模型接入（Onboarding）**：冻结源接口后，新模型 u 只需优化自己的 A_enc_u 和 A_dec_u，损失为自重建 + 与源模型共识表示 c(x) 的 L2 对齐。无需任何成对连接器。
6. **接口操作**：
   - 共享空间工具 Q：直接应用于任何已连接模型的共享状态 Q(E_m(h_m(x)))（如探针、共享 SAE）
   - 载体特定工具 Q_c：通过解码器翻译到载体模型的原生空间后再应用（如 NLA）

## 3. 实验设计

## 6. 主要结论与发现

1. **共享激活接口是可行的**：跨五个异质模型，语义相关的文本在共享空间中形成一致的邻域，ID 检索 R@1 ≥ 99.5%，OOD 检索 R@10 达 79.6–90.8%；行为轴方向在共享空间中按语义聚类，且不同模型间同一轴的余弦相似度高达 0.815。
2. **冻结接口可扩展**：新模型仅通过训练自己的适配器对即可接入，现有坐标和路径保持稳定；且 1 万条校准位置就可使 R@1 饱和至 99.6%（默认 10 万条），无需重训练。
3. **工具可跨模型复用**：共享探针（OLMo 9 路准确率 95.4%、宏 AUROC 0.959，与原生探针相当）、单一 SAE 字典（OLMo 特征重叠 0.602–0.613）、以及跨载体 NLA（源模型路由后分类准确率 84.9–94.4%）均无需修改即可适用于已接入模型。
4. **跨模型状态执行有效**：翻译后的中间激活可被另一模型的冻结上层消费，组合模型在 72.4–87.7% 的下一 token 上follow接收模型（B），超出原生 A–B 一致率 7.5–27.2 个百分点，同时保留前缀语义信息。
5. **兼容性存在边界**：模型宽度超过共享维度（如 OLMo 4096 > D=3072）时，重建保真度显著下降（self-FVE 0.734），但检索对齐仍保持良好。

## 7. 优点

1. **模型级接口设计**：每个模型只配备一对适配器，代替了成对连接器；任意两个已连接模型之间都自动获得可逆翻译路径，可扩展性远超此前方法。
2. **向后兼容性**：接口冻结后新模型接入不影响已有坐标、路径和工具，这使工具生态可以增量扩展，是一个很实际的工程创新。
3. **统一的工具契约**：同时支持"训练在共享空间中的工具"（探针、SAE）和"保留在载体模型空间的工具"（NLA）两种复用形式，覆盖面广泛。
4. **验证充分**：从表示质量（检索、保真度）→ 工具复用 → 跨模型执行，形成相对完整的技术验证链条。
5. **适配器极轻量**：每个模型新增参数量约 12–25M，且训练不需要标注数据（只使用匹配前缀的激活），接入成本极低。
6. **跨尺度/变体的泛化验证**：1.24B 至 14.8B 的检查点均能以 99.9%+ 的 ID R@1 接入接口，且 9/9 行为轴分配正确。

## 8. 不足与局限

1. **适用范围有限**：论文明确承认并非所有模型都满足对齐契约，模型筛选环节淘汰了 Phi-3.5、Gemma-3、Mistral-7B 等模型；"兼容模型"这一前提条件限定了通用性结论的适用范围。
2. **重建保真度有时受限于共享维度**：OLMo 的 self-FVE 仅 0.734，远低于其他模型的 0.98+；Qwen3-14B 的 self-FVE 仅 0.591，说明宽模型在固定 D=3072 的压缩损失显著，论文未深入探讨维度自适应策略。
3. **缺少部分消融细节**：如各损失项（L_self/L_cross/L_nce）的独立贡献分析未展示；共享 MLP（Φ_in/Φ_out）的结构选择（为什么是 2 层而非更深/更浅）未做敏感性分析。
4. **NLA 路由存在信息损耗**：跨模型路由后 NLA 分类的绝对准确率低于原生载体，且 OLMo 在情感轴上的召回率骤降至 6%，说明部分行为信号在翻译过程中丢失，论文对此的解释不算充分。
5. **SAE 功能性下降**：共享 SAE 的 ΔCE 明显高于各自原生训练 SAE（0.189–0.398 vs 0.061–0.128），虽然效用保留率相对高，但绝对性能差距说明共享字典仍有优化空间。
6. **没有披露算力**：GPU 型号、训练时长等未说明，其他研究者难以估计复现成本。
7. **上游筛选偏差**：模型选择基于与 Llama-3.2-3B 的线性映射过滤，这使"通用性"结论在某种程度上受限于筛选标准的偏见（以参考模型为中心）。
8. **跨模型执行仅测试了"匹配上下文"场景**：只替换最终位置状态，未做完整序列的模型拼接，实验场景相对受限。
