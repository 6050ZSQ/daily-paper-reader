## 摘要
随着大型语言模型（LLM）越来越多地被部署为自主代理，准确评估其潜在价值观和偏见变得至关重要。NLP社区通常使用大型非结构化基准来评估模型。虽然这些基准对于一般能力有效，但它们在根本上混淆了因果机制：即使检测到聚合偏差，非结构化评估也无法厘清它源于基线特征、上下文混淆因素还是复杂交互。为了解决这一问题，我们引入了一个分析上精确的框架，用于对LLM进行受控行为评估。我们通过弥合设计、测量和分析方面的空白，将人类心理测量学与LLM机制联系起来。首先，我们用完全交叉的因子实验取代非结构化提示，以系统地隔离因果主效应和交互效应。其次，我们直接基于精确的、词级概率质量函数（PMF）进行操作，消除了蒙特卡洛文本采样噪声。第三，我们推导出一个多变量有序共识指标和一个分布方差分析，以分析方式处理这些PMF。我们通过对五个LLM的消费者民族中心主义案例研究验证了我们的框架，展示了我们的方法如何隔离出聚合基准原本掩盖的系统性原产国偏见。

## Abstract
As Large Language Models (LLMs) are increasingly deployed as autonomous agents, accurately evaluating their latent values and biases is critical. The NLP community typically evaluates models using large, unstructured benchmarks. While effective for general capabilities, these datasets fundamentally conflate causal mechanisms: even when an aggregate bias is detected, unstructured evaluations cannot disentangle whether it stems from baseline traits, contextual confounders, or complex interactions. To address this, we introduce an analytically exact framework for the controlled behavioral evaluation of LLMs. We bridge human psychometrics with LLM mechanics by resolving gaps in design, measurement, and analysis. First, we replace unstructured prompting with fully crossed factorial experiments to systematically isolate causal main and interaction effects. Second, we eliminate Monte Carlo text sampling noise by operating directly on exact, token-level Probability Mass Functions (PMFs). Third, we derive a multivariate ordinal consensus metric and a distributional ANOVA to process these PMFs analytically. We validate our framework with a case study on consumer ethnocentrism across five LLMs, demonstrating how our approach isolates systemic country-of-origin biases that aggregate benchmarks otherwise obscure.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式与流程

论文提出一个三层分析管线（对应三个方法论缺口）：

### （1）设计层：完全交叉因子实验（解决"设计缺口"）

- 将 LLM 评估构建为完全交叉的固定效应因子实验设计。每个独立变量（如被测模型、提示词中的目标国家）都作为一个因子，每个因子包含若干水平。
- 实验条件 λ 代表一个具体的因子水平组合（如 MODEL=Llama-3.3, TARGET=Canada）。
- 通过穷举所有组合，可在数学上隔离单个变量的效应，同时控制其他变量。
- 使用经过验证的心理测量学量表（如 CETSCALE）作为测量工具，保持提示词模板固定，确保构造效度。
- 关键性质：LLM 的各条目（item）之间具有"无状态性"（无 carry-over 效应），且给定条件 λ 下各条目条件独立，联合 PMF 可精确分解为条目 PMF 的乘积。

### （2）测量层：直接使用精确 token 概率（解决"测量缺口"）

- 传统 NLP 评估通过蒙特卡洛文本采样（配合温度参数）模拟"回答总体"，这会注入额外噪声。而 LLM 对给定提示具有确定性的内部状态。
- 作者直接获取下一个 token 的精确概率质量函数（PMF），完全绕开自回归解码和采样参数（温度、top-p 等在此框架中无关紧要）。
- 约束层：定义有效 token 集合 Vval（如数字 1-7），通过满射映射 φ 将有效 token 映射到有序李克特值；通过失败率（failure rate）量化模型偏离格式的程度，并在后续分析中将 PMF 在有效集合上重新归一化。

### （3）分析层：分布级统计工具

- **多元共识指标（Multivariate Consensus）**：传统 Shannon 熵忽略有序性，无法区分"两极分化于 1 和 7"与"集中在中性 3"这两种分布。作者基于 Tastle 和 Wierman 的 Consensus 指标提出多元拓展，公式为：
  `Cns(Yλ) = 1 + Σ_y P(y) log2(1 - ||y - μ||₂/dmax)`
  其中 dmax = √K(ymax - ymin) 为李克特超立方体的最大对角线距离。该指标对极端极化严重惩罚，对集中分布给予高分。
- **构造层（Construct）**：将条目级 PMF 通过离散卷积合成复合得分分布 PSλ = PY1,λ ⊛ ... ⊛ PYK,λ。
- **分布级 Hoeffding 分解（分布 ANOVA）**：
  - 通过"最优传输配对对比"（comonotone 耦合/共同分位数耦合）构造主效应分布 Ec(λc) 和交互效应分布 EU(λU)。
  - 定理 3.1 保证这些效应分布的期望值精确对应经典 ANOVA 固定效应参数（Hoeffding 分解的唯一性）。
  - 关键区分：作者使用**配对对比**（如 S(λc,λ−c) ⊖ S0|λ−c）而非卷积相减，避免了将被比较分布视为独立所导致的方差膨胀。
  - 摘要统计量：均值偏移 E[E]、预测离散度 SD(E)、离散方向概率 dPD、信噪比 SNR = |E|/SD(E)。
- **趋势效应**：对有序因子（如模型参数量）计算相邻水平间的配对有限差分分布，并加权聚合为每单位趋势分布。

## 6. 论文的主要结论与发现

### （1）约束层（格式遵守）

- Gemma 3、Llama 3.3、Qwen3 对数字约束的遵守近乎完美（失败率 < 0.001）。
- Aya Expanse 失败率最高（M=0.006，SD=0.049），方差极大，表明在 agentic 场景中可能出现零星的格式崩溃。

### （2）共识层（内部一致性）

- 四个模型共识值 Cns > 0.88，显示出较高的内部一致性。
- **Ministral 14B 是明显异常值**（Cns ≈ 0.65-0.67），即使在强制有效数字后，其条目级 PMF 经常在同一李克特尺度的两端放置大量概率质量。标准熵无法捕捉这种行为的失调（熵在"1/7 极化"与"3/5 集中"两种分布上给出相同值），而 Consensus 指标能有效区分。

### （3）构造层（民族中心主义水平）

- 与人类历史基线对比：Aya Expanse 的期望得分为 89.11，超过人类样本中民族中心主义最强的底特律样本（68.58）；Llama 3.3 为 71.99，也接近这一水平；Qwen3 得分为 53.85，接近较开放的人类样本（如学生组 51.92-53.39）。
- **模型主效应**：Aya Expanse 表现出极强的正向民族中心主义（E=21.19, SNR=1.63, dPD>0.99）；Qwen3 Next 表现出显著的负向效应（E=-14.63, SNR=1.20, dPD=0.93）。
- **目标国主效应**：对所有模型整体而言，涉及中国时民族中心主义显著下降（E=-6.46），而北美目标国相对受偏袒（加美对比 E=11.08, SNR=1.46, dPD=1.00）。

### （4）交互效应与原产国偏见

- 美国开发的模型（Gemma 3、Llama 3.3）表现出正向的"本国（美国）"交互效应（+3.21 和 +2.59），且对北美区块偏正面、对中国偏负面。
- **并非所有模型都呈现本国偏袒**：Aya Expanse（加拿大）的本国交互为负（-3.77），Qwen3（中国）的本国交互接近零（-0.20）。这证明了框架能够区分"存在、缺失或反转"的原产国偏见。
- **聚合 vs 因子分解的对比**：聚合基准会得出"所有模型都普遍反对中国"的结论，但因子分解显示 Aya（+5.35）和 Ministral（+4.54）对中国的交互效应为正；聚合基准认为存在普遍的法国负偏见，但 Ministral 对法国实际表现出正面的同国偏袒（+2.45）。**聚合方法的结论在具体模型的交互层面是方向性错误的**。

### （5）采样成本量化

- **采样噪声**：N=100 时，采样标准误最高可达 0.52 复合得分点（对低共识模型）；小效应（|E|<1）在 N=10 时有 18% 的概率符号翻转，N=100 时仍有 6.3%。
- **解码偏差**：非默认温度/top-p 设置会给低共识模型（Ministral）引入高达 2.79 点的系统性偏移，且该偏差与共识值显著负相关（r=-0.85）。

### （6）提示敏感性

- TARGET 主效应在控制提示框架后仍复现主研究的方向性模式，核心信号鲁棒。
- 提示框架本身是一个因果主效应，可移动潜在构造得分最多 13.5 点。
- 模型间提示敏感性差异显著：Gemma 3 对措辞变化低敏感，Aya 和 Ministral 与特定框架交互强烈。

## 7. 优点

- **因果归因能力突出**：通过完全交叉因子实验与分布级 ANOVA 分解，能够将基线特质、主效应和交互效应从数学上分离，解决了非结构化基准无法回"为什么偏"的问题。
- **确定性测量**：直接利用精确 token 级 PMF 消除了采样噪声（达到 N→∞ 的极限效果只需一次前向传播），彻底避免了温度/top-p 等生成超参数引入的偏差。
- **数学严谨性完备**：定理 3.1 及其附录证明（期望级 Hoeffding 分解唯一性、主效应与交互效应的 sum-to-zero 约束、Möbius 反演形式等）保证了分布级方法在期望层面与经典 ANOVA 参数严格一致。
- **配对对比的巧妙设计**：采用 comonotone 耦合（最优传输）而非卷积相减来计算效应分布，避免了将相关分布错误视为独立的方差膨胀问题。
- **序数感知的一致性指标**：多元 Consensus 正确识别了 Shannon 熵在有序李克特尺度上的关键失效模式（无法区分极化与集中），为序数心理测量数据的可靠评估补上了空白。
- **框架可扩展性强**：任何潜在混淆变量（如提示框架）都可以被提升为实验因子，通过相同的分布 ANOVA 管线进行隔离和量化，将"提示敏感性问题"转化为可测量、可隔离的效应。
- **实证验证充分**：通过聚合 vs 因子分解对比明确展示了两种方法在结论方向上的关键分歧，有力论证了方法的必要性。

## 8. 不足与局限

- **构造覆盖单一**：实证仅聚焦消费者民族中心主义一个构造，未覆盖人格特质、道德价值观、政治意识形态等更广的行为维度，作者在"Limitations"中明确承认该局限。
- **语言覆盖不足**：所有实验仅使用英语。当模型以其他语言或脚本查询时，观察到的系统性偏见是否成立仍是开放的实证问题。
- **模型范围有限**：实验仅覆盖 5 个模型的一个快照版本；结论不一定推广到未来权重更新或后续模型版本。
- **单 token 响应范式的前提约束**：框架明确设计用于受限的单 token 响应范式（如李克特数字），对使用思维链（CoT）多 token 推理协议后再生成最终答案的模型，无法直接扩展。此外，完全隐藏 log-probability 的 API 提供商不在适用范围内。
- **构造效度问题**：即使使用经过验证的心理测量工具，将人类设计的问卷直接迁移到 LLM 上仍存在生态效度问题。提示词模板被严格固定（相当于标准化测量工具），这在方法论上是合理的，但也意味着不考虑模型对措辞的天然偏好差异。
- **对比基准为历史数据**：与人类数据的对比来自 1987 年之前收集的样本，作者明确说明这仅是"历史幅度锚点"，不反映现代人类态度；但读者需警惕不适当地将这一对比解释为"LLM 比人类更偏"的证据。
- **关于最小效应为统计显著性的问题**：论文明确拒斥基于 p 值的零假设显著性检验，采用 dPD/SNR 等分布摘要指标。尽管数学上合理，但缺乏传统显著性测试可能使得结论的统计可读性对非该领域研究者有所降低。
- **道德风险**：作者在伦理声明中提醒，直接针对这些指标优化可能使模型在得分上"表现良好"而并未真正减少底层偏见（即"指标游戏"风险）。
