## 摘要
专有大型语言模型（LLMs）只能通过封闭API访问，其广泛采用给负责任部署带来了关键挑战：根本缺乏可解释性。为解决这一问题，我们提出了一种与模型无关、事后归因的句子级解释器。我们的方法训练一个基于能量的模型（EBM）作为代理，以捕捉LLM在提示与响应之间的内部概念一致性。该能量景观指导一个轻量级解释器网络的训练。特别地，我们的解释器作为独立工具运行；一旦训练完成，它即可量化提示句子对用户指定目标输出的影响，而无需再向LLM发起API查询。通过跨多样输入全局训练一个局部解释器，我们的框架捕获更广泛的生成模式并减轻实例特定偏差。实验表明，我们的EBM准确模拟目标LLM，使解释器能够有效识别对生成特定目标输出最有影响的提示句子。

## Abstract
The widespread adoption of proprietary Large Language Models (LLMs) accessed strictly through closed APIs has created a critical challenge for responsible deployment: a fundamental lack of interpretability. To address this, we propose a model-agnostic, post-hoc attribution interpreter operating at the sentence level. Our approach trains an Energy-Based Model (EBM) as a surrogate to capture the LLM's internal conceptual consistency between prompts and responses. This energy landscape guides the training of a lightweight interpreter network. Uniquely, our interpreter operates as a standalone tool; once trained, it quantifies the influence of prompt sentences on a user-specified target output without requiring further API queries to the LLM. By globally training a local interpreter across diverse inputs, our framework captures broader generation patterns and mitigates instance-specific biases. Experiments demonstrate that our EBM accurately simulates the target LLM, allowing the interpreter to effectively identify the prompt sentences most influential in generating specific target outputs.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：当前最强大的 LLM（如 GPT-4o-Mini）多为专有系统，仅通过封闭 API 提供黑盒访问，内部计算机制完全不可见。这种不透明性在医疗、法律等高风险领域构成严重障碍，专家无法验证输出是否符合领域知识或发现隐藏偏见。
- **现有方法不足**：
  - 白盒方法（梯度、注意力权重、激活）依赖内部访问，与封闭 API 不兼容；
  - 注意力权重作为解释代理已被证明不可靠（Jain & Wallace, 2019）；
  - 通用模型无关方法（LIME、SHAP）主要面向判别式模型，对生成式模型的高维输出难以有效适配，且计算成本高昂；
  - 提示词自解释（如 CoT）依赖待验证的同一过程，存在循环论证和事后合理化风险（Turpin et al., 2023）。
- **核心主张**：将归因分析的粒度从含噪的 token 提升到完整的句子（定义为“概念”），通过训练能量模型（EBM）作为黑盒 LLM 的可微分代理，进而在句子层面实现模型无关、无需内部访问的事后归因解释。

## 2. 论文提出的方法论：核心思想、关键技术细节与流程

- **整体框架（两阶段）**：
  1. **阶段一**：预训练一个基于 Transformer 的 EBM 作为目标 LLM 的代理（surrogate）。EBM 学习一个标量能量函数，用于评估提示 (x) 与响应 (y) 的概念级兼容性——低能量代表与目标 LLM 的生成模式一致。
  2. **阶段二**：利用该能量景观作为监督信号，训练一个轻量级解释器网络 IN(x, yT; α)，输入为提示、响应与用户指定的目标输出子集 yT（如某个响应句子），输出一个二值重要性向量，标识对生成 yT 最关键的提示句子子集 xS。
- **句子级“概念”定义**：采用命题性定义（Frege 的语境原则与 Kintsch 的完整思想理论），句子是表达完整命题的最小语言单元，比 token 更稳健、更符合人类理解。
- **EBM 架构（三个阶段）**：
  1. **概念空间投影**：用冻结的 Sentence-BERT（all-mpnet-base-v2）将提示/响应的句子映射为嵌入序列，再通过可训练的自注意力模块投影到动态“概念空间”（Cin, Cout），使距离反映 LLM 内部的依赖结构而非通用语义相似度。
  2. **输入-输出交互**：交叉注意力模块使输入概念（Cin）关注输出概念（Cout），学习提示对响应的因果影响。
  3. **能量计算**：通过注意力池化 + MLP 输出标量能量 E(x, y; θ)。
- **EBM 训练目标（双目标对比学习）**：
  - **保真度目标（Lfidelity）**：InfoNCE 损失，以人类回答或其他 LM 的生成作为负样本，捕捉目标 LLM 的全局生成风格与分布特征；
  - **局部依赖目标（Ldep）**：包含两个批内采样器——（1）Lresp-dep 区分正确局部响应与离题局部响应；（2）Lpmt-dep 区分正确局部提示与错误提示；
  - **总损失**：Ltotal = (1−λ)·Lfidelity + λ·Ldep，实验中最优配置为 λ = 0.9（MHybrid）。
- **解释器训练与优化**：
  - 解释器架构镜像 EBM：相同嵌入 → 概念投影 → 仅保留目标概念 yT 的交叉注意力 → MLP + Gumbel-Softmax 输出稀疏二值掩码；
  - **目标函数**：最大化选中子集的能量差——即最小化 E(x̃, yT)（选中子集导致低能量）同时最大化 E(x−x̃, yT)（清除子集导致高能量）；
  - **交替优化**：定期用当前掩码生成的提示子集重新查询目标 LLM，获取新的 (x̃, ỹ) 对并微调 EBM，以缓解掩码导致的分布偏移。该步骤虽产生 API 成本，但在标准 benchmark 上可略过。

## 6. 论文的主要结论与发现

- **EBM 消融**：
  - 仅靠全局保真度（MFidelity）导致依赖表面伪相关的能量景观（R1E 高达 85.1%，SNR 仅 1.45）；
  - 仅靠局部依赖（MDep）产生过度的判别力（Accuracy 84.16%），但潜在空间过分抽象，导致下游解释器训练崩溃；

- **归因合理性**：ESCI 与 GPT-J-6B 和 Gemini-2.5-Flash 高度对齐（场景 B 中 Soft Top-1 分别为 0.97 和 0.83），表明能量景观有效内化了自回归生成机制；ESCI 输出稀疏、自信的分数，与指令调优 oracle 的弥散分布形成对比。
- **因果忠实性**：ESCI（Gap=0.195）接近 LIME（0.245）但推理成本为 O(1) 且零 API 调用，优于 GPT-4o-Mini（0.192）和 GPT-4o（0.175）；随机基线为负值（−0.146），确认指标有效。
- **效率结论**：一次性预训练（约 20K 查询）的 API 成本在**约 400 个提示**处即达到收支平衡，之后无限扩展无需额外 API 调用，表明能量景观以远小编码器捕获了目标 LLM 的因果机制。

## 7. 优点

- **模型无关与黑盒友好**：无需梯度、激活或注意力权重等内部访问，推理阶段零 API 查询，可直接应用于任何封闭 LLM。
- **句子级概念粒度**：将解释单位从含噪 token 提升到句子，更符合人类认知，也更好地对应生成背后的“命题逻辑”，直观且易于验证。
- **全局训练缓解局部偏差**：不同于 LIME 等局部解释器（易受局部近似扰动影响），全局训练使解释器捕获跨样本的生成模式，缓解实例特定偏差。
- **EBM 的独特建模视角**：将生成问题从局部概率建模（自回归）转向整体一致性评估（能量），避免了对词汇海量空间做归一化的不可行性。
- **双目标消融设计严谨**：通过保真度 + 局部依赖的加权组合，验证了代理模型必须同时“像目标 LLM”与“精确追踪局部因果”的核心假设。
- **高效可扩展架构**：ESCI 与 LIME 效果接近，但推理零额外 API 成本，为大规模持续部署提供了可行路径——是解释方法与计算效率之间的 Pareto 最优。
- **避免了循环论证**：不使用 LLM 的自我解释，而用独立 EBM 代理 + 干预式验证，回避 CoT 事后合理化的核心局限。

## 8. 不足与局限

- **训练期开销高**：预训练 EBM 需 25 小时/任务（T4 × 2），且是任务导向型——每个任务需要单独训练替代模型与繁重的超参数搜索，通用性和开箱即用性受限。
- **黑盒验证缺乏机械性基准**：伦理上只能依赖概率性 oracle（如 GPT-4o）而非确定性真值；高 oracle 对齐度不能保证与目标 LLM 真实内部计算路径的机械对齐，目前仅属行为模拟。未来需用开放权重模型（Llama 3、Pythia）对照白盒信号（IG、注意力图）进行验证。
- **实验覆盖单一**：仅覆盖标准 Q&A（HC3），未扩展至复杂推理、开放式生成、超长上下文（128k+ tokens）；且仅验证了 GPT 家族 + 紧凑 EBM，规模规律不明。

- **人类效用未验证**：缺乏严格受试者研究，尚无法确认因果准确性自动等于人类可理解性和实用性（如幻觉检测、偏见识别等下游审计任务）。默认假设“给最小必要子集即最佳解释”尚需认知层面的验证。
