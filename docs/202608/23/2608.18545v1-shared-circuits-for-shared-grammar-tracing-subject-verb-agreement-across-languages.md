## 摘要
多语言大型语言模型常常能跨语言泛化，且先前的研究表明其内部机制可能具有跨语言重叠性。然而，这种共享何时出现，以及它是否随同一语法操作的外显实现而变化，仍不清楚。我们针对现在时主谓一致这一跨语言差异显著、在英语中表达较弱的形态句法过程展开研究。通过跨29种语言和五个开源模型家族的激活修补与注意力分析，我们识别了与主谓一致有因果关联的注意力头，并比较了这些基于头的跨语言特征。我们发现，具有显性人称/数屈折的语言比不进行变位语言表现出更相似的一致回路，且当分析聚焦于屈折对比恢复本身时，共享性最强。英语提供了一个具有信息性的桥梁案例：在需要显性一致的语境中，它变得更加接近变位语言。最后，许多相关注意力头在跨语言中表现出相似的模式，这表明跨语言重叠既反映了共享的功能角色，也反映了共享的定位。综合来看，这些结果表明多语言LLM在形态句法一致上重用了部分共享的计算结构，而非依赖于完全分离的语言特定解决方案。

## Abstract
Multilingual large language models often generalize across languages, and prior work suggests that their internal mechanisms can overlap cross-lingually. It remains unclear, however, when such sharing emerges and whether it varies with the overt realization of the same grammatical operation. We investigate this question for present-tense subject-verb agreement, a morphosyntactic process that varies substantially across languages and is only weakly expressed in English. Using activation patching and attention analysis across 29 languages and five open-source model families, we identify the attention heads causally implicated in agreement and compare these head-level signatures across languages. We find that languages with overt person/number inflection exhibit more similar agreement circuitry than non-conjugating languages, with the strongest sharing appearing when the analysis isolates recovery of the inflectional contrast itself. English provides an informative bridge case, becoming more similar to conjugating languages precisely in contexts where overt agreement is required. Finally, many implicated heads display similar attention patterns across languages, suggesting that cross-lingual overlap reflects shared functional roles as well as shared localization. Together, these results indicate that multilingual LLMs reuse partially shared computational structure for morphosyntactic agreement rather than relying on fully separate language-specific solutions.

## 论文总结：共享语法中的共享回路——跨语言追踪主谓一致

### 1. 核心问题与研究动机

- **背景**：多语言大型语言模型（Multilingual LLM）在多种语言上都能表现出良好的泛化能力，但其内部计算机制在跨语言时究竟是共享的还是语言特异的，这一问题尚不明确。
- **核心问题**：当多语言模型处理跨语言、跨类型的同一形态句法现象（此处为主谓一致）时，它们使用的是共享的内部电路，还是各自独立的语言特定解决方案？更进一步，这种共享的出现是否取决于该语法操作在某一语言中是否以显性（overt）形态实现？
- **研究意义**：如果同一计算由共享电路实现，那么可解释性发现、因果干预与对齐方法就可能跨语言迁移；反之，则在某一语言中开发的分析工具可能无法适用于其他语言。该问题对形态学与句法领域尤为关键，因为语言间的差异可能无法直接映射到一个统一的语言无关内部表征上——尤其是当某个高资源语言（如英语）本身缺乏相关语法特征时。
- **研究切入点**：选择**现在时主谓一致**作为测试案例，因为其在不同语言中的显性实现差异极大：许多语言有显性的人称/数屈折，中文等语言完全没有该屈折，而英语只部分标记（仅第三人称单数）。

### 2. 方法论

- **核心方法**：结合**注意力输出修补（attention-output patching）** 与**注意力模式分析（attention analysis）**，对主谓一致的内部神经电路进行因果层面的定位与刻画。
- **最小对比对（Minimal pairs）**：
  - 为每个语言构造干净提示（clean prompt）与损坏提示（corrupted prompt），二者仅主语代词不同，目标屈折形式也只差最终 token。
  - 测试四类人称/数对比：1sg↔2sg、1sg↔3sg、1pl↔3pl、3sg↔3pl；英语在其中两组（1sg↔3sg、3sg↔3pl）有屈折变化。
- **头级修补（Head-level patching）**：在后向传播（损坏提示）中，将特定层 ℓ 的注意力头 h 在前向传播（干净提示）中缓存的输出替换到对应序列位置，观察最终层 logit 的变化，从而定位因果重要的注意力头。
- **两种恢复度量（Recovery Metrics）**：
  - **目标 logit 恢复（Target-logit recovery）**：衡量修补后干净目标 token logit 相对于损坏基线的提升幅度：
    \[
    M_{\text{target}}(\ell,h) = \frac{1}{n}\sum_{i=1}^n \left[ L_{\text{patch}}^{(\ell,h,i)}_{y_{\text{clean}}^{(i)}} - L_{\text{corr}}^{(i)}_{y_{\text{clean}}^{(i)}} \right]
    \]
    该指标不要求两个不同屈折形式之间存在对比，因此可同时适用于变位语言与非变位语言，捕捉“上下文合适的目标形式恢复”。
  - **最小对比对恢复（Minimal-pair recovery）**：衡量修补后在干净形式与损坏形式之间恢复 logit 对比的程度：
    \[
    M_{\text{pair}}(\ell,h) = \frac{\Delta(L_{\text{patch}}^{(\ell,h)}) - \Delta_{\text{corr}}}{\Delta_{\text{clean}} - \Delta_{\text{corr}} + \epsilon}
    \]
    其中 \(\Delta(L) = L_{y_{\text{clean}}} - L_{y_{\text{corr}}}\)。该指标仅适用于干净/损坏提示具有不同最终屈折 token 的情况，是对屈折对比本身恢复的精确测度。
- **跨语言比较**：将每对语言在相同模型、相同变位对比、相同修补方向下的层-头热力图展开为向量，计算**Pearson 相关系数**（主分析中使用绝对值热力图），以衡量不同语言在电路定位层面的相似性。
- **注意力角色分析（Attention-role analysis）**：对每个语言对中重叠的前 k=20 个头，度量最终前缀位置注意力分配到主语代词、不定式片段和其他 token 的比例，用于比较跨语言共享头的功能角色是否一致。
- **模型选择**：BLOOM、Gemma、Llama、Mistral、Qwen 共 6 个检查点、5 个模型家族。

### 3. 实验设计

- **数据集**：
  - 动词词库源自 **UniMorph 4.0**（覆盖 33 种语言的动词原形及现在时屈折形式）和**中文动词语义特征数据集（CVFD）**（获取中文动词词元）。
  - 初始词库覆盖 34 种语言；经过 tokenization 过滤和行为过滤后，**29 种语言**进入主分析，包括 24 种显性一致语言、4 种非变位语言，以及英语作为中间案例。
- **Prompt 模板**：各语言采用统一的零样本模板，如“Conjugation of the verb [infinitive] in present tense: [pronoun] [conjugation]”，并翻译为各语言。模板保持位置对齐，以支持受控激活修补。
- **过滤条件**：
  - **Tokenization 过滤**：仅保留干净/损坏形式只在最终 token 不同的动词，以确保对比隔离在模型要预测的 token 上。
  - **行为过滤**：仅保留模型能成功产出正确屈折形式的样本，使分析聚焦于成功的一致计算电路而非错误行为。
- **Benchmark/对比方法**：该工作没有与之前的方法进行直接“基准测试”式对比，而是与文献中的跨语言电路研究（如 Mueller et al., 2022; Ferrando & Costa-jussà, 2024; Zhang et al., 2025）在方法上对比，差异化体现在三点：严格控制的多语言最小对比对、更广泛的类型学语言覆盖、两种互补恢复指标。

### 6. 主要结论与发现

1. **变位电路跨语言部分共享**：在具有显性主谓一致的语言之间，激活修补识别出的注意力头具有显著的重叠，且这一相似性广泛分布在所有语言对中，而非仅集中于少数近缘语言。
2. **共享在屈折特异性恢复指标下最强**：最小对比对恢复指标的跨语言相似性显著高于目标 logit 恢复指标，说明模型在恢复“屈折对比本身”时电路共享最强烈；而更宽泛的目标形式恢复则引入了更多语言特定差异。
3. **共享电路追踪共享的语法结构**：几乎没有基于人称的动词屈折的语言（如中文、瑞典语、丹麦语、挪威语）与变位语言在头级特征上相似度明显更低。英语则作为桥梁案例：整体上不同于强变位语言，但其**第三人称单数语境**下与变位语言的相似性显著高于非屈折语境（所有 6 个模型中一致成立）。
4. **共享头具有相似的功能角色**：跨语言重叠的 top-20 头不仅定位相似，其注意力角色向量也高度一致（平均相似度约 0.93），说明共享不仅体现在“哪里”，也体现在“做什么”——即相似的信息路由功能。
5. **总体结论**：多语言 LLM 对主谓一致采用**部分共享的计算结构**，而非完全分离的语言特定方案；共享程度由是否执行相同的显性语法操作驱动，而非单纯由语言身份驱动。

### 7. 优点

- **因果方法**：使用激活修补而非纯相关性分析，能定位对任务有因果贡献的特定头。
- **严格受控的最小对比对**：通过 tokenization 过滤将屈折对比隔离到单个最终 token，极大减少混淆因素，提升因果推断的可信度。
- **双指标设计**：区分“上下文目标形式恢复”（较宽泛）和“屈折对比恢复”（较精确），揭示共享程度的层级性，具有方法论上的创新性。
- **类型学覆盖广**：29 种语言包含丰富屈折、部分屈折、无屈折三种类型，英语作为天然的准自然实验，极大增强了结论的外部有效性。
- **多模型验证**：5 个不同模型家族的结果一致性表明结论不是单个架构的伪影。
- **丰富的辅助分析**：模型规模、指令微调、预训练动态、相似度度量选择等多维度稳健性检验，使结论更加可靠。

### 8. 不足与局限

- **仅关注注意力头**：分析刻画的是基于注意力的信息路由组件，未覆盖完整计算图——位置级 MLP 在下游读取、变换或放大信号中的作用可能被忽略。
- **非自然主义提示**：使用结构化变位提示而非自然句子，识别出的电路特征可能无法完全推广到自然语言语境中的一致处理。
- **单一语法现象**：仅研究主谓一致，其他形态句法现象（格、性、时态等）的跨语言电路共享模式可能不同。
- **行为过滤引入偏差**：剔除了模型无法正确产出目标形式的样本，因此分析反映的是“成功一致行为”的电路而非整体语言能力，可能高估共享程度。
- **跨架构不可比较**：不在不同模型家族间直接比较头部坐标或激活值，跨语言相似性仅在模型内部计算，限制了跨架构泛化性推断。
- **算力与可复现性信息缺失**：未提供 GPU 配置等硬件细节，其他研究者复现实验的成本较高。
- **英语桥接效应基于有限对比**：英语仅在两组对比中有屈折变化，支持“语境驱动共享”的证据虽然方向一致，但基于的形态对比相对有限。
