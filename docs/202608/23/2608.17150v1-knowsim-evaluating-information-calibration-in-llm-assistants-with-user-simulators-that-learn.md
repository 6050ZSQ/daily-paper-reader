## 摘要
为了在知识密集型任务上与用户有效协作，大型语言模型（LLM）必须进行信息校准：将内容与用户不断变化的理解和认知能力相匹配。然而，用于评估和训练LLM的用户模拟器并未显式建模用户知识，因此它们既无法在知识水平维度上产生逼真的交互，也无法反映交互如何随着知识的演变而展开。为弥合这一差距，我们引入了KNOWSIM，一个围绕用户模拟器构建的评估框架，该模拟器维护显式的知识状态，表示为具有先决关系的信息单元图，这些状态在学习理论基础的更新规则下演变。KNOWSIM直接从知识状态轨迹计算三个指标（知识增益、交付校准、认知过载），反映了信息校准的关键机制方面。我们针对两个领域、按知识水平分层的705个人工智能会话对KNOWSIM进行了验证：其排名与人类判断显著一致（73-74%的符号一致性），优于三个基线模拟器。应用于9个LLM时，KNOWSIM揭示了最佳模型会随用户知识水平而改变，显示出标准评估无法察觉的能力倾向-处理交互。

## Abstract
To effectively collaborate with users on knowledge-intensive tasks, Large Language Models (LLMs) must perform information calibration: matching content to a user's evolving understanding and cognitive capacity. Yet user simulators used to evaluate and train LLMs do not explicitly model user knowledge so they neither produce realistic interactions across knowledge levels nor reflect how interactions unfold as that knowledge evolves. To close this gap, we introduce KNOWSIM, an evaluation framework built around a user simulator that maintains explicit knowledge states, represented as a graph of Information Units with prerequisite relationships, that evolve under update rules grounded in learning theory. KNOWSIM computes three metrics (Knowledge Gain, Delivery Calibration, Cognitive Overload) directly from the knowledge state trajectory, reflecting key mechanistic aspects of information calibration. We validate KNOWSIM against 705 human-AI sessions across two domains, stratified by knowledge level: its rankings align significantly with human judgments (73-74% sign agreement), outperforming three baseline simulators. Applied to 9 LLMs, KNOWSIM reveals that the best model shifts by user knowledge level, revealing aptitude-treatment interactions invisible to standard evaluation.

### 一、核心问题与整体含义

- **研究背景**：随着LLM在知识密集型任务（如医疗咨询、科学数据分析）中的广泛应用，用户越来越依赖它们作为协作伙伴。然而，现有训练范式（如RLHF）奖励“单次全面回答”，缺乏对信息跨轮次序列化的指导信号。
- **核心问题**：LLM助手必须执行**信息校准**——将内容与用户不断演化的理解水平和认知容量相匹配。例如，同一医学问题，医生和病人需要不同深度、不同顺序的答案。现有评估方法用综合答案追求“信息最大化”而非“信息校准”。
- **现有模拟器的缺陷**：
  - 不建模用户知识状态，无法评估对不同知识水平用户的信息校准效果；
  - 不追踪知识演化，无法测量客观知识增益，依赖LLM评分的表面质量。
- **整体含义**：需要一个能显式建模知识状态、可追踪知识演变轨迹的用户模拟器，以实现对人类学习过程的真实模拟，从而评估LLM助手的信息校准能力。

### 二、方法论：KNOWSIM框架

#### 1. 核心思想
以**信息单元图（IU Graph）**作为用户知识状态的核心表示，通过状态更新规则模拟人类学习过程中的认知机制，从状态轨迹中计算可解释的校准指标。

#### 2. 关键技术细节

| 模块 | 说明 |
|---|---|
| **IU图构建** | 每个问题q对应一个参考答案r，从中提取10-30个自包含的信息单元（IU）作为节点，边表示先决关系（有向无环图）；由GPT-5.2一次性提取 |
| **初始知识状态** | 根据用户水平ℓ∈{novice, intermediate, advanced}，按比例Rℓ采样初始状态（包括aware/struggling/partial/knows_well四个级别），沿拓扑序优先标记基础先决概念 |
| **用户消息生成** | LLM根据当前知识状态生成自然的用户话语，强制知识一致性行为：不能自发提及未知概念，对struggling概念会犯真实错误，对knows_well概念正确应用；根据局部邻居密度确定表达模式（明确/模糊/恭敬） |
| **信号提取** | 每轮调用LLM对每个IU分配教学标签（well_explained/shallow/not_mentioned）和用户参与标签（reasoning/articulation/none） |
| **状态更新规则** | ① 教学驱动：well_explained使状态提升一级；shallow只触发 unaware→struggling 转变；<br>② 先决条件上限：IU的可达状态受其先决条件的掌握程度限制；<br>③ 认知过载：计算状态加权负载Lt，超过容量τ时通过sigmoid函数降低状态转变幅度；<br>④ 单调性：知识状态不倒退 |
| **对话终止** | 基于学习进展假说：达到目标IU掌握程度（≥80% know_well）或持续5轮无进展/过载时终止；上限15轮 |
| **三个核心指标** | **KG (Knowledge Gain)**：所有IU的有序状态提升总和；<br>**DC (Delivery Calibration)**：解释IU的精确率与可教IU召回率的调和平均；<br>**CO (Cognitive Overload)**：每轮负载与容量比值的平均值 |

### 三、实验设计

#### 1. 数据集与场景
- **KNOWCHAT基准**：705个真实人类-AI会话，覆盖两个领域：

  - **ExpertQA**（专家级问答）：用户自选专业领域（如视觉艺术、教育、心理学），覆盖150个问题；无前后测。
- **四臂研究设计**：交叉两个因素——比较目标（策略 vs 模型）× 任务（数学 vs ExpertQA）。

#### 2. 对比条件

- **模型比较**：GPT-5.4、Claude Opus 4.7、Gemini 3 Pro（固定简单策略）。

#### 3. 基线方法
- **ZS（Zero-shot）**：仅以知识水平描述符和对话历史为条件；
- **ZS-CoT**：每轮加入思维链推理；

#### 4. 人类参与
通过Prolific招募，按知识水平（新手/中级/高级）分层，每臂约60人（50-72人），使用10题领域预筛选测试进行分层。

### 六、主要结论与发现

1. **与人类判断的一致性**：KNSOWSIM在MathQA上73%（p=.003）、ExpertQA上74%（p=.003）的符号一致率，两个任务均显著。
2. **新手层次对齐最强**：数学100%一致（p<.001）、专家QA 83%（p=.019）；中级和高级水平一致性更可变（50%-80%）。
3. **IQ和CO是最一致指标**：数学IQ/KG/CO均达75%；专家QA中IQ 80%、CO 79%领先；DC在专家QA中最低（64%）。
4. **优于基线**：KNSOWSIM在IQ对齐上领先所有基线（77% vs 73%/68%/64%）。
5. **能力倾向-处理交互**：最佳模型随知识水平变化——Gemini 3.1 Pro对高级用户最优（排名1.75），但对新手KG排名第6；DeepSeek V4最大化新手知识增益（KG=15.5）但认知过载最高（CO=0.945）。
6. **失败模式是方向性的**：新手会话65%的过载失败（先决阻塞37%+过载浪费28%）；高级会话89%为冗余重解释。

### 七、优点与方法亮点

- **知识状态显式建模**：将用户知识作为可追踪的状态图，而非黑盒行为代理，使指标具有机制可解释性。
- **学习理论扎实**：更新规则基于Ausubel的有意义学习理论、Vygotsky的最近发展区、Sweller的认知负荷理论。
- **指标可自动计算**：KG、DC、CO从状态轨迹确定性计算，不依赖LLM评分。
- **揭示标准评估看不见的现象**：能力倾向-处理交互是聚合排行榜无法暴露的。
- **人类实验规模大且分层设计**：705个会话，按知识水平分层，是少见的按知识水平分层的评估基准。
- **IU级失败模式分解**：可精确定位校准失败的具体原因（冗余/先决阻塞/过载浪费等）。

### 八、不足与局限性

- **未建模动机与情感动态**：模拟器缺乏挫折感、无聊感等情感因素；表现为高级模拟用户的知识增益饱和（KG接近0）。
- **领域覆盖有限**：仅覆盖数学问题求解和专家QA两个领域；对创意写作、探索性数据分析等更开放式成功标准的领域不适用。
- **个体差异建模困难**：从可观察行为估计个人初始知识状态仍具挑战性；当前方法只支持群体层面的知识水平分组。
- **计算成本高**：每轮多次LLM调用，扩展到大量助手模型时吞吐量受限。
- **主观与客观指标背离**：人类数据中IQ与KG呈负相关（ρ=-0.27），说明用户满意度不一定反映实际学习效果，这对依赖LLM评分的评估方法构成警示。
- **伦理风险**：不能替代人类研究；基于模拟器排名的部署可能系统性地损害知识较少用户（如DeepSeek V4新手过载问题）。
- **DC指标对齐偏弱**：特别在ExpertQA上（64%符号一致、ρ=0.08），表明感知校准质量难以通过单一主观评分完全捕获。
