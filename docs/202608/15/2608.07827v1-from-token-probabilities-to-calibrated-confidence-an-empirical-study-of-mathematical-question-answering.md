## 摘要
大型语言模型（LLM）的置信度估计旨在估计生成答案正确的概率，而校准则使这些估计与经验准确率对齐。先前的工作表明，词元概率往往过于自信，我们研究这些现成的信号是否仍能为数学问答提供良好校准的置信度估计。我们比较了单次估计器（复用原始生成中的词元概率）与多次估计器（通过验证或随机前向传播获取额外置信度信号）。虽然单个词元概率可能高度饱和，但我们发现，将整个序列上的词元概率聚合起来能够捕捉正确与错误生成之间微小但一致的差异，从而产生更有信息量的置信度估计。多次估计方法能够产生校准的置信度估计。我们研究了两种此类方法：通过重新提示进行自我验证（包括一种成本更低的原位变体），以及蒙特卡洛丢弃法（从随机前向传播的差异中推导置信度）。我们还评估了两种事后校准方法，即普拉特缩放和等渗回归，两者都显著降低了领域内的校准误差。然而，它们的数据效率随数据集难度而变化，且校准映射通常在不同数据集和模型之间不对称地迁移。

## Abstract
Confidence estimation for large language models (LLMs) aims to estimate the probability that a generated answer is correct, while calibration aligns these estimates with empirical accuracy. Prior work has shown that token probabilities are often overconfident, we investigate whether these readily available signals can nevertheless provide well-calibrated confidence estimation for mathematical question answering. We compare single-pass estimators, which reuse token probabilities from the original generation, with multi-pass estimators, which obtain additional confidence signals through verification or stochastic forward passes. While individual token probabilities can be highly saturated, we find that aggregating token probabilities over the full sequence captures small but consistent differences between correct and incorrect generations, yielding more informative confidence estimates. Multi-pass methods can yield calibrated confidence estimates. We study two such approaches: self-verification through re-prompting, including a lower-cost in-situ variant, and Monte Carlo Dropout, which derives confidence from variation across stochastic forward passes. We further evaluate two post-hoc calibration methods, Platt scaling and isotonic regression, both of which substantially reduce in-domain calibration error. However, their data efficiency varies with dataset difficulty, and the calibration mappings often transfer asymmetrically across datasets and models.

- **整体含义**：论文聚焦**数学问答**（答案可验证、结构标准），从"单遍估计 vs 多遍估计"和"后处理校准"两条路线，系统研究 token 概率在置信度估计中的价值与局限，并给出可操作的工程建议。

## 2. 论文提出的方法论

论文将置信度估计与校准区分开：**估计**是构造标量分数反映答案正确与否；**校准**是将该分数映射到经验准确率。

### 2.1 单遍估计（Single-pass Estimation）
- 直接复用原始生成时得到的 token 概率，无需额外前向传播。
- 两个设计维度：
  - **所选 token 子集**：完整生成序列（reason + answer）或仅最终答案 token。
  - **聚合方式**：
    - 算术平均（SEQ AVG / ANS AVG）；
    - 长度归一化联合概率，等价于几何平均（SEQ JOINT / ANS JOINT）。
- 组合得到四种单遍估计器：SEQ JOINT、SEQ AVG、ANS JOINT、ANS AVG。

### 2.2 多遍估计（Multi-pass Estimation）
1. **p(True) 自我验证**（Kadavath et al., 2022）：
   - 重新提示模型让其判断自身答案正确性，计算 True 与 False token 概率的归一化比值作为置信度。
   - 需要重新处理完整 question–response 上下文。
2. **原位（In-situ）自我验证**（论文提出）：
   - 将验证提问直接追加到原始生成轨迹末尾，而不是从头重新编码全部上下文。
   - 可复用原始生成状态，大幅降低 token 处理开销（平均降低约 88%）。
3. **MC Dropout 置信度（cBALD）**：
   - 以固定推理轨迹为条件，在启用 dropout 的情况下做 T 次随机前向传播，仅评估答案 token 位置的预测分布：
     - BALD_j = 预测熵（H(平均分布)） − 期望条件熵（平均 H(单样本分布)）
   - BALD 是不确定性分数，需通过单调递减函数 φ 转为置信度：cBALD = (1/|y_ans|) Σ φ(BALD_j)
   - 论文最终采用简单的 clip 归一化：φ(BALD) = clip(1 − BALD, 0, 1)。

### 2.3 后处理校准（Post-hoc Calibration）
- **等渗回归（Isotonic Regression）**：非参数单调映射，可拟合非线性校准曲线。
- **普拉特缩放（Platt Scaling）**：对 logits 做全局参数化修正；答案 token 估计器用 temperature scaling，p(True) 用二元 Platt 参数。
- 评估指标：ECE、MCE（Brier 分数见附录）。

## 6. 论文的主要结论与发现

1. **发现 1（轨迹级置信度）**：校准良好的置信度来源于将推理轨迹上微弱但一致的 token 概率差异进行聚合。序列级估计器（SEQ AVG/SEQ JOINT）在所有 model–dataset 对上 ECE 均低于仅用答案 token 的估计器；在部分设置下，单遍序列级估计器 ECE 甚至低于更昂贵的多遍方法。
2. **发现 2（分布不确定性）**：MC Dropout 通过随机前向传播的预测分布差异捕捉不确定性，在 GSMHard 上尤其优于 p(True)，但代价是 dropout 率调参 + 多次前向传播（约 5 倍单遍开销）。
3. **发现 3（原位验证）**：In-situ p(True) 与标准 p(True) 校准性能相当，但平均降低约 88% 的 token 处理开销，尤其适合长输出场景。
4. **发现 4（难度相关的数据效率与不对称迁移）**：
   - 等渗回归和普拉特缩放均显著降低域内校准误差；等渗回归在仅 50 个样本时往往已有效。
   - GSMHard（更难）在随机采样下更少样本即可受益，因为高置信错误样本出现更频繁。
   - 跨数据集/跨模型迁移存在强烈不对称性：GSM8K→GSMHard 迁移普遍改善，反向通常恶化；模型间迁移高度依赖特定 source–target 对。

## 8. 不足与局限

- **评估场景单一**：仅覆盖数学问答基准（GSM8K/GSMHard/SVAMP），无法推广到开放域对话、长文档、多轮对话等更复杂任务。

- **MC Dropout 的敏感性**：结果依赖 dropout 率、启用层、随机前向传播次数 T 及 BALD 归一化策略的选择，调参成本高且论文未探索逐层 dropout 配置。

- **未评估更复杂校准器**：仅考虑等渗回归和普拉特缩放两种经典方法，更 expressive 的校准方法（如基于 LLM 的校准器、逐层校准）未纳入比较。
