## 摘要
稀疏自编码器（SAEs）已通过理解相应的任务相关且因果有效的特征，帮助揭示了大语言模型（LLM）行为（如推理、越狱等）的机制性解释。为了评估此类机制性解释，下游研究必须区分表面词汇特征与真正的高层特征。然而，基于自动解释的语义描述和因果引导效用都无法完全确定特征的抽象层级。为此，我们引入了	extbf{特征非局域性}（FNL），定义为SAE特征激活的归一化逐位置影响的熵。我们报告FNL与现有基于LLM的特征语义抽象度代理指标相关，并能成功区分上下文相关推理特征与标记驱动特征，在随机抽取的包含一个上下文特征和一个标记级特征的特征对中，有$73$--$84\%$的比例正确地将更高的FNL分配给上下文特征。我们展示了两个下游应用。我们审计了用于越狱缓解的SAE特征，发现大多数有效特征实际上是低FNL的位置特征，而非真正识别有害意图的特征。我们报告在DeepSeek-R1-Distill-Llama-8B中引导高FNL特征可使MATH-500准确率比未引导模型提高$4.6$个百分点，且优于引导低FNL特征，尽管这些收益具有模型特异性。我们得出结论：FNL提供了SAE特征抽象层级的与LLM无关、无标签、相关的证据，可用于评估机制性解释以及选择下游干预特征。

## Abstract
Sparse autoencoders (SAEs) have helped uncover mechanistic explanations for LLM behaviours such as reasoning, jailbreaking etc., via understanding the corresponding task-relevant and causally effective features. To evaluate such mechanistic explanations, downstream studies must distinguish surface lexical features from genuinely high-level ones. However, neither an autointerp-based semantic description nor causal steering utility fully resolves the abstraction level of a feature. To this end, we introduce \emph{Feature Nonlocality} (FNL), defined as the entropy of the normalized per-position influence on an SAE feature's activation. We report that FNL correlates with existing LLM-based proxy metrics of feature semantic abstractness, and successfully distinguishes context-dependent reasoning features from token-driven ones, correctly assigning the higher FNL to the contextual feature in $73$--$84\%$ of randomly drawn pairs that consist of one contextual and one token-level feature.   We demonstrate two downstream applications. We audit SAE-based features used for jailbreak mitigation and find surprisingly that most effective features are positional features with low FNL rather than genuinely recognizing harmful intents.   We report that steering high-FNL features in DeepSeek-R1-Distill-Llama-8B improves MATH-500 accuracy by $4.6$ points over the unsteered model and outperforms steering low-FNL features, though the gains are model-specific. We conclude that FNL provides an LLM-independent, label-free, correlational witness of the abstraction level of an SAE feature, with applications in evaluating mechanistic explanations as well as selecting features for downstream interventions.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在机制可解释性（Mechanistic Interpretability）研究中，如何使用稀疏自编码器（Sparse Autoencoders, SAEs）提取特征时，**有效区分表面词汇/标记级特征（token-level, "wrapper" features）与真正高层、上下文相关的抽象特征（high-level semantic features）**。现有特征选择方法（关键词过滤、对比数据集、auto-interp、steering 验证）均无法完全判断特征的抽象层级。
- **研究动机**：成功引导（steering）一个特征并不意味着理解了底层机制——例如，引导一个特征能可靠地引发回溯行为，该特征可能真正表示"不确定性检测"，也可能只是提高了输出 token "Wait"的概率。因此，需要一种不依赖 LLM 判断、无需标签的度量来区分特征的机制复杂度。
- **整体意义**：提出了**特征非局域性（Feature Nonlocality, FNL）**——利用反向传播衡量 SAE 特征激活对输入序列各位置的影响熵，作为语义抽象度的"相关性证据"（correlational witness），为评估机制解释和选择下游干预特征提供了新工具。

### 2. 论文提出的方法论

- **核心思想**：一个特征的语义抽象程度与其"上下文触达范围"（contextual reach）成正比。token 级特征只依赖局部前缀线索（低非局域性），而抽象主题特征需要广泛跨上下文的证据（高非局域性）。
- **关键技术细节与公式**：
  - 记第 ℓ 层残差流在末位置 T 的隐向量为 h_T，x_t 为第 t 个 token 的 embedding。特征 a 的激活为 z_a(T, P)。
  - **逐位置影响**（平方梯度范数）：

    $J_a(t, T, P) := \left\lVert \frac{\partial z_a(T, P)}{\partial x_t} \right\rVert_2^2$

  - **归一化为概率分布**：

    $p_a^{(P)}(t) = \frac{J_a(t, T, P)}{\sum_{t' \le T} J_a(t', T, P)}$

  - **FNL（特征非局域性）**定义为该分布的香农熵：

    $H(a, P) = -\sum_{t=1}^{T} p_a^{(P)}(t) \log_2 p_a^{(P)}(t)$

  - 数据集层面的 FNL 为所有触发事件（z_a > τ）的平均熵。
- **计算流程**：
  1. 在数据集 D 上运行前向传播，收集特征 a 的 top-k（默认 32）触发事件；
  2. 对每个触发事件，考虑其前 T=128 个 token 的上下文，进行反向传播计算逐位置梯度；
  3. 将每个事件的熵平均得到该特征的 FNL。
- **直觉类比**：作者指出 FNL 的定义受全息对偶（holographic duality）启发——将 transformer 视为 token 向量空间中的"时间演化"，FNL 衡量特征在"时间方向"上的非局域性，即其上下文影响范围。
- **可扩展性**：FNL 不限于 SAE 特征，可推广到任意线性子空间（如残差流向量本身）。

### 3. 实验设计

- **使用的模型与 SAE 字典**：

  - FNL 引导的 steering：按 FNL 排名选取 top/bottom 20% 的特征进行包络 steering（envelope steering），对比未引导基线、低 FNL steering、随机特征 steering 和代表性子特征（ReasonScore 选出的 f3466）在 MATH-500 上的得分

### 6. 论文的主要结论与发现

- **FNL 是一个稳定、可复现的特征级度量**：跨数据集 FNL 排序高度一致（即使经过去衰减校正后仍保持大部分一致性）；深度剖面呈"先升后饱和"形态，与残差流本身的非局域性趋势一致。
- **FNL 与语义抽象度相关**：
  - 与 token 注入激活恢复度显著负相关（ρ = −0.39 至 −0.46）；
  - 与释义鲁棒性显著正相关（ρ = 0.27, p = 0.011）；
  - 能以 73%–84% 的概率将上下文相关特征与 token 驱动特征正确区分。
- **越狱缓解机制的新洞察**：CC-Delta 选出的 25 个缓解特征中，21 个是 FNL=0 的纯位置特征（在普通有害提示的 position-0 激活，但 wrapper 包装后不激活），steering 这些位置特征产生大部分防御提升；而内容感知特征对 OOD 越狱防御几乎无效。这表明这类缓解机制读取的是位置伪迹而非有害内容语义。
- **FNL 可作为特征选择标准（概念验证）**：在 DeepSeek-R1-Distill-Llama-8B 上，引导高-FNL 特征将 MATH-500 准确率从 86.5% 提升至 91.1%（+4.6 点），优于低-FNL（+3.8）、随机（+3.6）和单特征 ReasonScore（+3.9）；但该效果在 Gemma/Qwen 上未复现。
- **核心主张**：FNL 提供了一种不依赖 LLM 判断、无需标签的语义抽象度"相关性证据"，可辅助机制解释评估和下游特征选择。

### 7. 优点（方法或实验设计上的亮点）

- **全自动、无监督、无需标签**：FNL 只需要梯度计算，不需要对比数据集、人工标注或 LLM 生成解释。
- **适用范围广**：可推广到任意线性子空间（包括残差流向量本身），不仅限于 SAE 特征。
- **计算高效**：同一层的所有特征可以用一次前向传播并行计算；全部图表可在 CPU 分钟内复现（作者声明）。
- **与已有指标互补**：FNL 与 ReasonScore 近乎正交（ρ = −0.21），说明它不是 token 频率统计的变体；与对比富集度只有温和正相关，因此是一种新的、独立的度量维度。
- **实验设计严谨**：采用了去衰减 Spearman 相关（disattenuated correlation）来控制测量信度上限；提供 bootstrap 置信区间；对随机种子详细记录；越狱缓解审计中对"位置子集"和"内容子集"进行了分离式 steering，因果归因清晰。
- **理论与直觉结合**：将 FNL 与全息对偶联系，赋予度量以物理直觉——特征如同"体理论自由度"，FNL 度量其在"时间方向"上的位置（对应不同长度尺度）。
- **开源与可复现**：按 Agentic Publication Protocol 发布代码库，包含 AI 编程代理的使用说明，支持交互式复现。

---

### 8. 不足与局限

- **相关性而非因果性**：作者明确承认 FNL 是"相关性证据"，高 FNL 不一定意味着语义抽象；可能存在既高 FNL 又与语义无关的混杂因素。
- **steering 效果为模型特异性**：FNL 引导改进推理仅在 DeepSeek-R1-Distill-Llama-8B 上显著；在 Gemma-2-9B 和 Qwen3-8B 上，高 FNL 与低 FNL 包络都低于无引导基线。这限制了其作为通用特征选择标准的效力。
- **实验规模有待扩展**：样本规模有限（FNL 每个特征只用 16–60 个激活事件，MATH-500 上部分对比 n=100），部分统计显著性较弱（如释义鲁棒性 ρ=0.27, p=0.011）。
- **操作定义的选择不唯一**：作者指出 FNL 可用 softmax 替代归一化、Rényi 熵替代 Shannon 熵等，不同操作选择对绝对值和排序的影响尚无系统消融。
- **steering 强度选择存在泄漏风险**：γ 是通过在 MATH-500 的 held-out 子集上 pilot sweep 选择的，虽然与报告集不相交，但所选择的 γ 仍然是在同一基准家族上调优的，存在间接选择效应。
- **对"位置特征"的解释可能需要更多证据**：21 个 FNL=0 的特征被解释为"BOS 指示器/位置伪迹"，但作者承认对这些特征的完整机制说明仍需未来工作。
- **高计算成本**：字典规模扫描需 7–8 GPU 小时（4×H200），对计算资源有限的团队复用性受限。
- **没有在不同上下文窗口大小 T 下优先验证 FNL 对绝对阈值的敏感性**：虽然作者提供了 T 扫描实验，但主实验固定 T=128，绝对 FNL 值可能随窗口大小变化。
