## 摘要
Transformer中的位置嵌入（PE）编码了令牌（token）之间的距离和顺序，但对句法结构基本不敏感。我们提出了语法信息位置嵌入（SiPE），它在预训练期间从依存句法分析中学习一个轻量级的句法先验，并将其注入到所有三类主流PE家族（绝对、相对、旋转）中，同时适用于编码器和解码器，而不改变自注意力机制和架构的其余部分。我们分离了先验应进入模型的位置和方式，并发现这取决于架构：对于使用相对PE的自回归解码器，当先验与注意力分数的相对位置项以乘法方式耦合时最强，优于将其注入输入嵌入、自注意力或同时注入位置项和注意力项；而对于编码器，最好直接添加到输入嵌入中，与每个编码器原生的位置机制组合。我们发现，使用SiPE预训练的模型在SyntaxGym基准上性能最高提升10.3%，同时相对于没有句法监督的基础模型，困惑度降低9.0%——而几乎每种现有的句法注入方法反而会降低该指标。关键在于，这些收益不仅限于句法泛化：SiPE还提升了真实世界的语言理解能力，在GLUE基准上的得分相比未使用SiPE训练的模型最高提高8.2%。与现有句法语言模型在推理时对多个解析结果进行边缘化或在运行时丢弃句法不同，SiPE仅基于单一解析结果，从而在句法监督和推理成本之间建立了新的帕累托前沿。

## Abstract
Positional embeddings (PE) in Transformers encode token distance and order but are largely agnostic to \textit{syntactic structure}. We introduce \textbf{S}yntax-\textbf{i}nformed \textbf{P}ositional \textbf{E}mbeddings (\textbf{SiPE}), which learns a lightweight syntactic prior from dependency parses during pretraining and injects it across all three dominant PE families (absolute, relative, rotary), for both encoders and decoders, leaving self-attention and the rest of the architecture untouched. We isolate \emph{where} and \emph{how} the prior should enter the model, and find it depends on the architecture: for autoregressive decoders that use relative PE, the prior is strongest when coupled multiplicatively with the relative-position term of the attention score, outperforming injection into the input embeddings, into self-attention, or into the positional and attention terms jointly---while for encoders it is best added directly to the input embeddings, composing with each encoder's native positional mechanism. We find that models pre-trained with SiPE improve on the SyntaxGym benchmark by up to $10.3\%$ while simultaneously reducing perplexity by $9.0\%$ over a base model with no syntactic supervision---a metric nearly every existing syntax-injection method instead degrades. Crucially, these gains extend beyond syntactic generalization: SiPE also improves real-world language understanding, raising scores on the GLUE benchmark by up to $8.2\%$ over a model trained without it. Unlike existing syntactic language models that marginalize over many parses at inference or discard syntax at runtime, SiPE conditions on a single parse, establishing a new Pareto frontier between syntactic supervision and inference cost.

### 1. 论文的核心问题与整体含义（研究动机与背景）

- **核心问题**：Transformer 中的位置嵌入（Positional Embeddings, PE）仅编码序列中的顺序与距离信息，对句法结构基本不敏感。尽管位置编码保证了计算效率与可扩展性，但它将位置信息简化为一种排序机制——足以指示 token 出现在哪里，却不足以捕捉支撑下游语义的句法组合关系。
- **具体后果**：模型难以将谓语与其实参（如 move predicate 与 file/folder 论元）正确关联。例如，相对距离编码（如 DeBERTa、Transformer-XL）会弱化“move”与“folder”之间的句法联系——二者表面距离虽远（6个词），但存在直接修饰关系。
- **既有方法的不足**：先前注入句法先验的工作通常通过约束自注意力、硬编码注意力掩码或二次 token-token 交互实现（如 Pushdown LM、Transformer Grammar 等），这需要大量改动架构，并增加注意力机制的计算开销；且在推理时要么对大量句法树做边缘化（昂贵），要么在运行时丢弃句法（损害句法泛化）。
- **整体含义**：论文提出一种轻量、可移植的句法先验注入方式，在不改动自注意力与架构的前提下，同时提升句法泛化与下游语言理解，并建立句法监督与推理成本之间的新帕累托前沿。

### 2. 论文提出的方法论

**核心思想**：SiPE（Syntax-informed Positional Embeddings）从依存句法解析中学习一个轻量句法先验，在预训练期间注入位置编码通路，使模型在不修改自注意力的情况下获得句法结构信息。

**关键技术细节**：

1. **Hexatagging（“解析即标注”）**：利用 Hexatagger 将投影依存树二值化为二叉头树（BHT），通过中序（左角）遍历线性化，为每个 token 分配两类离散句法标签：
   - 终结符标签（terminal tags，2 类）：指示左右子节点；
   - 非终结符标签（non-terminal tags，5 类）：指示头方向（L/R）。
   - 每个标签对应一个嵌入查找表（|T|=2、|N|=5），以 `mp · (ET_τp + EN_νp)` 形式注入，其中 `mp` 为首子词掩码（保证每个词仅注入一次标签，避免子词切分导致信号放大不均）。

2. **注入位置与方式（架构依赖）**：
   - **编码器（RoBERTa/DeBERTa/ModernBERT）**：最优策略是将句法先验**直接加性注入输入嵌入**（input-pathway），与各编码器原生位置机制组合，最简单且最可靠。
   - **自回归解码器（Transformer-XL，相对位置编码）**：最优策略是**位置通路注入（PP-SiPE）**——将标签嵌入经逐层投影 `W_E^(ℓ)` 映射到注意力头子空间，与有效查询 `q_i,n + v_n` 求内积得到对齐分数 `c_i,j,n`，再与相对位置项 **乘性耦合**：
     `eA = AC + (1 + c) · BD`
     这一乘性门控使句法修正按查询对偏移的既有注意力强度成比例缩放，即“语法锐化已有位置偏好”，而非独立作用。消融显示：输入侧注入 < 完全解耦加性注入 < 乘性耦合注入。
   - **DeBERTa-v3（解耦相对注意力）**：无输入级位置嵌入，先验通过内容流（content stream）传播到三类分数项，或将先验注入相对位置项 `S_pos` 做乘性缩放。
   - **ModernBERT（RoPE）**：先验可加性注入输入残差，或将标签嵌入投影为逐频率相位偏移 `Δθ`，叠加到旋转角上，形成“句法相位偏移”。

3. **辅助训练目标**：预训练时除 LM 损失外，还通过两个轻量标签预测头监督终结符/非终结符标签的预测（编码器 MLM 掩码位置预测；解码器预测下一个带标签位置）。

4. **推理成本**：仅需单个解析树（一次 parser 通过），无需像联合句法 LM 那样对约 300 棵候选树做边缘化；附加参数约 1000 个（7d，远小于模型总参数量），时间复杂度不高于自注意力的渐近复杂度。

### 3. 实验设计

**数据集 / Benchmark**：

- **外在（下游）评估**：GLUE 基准（8 个任务：CoLA、SST-2、QQP、QNLI、MNLI、RTE、STS-B、MRPC）。
- **OOD 泛化**：WikiText → BLLIP-LG 持续预训练后的 BLiMP 评估。

**模型与预训练设置**：

**对比方法**：

- 无句法基线：Transformer-XL（tokens）、GPT-2；

- SiPE 自身的多种注入变体（输入侧、位置通路、完全解耦、注意力偏置、组合注入等）。

### 6. 论文的主要结论与发现

1. **架构决定最优注入位点**：自回归解码器（相对 PE）应将句法先验乘性耦合到注意力分数的位置项（PP-SiPE 最优）；编码器则应加性注入输入嵌入。
2. **显著收益**（相对无句法基线）：
   - SyntaxGym 最高提升 10.3%（80.60 vs. 73.09）；
   - 困惑度降低 9.0%（18.63 → 16.95）；
   - GLUE 宏平均最高提升 8.2%（Transformer-XL：68.17 → 73.78）。
3. **收益超出句法泛化**：GLUE 上所有架构均获提升（RoBERTa +0.75%、DeBERTa-v3 +0.59%、ModernBERT +1.0% 相对）；编码器 BLiMP 提升 +1.41%（RoBERTa）、+2.27%（DeBERTa）、+2.32%（ModernBERT），且在 OOD 持续预训练后提升更大（最高 +4.21%）。
4. **超越既有方法**：以单解析推理超越 parser-free 方法（TreeReg 与所有 TPT 变体）的 SyntaxGym 与困惑度；在困惑度上比 TreeReg 低约 1/4，比 TPT 低一半以上。
5. **层wise 注入扫描**：句法先验应自第一层（k=1）起注入；跳过第一层即导致 SyntaxGym 从 80.6 骤降至 73.5，后续层注入效果持续衰减。
6. **句法先验的注意力表现**：编码器会将注意力权重重新分配到句法相邻但线性距离较远的 token（如动词→宾语，90%/85% 的案例）；解码器的注意力变化较弱（55%），却转化为最大的下游 GLUE 收益，暗示其将句法知识更多路由到语义处理。
7. **冗余性发现**：位置通路与注意力侧同时注入会互相损害，“一次注入”优于“双重注入”。

### 7. 优点

- **极轻量**：仅需约 1000 个额外参数（两个小型查找表），不改变自注意力、不增加渐近复杂度（O(L²d) 与自注意力同阶）。
- **高度可移植**：统一兼容绝对、相对、旋转三类主流位置编码，以及编码器/解码器两种架构形态。
- **推理高效**：仅依赖单一解析树，比边缘化多棵候选树（约 300 棵）的联合句法 LM 快两个数量级，同时保留大部分句法收益，建立新 Pareto 前沿。
- **系统性与严谨性**：对“何处注入、如何耦合”进行了全面的消融与分离研究（注入位点、耦合方式、投影设计、层深度、融合机制、标签粒度），结论清晰且具有可操作指导意义。
- **兼顾内在与外在评估**：同时验证句法泛化（BLiMP/SyntaxGym）与真实下游任务（GLUE），并报告 OOD 持续预训练效果，证据链完整。
- **不改变下游用法**：模型架构保持标准 Transformer 兼容性，可直接进行持续预训练、监督微调与强化学习。

### 8. 不足与局限

- **推理时依赖解析器**：每个输入序列在注入前必须经过六标签解析器（约 184M 参数）标注，增加了预处理步骤，并继承解析器误差；在解析器精度较低的领域收益可能减小。
- **自回归生成的 KV-cache 不兼容**：生成每个新 token 需要重新解析已生成序列，而解析器可能修订先前 token 的标签，使缓存键值失效；高效增量解码仍是开放问题。
- **句法信号粒度较粗**：仅使用终结符/非终结符方向标签，完整依赖关系标签（DEPREL）未带来额外收益，且未进一步深究。
- **实验规模有限**：仅覆盖小模型、英文文本、有限预训练预算；十亿参数规模、多语言、更长预训练下收益是否保持尚不明确，显式句法先验的相对收益随规模如何变化仍是开放问题。
- **配置非全局最优**：受学术算力约束，未穷尽所有注入组合（尤其相对/旋转注意侧变体），报告结果仅为“已验证的最强配置”；且 RoBERTa 上无单一配置在所有任务上均最优。
- **注意力分析样本量小**：动词→宾语注意力分析仅人工检查 20 个样例，统计效力有限。
