## 摘要
多语言基准测试是评估跨语言大型语言模型（LLM）的核心，但它们存在三个问题：穷举评估随语言数量线性增长，自动翻译会引入大规模下难以察觉的错误，以及某些项目混淆了通用知识与特定文化知识。我们通过统一的统计框架Multilingual-IRT解决了这三个问题，该框架扩展了项目反应理论，引入了每种语言的难度偏差、区分内容与语言效应的分离区分度，以及每种语言的能力残差。在MMLU-Pro-X的29种语言上对25个LLM拟合Multilingual-IRT后，我们表明其拟合参数支持三种实际应用：预测未观测到的（项目，LLM，语言）实例时，二元交叉熵比基于准确率的最强基线低11-16%；揭示分布在所有28种非英语语言中的候选翻译错误，而基于准确率的基线则将检测集中在少数几种语言上；以及恢复基于准确率的基线遗漏的文化特定项目。

## Abstract
Multilingual benchmarks are central to evaluating large language models (LLMs) across languages, but they suffer from three issues: exhaustive evaluation scales linearly with the number of languages, automatic translation introduces errors that are easily missed at scale, and some items conflate general and culture-specific knowledge. We address all three with a unified statistical framework, Multilingual-IRT, which extends Item Response Theory with per-language difficulty deviations, split discriminability separating content from language effects, and per-language ability residuals. Fitting Multilingual-IRT on 25 LLMs across 29 languages of MMLU-Pro-X, we show that its fitted parameters support three practical applications: predicting unobserved (item, LLM, language) instances with 11-16% lower binary cross-entropy than the strongest accuracy-based baseline, surfacing candidate translation errors distributed across all 28 non-English languages, whereas accuracy-based baselines concentrate detections in a few languages, and recovering culture-specific items that accuracy-based baselines miss.

### 2. 论文提出的方法论：核心思想、关键技术细节、公式

- **核心思想**：将每个项目在不同语言中的表现建模为 LLM 整体能力、语言特定残差、项目难度和区分度的函数，通过贝叶斯推断同时学习所有参数。
- **基础模型**：扩展 2PL IRT 模型，定义概率：
  \[
  \text{logit}(p_{ijl}) = a_i^{\text{base}} \theta_j + a_i^{\text{lang}} (\varepsilon_j)_l - (b_i + d_{il})
  \]
  其中：
  - \( \theta_j \)：LLM \( j \) 的整体能力（语言无关）。
  - \( b_i \)：项目 \( i \) 的跨语言平均难度。
  - \( d_{il} \)：项目 \( i \) 在语言 \( l \) 上的难度偏差，满足 \(\sum_l d_{il} = 0\)。
  - \( a_i^{\text{base}} \)：内容区分度，反映项目内容本身区分 LLM 的能力。
  - \( a_i^{\text{lang}} \)：语言区分度，反映语言变化带来的额外区分能力。
  - \( \varepsilon_j \in \mathbb{R}^L \)：LLM \( j \) 的语言特定能力残差向量，满足 \(\sum_l (\varepsilon_j)_l = 0\)，且先验为 \(\varepsilon_j \sim N(0, \sigma^2 R_{\text{lng}})\)，其中 \( R_{\text{lng}} \) 是学习的语言相关系数矩阵。
- **关键技术细节**：
  - **可识别性**：通过不对称构造（\(\theta_j\) 标量 vs \(\varepsilon_j\) 向量带零和约束）解决标准多维 IRT 的旋转不确定性问题。
  - **模型族 M2-IRT**：包括 Indep-IRT（每语言独立）、Parallel-IRT（共享难度和区分度加语言偏差）、Coupled-IRT（增加语言残差先验）、以及完整的 Multilingual-IRT（分解区分度）。
  - **参数估计**：使用随机变分推理（SVI）在约 850 万观测上近似后验，采用弱信息先验，30,000 步 Adam 优化。
- **公式流程文字说明**：
  1. 输入：并行多语言基准预测张量 \( Y_{ijl} \)（1/0 正确/错误）。
  2. 初始化所有参数先验，通过 SVI 学习后验分布。
  3. 输出：每个 LLM 的能力 \(\theta_j\)、残差 \((\varepsilon_j)_l\)，每个项目的难度 \(b_i\)、语言偏差 \(d_{il}\)、区分度 \(a_i^{\text{base}}, a_i^{\text{lang}}\)，以及语言相关矩阵 \(R_{\text{lng}}\)。

### 3. 实验设计：数据集 / 场景、基准、对比方法

- **数据集**：MMLU-Pro-X，包含 **11,759 个多项选择题**（10 个选项），涵盖数学、物理、法律等多个领域，共 **29 种语言**（高资源如英德中，低资源如沃洛夫、约鲁巴、祖鲁）。
- **被评估模型**：**25 个 LLM**，来自 7 个模型家族：Aya、Qwen3.5、OLMo-3、Gemma-3、Llama-3、Phi-4、GPT-OSS，参数量 2B–120B，均为指令微调变体。
- **对比方法**：
  - **非参数准确率基线**：
    - 项目均值：\(\hat{Y}_i = \text{mean}_{j,l} Y_{ijl}\)
    - 对数几率加性模型：\(\text{logit}(\hat{p}_{ijl}) = \hat{A}_i + \hat{A}_{jl}\)
    - 对数几率加性模型+项目-语言项：\(\text{logit}(\hat{p}_{ijl}) = \hat{A}_i + \hat{A}_{jl} + \hat{A}_{il}\)
  - **参数消融模型（M2-IRT 家族）**：
    - Indep-IRT：每语言独立拟合 IRT。
    - Parallel-IRT：共享难度和区分度，加语言偏差。
    - Coupled-IRT：在 Parallel-IRT 基础上加语言残差先验 \(R_{\text{lng}}\)。
    - Multilingual-IRT：完整模型（区分度分解）。
- **三个应用场景**：
  1. **高效评估**：随机采样部分观测（\(\rho\) 从 0.1 到 0.9），预测剩余未观测（项目,LLM,语言）实例，用 BCE 和 ROC-AUC 衡量。
  2. **翻译错误检测**：按 \(s(i,l) = d_{il} / \text{SE}(d_{il})\) 排序，对 top-1000 用 Gemini-2.5-Flash 标注错误类型（Critical/Minor），并验证人类一致性。
  3. **文化特定项目检测**：按 \(a_i^{\text{lang}}/a_i^{\text{base}}\) 排序，对 top-2000 用 Gemini-2.5-Flash 标注是否为文化特定，验证人类一致性。

### 6. 论文的主要结论与发现

- **高效评估**：Multilingual-IRT 在预测未观测实例上比最强准确率基线 **降低 11–16% BCE**，且仅需 40% 观测即可接近全量性能；参数共享（Parallel-IRT）是预测增益的主要来源。
- **翻译错误检测**：Multilingual-IRT 的难度偏差 \(d_{il}\) 能发现 **覆盖全部 28 种非英语语言** 的翻译错误，而准确率基线将 70% 以上检测集中在三种低资源非洲语言；负 \(d_{il}\) 可有效识别“源语言入侵”（未翻译英语术语）。
- **文化特定项目检测**：区分度比 \(a_i^{\text{lang}}/a_i^{\text{base}}\) 能发现 **26.1% 的文化特定项目**（高于准确率基线的 24.2% 和随机基线的 19.8%），且与准确率基线的检测结果重叠很小（Jaccard ≤ 0.11）；文化特定项目整体更难（平均 \(b_i\) 更高）。
- **参数分析**：
  - 难度和能力参数与准确率统计几乎完全相关（r≈0.99），但区分度参数捕捉了准确率统计无法获得的信息（r≈0.55–0.70）。
  - 学习到的语言相关矩阵 \(R_{\text{lng}}\) **无监督地恢复了语言家族结构**（如罗曼语族、斯拉夫语族、南亚语族等），并反映了预训练数据资源水平的梯度（英语与非洲语言负相关）。
- **消融研究**：区分度分解是将翻译错误检测从低资源语言扩展到高资源语言的关键；交叉语言先验 \(R_{\text{lng}}\) 在预测和文化检测上增益不大。

### 7. 优点

- **方法论创新**：首次将 IRT 扩展至并行多语言基准，提出区分度分解和语言残差先验，解决了传统多维 IRT 的旋转不确定性问题。
- **统一解决多个问题**：单一框架同时支持高效评估、翻译错误检测、文化特定项目识别，展示了统计模型在 NLP 评估中的强大分析能力。
- **实验设计严谨**：
  - 对比了多种非参数和参数基线，有系统消融。
  - 对 LLM-as-a-judge 做了人类验证和多数投票校验，增强了自动标注的可信度。
  - 包含仿真、种子稳定性、先验敏感性等鲁棒性分析。
- **实用性**：提供了可操作的排名分数（如 \(d_{il}/\text{SE}(d_{il})\) 和 \(a_i^{\text{lang}}/a_i^{\text{base}}\)），可直接用于基准审计。
- **可解释性**：学习到的 \(R_{\text{lng}}\) 矩阵揭示了 LLM 跨语言行为的结构性模式，有助于理解语言间关系。

### 8. 不足与局限

- **应用限制**：
  - Multilingual-IRT **假设项目翻译是严格对齐的**，不适用于独立来源的非并行多语言数据集。
  - 模型对 LLM 样本量敏感：论文仅使用 25 个 LLM，导致语言难度偏差 \(d_{il}\) 和 \(R_{\text{lng}}\) 非对角项恢复精度有限（仿真显示增大 J 可改善）。
  - 实验仅基于 **单一基准 MMLU-Pro-X**，未在更多多语言基准（如 Belebele、Global MMLU）上验证，泛化性待确认。
- **偏差风险**：
  - 翻译错误和文化检测依赖 Gemini-2.5-Flash 自动标注，尽管有人类验证，但人类标注本身主观性较高（文化特定任务中人类间一致性仅中等 κ=0.57），且 LLM 倾向于过度标记。
  - 评估的 25 个 LLM 中英语模型占主导，可能影响参数估计的公平性。
- **计算与效率**：
  - 虽然 IRT 拟合本身轻量，但 LLM 推理仍需大量 GPU 资源；论文未提供 LLM 推理总 GPU 小时数，且依赖 API 评判（尽管成本可控）。
  - 高效评估场景中，模型预测准确率略低于全观测基准，在实际中需权衡采样率与精度。
- **理论假设**：IRT 的单调性和局部独立性假设在 LLM 评估中未必完全成立（例如，LLM 可能通过记忆而非能力作答），论文未深入讨论这一潜在违反。
