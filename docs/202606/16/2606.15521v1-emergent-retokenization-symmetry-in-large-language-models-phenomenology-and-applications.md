## 摘要
分词引入了表征冗余：在固定的词汇表下，每个字节串都对应多个有效的token编码（即分词结果），它们解码后得到相同的表层字符串。然而，给定一个提示，大多数语言模型的分词器通过返回一个规范分割来打破这种表征对称性。仅基于规范分割进行训练会影响推理行为，并且没有理由期望模型在下游任务中尊重分割对称性。我们发现这种对称性在训练过程中部分涌现。在此，我们通过实验探讨这种涌现对称性，实验测试了token组合理解、表征多样性和任务导向的基准性能。我们主要使用重分词——将提示的规范分词替换为另一种分割，同时精确保留其字节。与其他提示扰动相比，重分词特别简洁，因为它隔离了分割效果，而不改变语法、语义或表层形式。我们利用重分词来研究预训练和后训练中对语义相同输入表征的敏感性和鲁棒性。此外，这种部分重分词对称性暗示了一个不同的推理时采样轴。温度采样通过利用模型的下一个token概率分布生成多样化的输出，而重分词则通过语义等价的输入表征从模型的内部计算中生成多样性。我们发现，虽然这种重分词采样策略可能损害简单问题的性能，但它也能恢复传统采样无法找到的解决方案。总体而言，我们的工作将重分词呈现为一种简单而强大的大型语言模型探测工具，揭示了组合理解和提示敏感性，并提供了一种新颖的采样策略。

## Abstract
Tokenization introduces representational redundancy: under a fixed token vocabulary, every byte string admits many valid token encodings, or segmentations, that decode to the same surface string. However, given a prompt, most language model tokenizers break this representational symmetry by returning a canonical segmentation. Training only on canonical segmentations should influence inference behavior, and there is little reason to expect models to respect segmentation symmetry on downstream tasks. We find that this symmetry partially emerges during training. Here, we probe this emergent symmetry through experiments testing token compositional understanding, representation diversity, and task focused benchmark performance. We primarily use \textbf{retokenization} -- replacing a prompt's canonical tokenization with an alternative segmentation while preserving its bytes exactly. Relative to other prompt perturbations, retokenization is unusually clean because it isolates segmentation effects without changing syntax, semantics or surface form. We use retokenization to study sensitivity and robustness to semantically identical input representations across pretraining and post-training. Moreover, this partial retokenization symmetry suggests a distinct inference-time sampling axis. While temperature sampling generates diverse outputs from the model using its next-token probability distribution, retokenization generates diversity from the model's internal computations through semantically equivalent input representations. We find that while this retokenization sampling strategy can hurt performance on easy problems, it can also recover solutions that conventional sampling does not find. Overall, our work presents retokenization as a simple yet powerful probe of large language models, shedding light on compositional understanding and prompt sensitivity, and offering a novel sampling strategy.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：大型语言模型（LLM）使用的分词器通常为每个字节串只返回一个“规范”分词（canonical segmentation），但同一字节串在固定词汇表下实际上存在多种有效分词（即重分词）。如果模型仅在规范分词上训练，它是否会学会对这种分割方式的变化具有鲁棒性？即，模型是否能在内部涌现出对语义等价但分割不同的输入表征收敛的对称性？
- **研究背景**：先前工作表明，分词是LLM脆弱性的一个来源（如无法准确数出单词中的字母），但近期研究也发现模型能部分理解非规范分词。本文位于两者之间的空白地带：系统性地探测模型在多大程度上处理等价分割时具有不变性（symmetry）或敏感性（sensitivity），并利用这种部分不变性设计新的采样策略。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：将重分词（retokenization）作为一种受控的推理时干预。对于固定字节串 \(s\)，令 \(E_0(s)\) 为规范分词编码，\(E_\mu(s)\) 为同一字符串在相同词汇表下的任意有效分词。重分词仅改变 token 层面的分解，而不改变任何字节、语义或句法。
- **关键技术细节**：
  - **随机重分词生成**：以概率 \(p_{\text{retok}}\) 独立地对每个规范 token 进行分割，将其随机替换为词汇表中存在的更短 token 序列，保证所有有效分割等概率抽样。特殊 token 和控制符保持规范形式。
  - **内部表征分析**：计算最终 token 在模型各层隐藏状态相对于规范输入的位移（displacement）的范数均值和方差，对比打字错误扰动。
  - **Retokenization Sampling**：对同一提示采样 \(k\) 个不同的非规范分词，对每个分词进行贪心解码，用 `pass@retok(k)` 度量正确率（类似 `pass@k` 但多样性来自输入表示而非输出随机性）。
  - **AST 多样性度量**：将生成代码解析为语法抽象树（AST），提取固定高度的子树，计算子树集合之间的 Jaccard 距离作为结构多样性指标。

## 6. 主要结论与发现

1. **模型涌现了部分重分词对称性**：在内部表示中，重分词输入的隐藏层位移随训练逐渐减小（中间层收敛），但最终层仍然保留差异——说明模型理解等价分割但并非完全不变。
2. **行为上，重分词采样能产生有效多样性**：`pass@retok(k)` 曲线与 `pass@k` 形状类似，虽然整体低于温度采样，但在部分任务上能恢复温度采样无法找到的正确方案。
3. **后训练显著提升鲁棒性**：从 base → SFT → DPO → Instruct，`pass@retok` 与 `pass@k` 同步提高，表明鲁棒性随整体能力提升而提升。
4. **重分词产生的程序结构多样性不低于温度采样**：AST 距离分析显示，重分词生成的正确程序与温度采样生成的程序覆盖相似的结构范围，且部分任务仅由重分词采样解决。
5. **与打字错误的比较**：打字错误采样性能介于重分词和温度采样之间，说明表面文本变化的扰动比纯分割变化更“破坏”模型，但重分词作为控制变量更纯净。
6. **计算成本**：在同等提示预算下，重分词因提示变长而成本更高，目前不宜作为温度采样的替代，而是互补的多样性来源。

## 7. 优点（方法或实验设计亮点）

- **干净的受控变量**：重分词只改变 token 分割，不改变任何字节、语义、句法，是研究分词鲁棒性的理想探针。
- **新颖的采样轴**：提出 `pass@retok` 作为与 `pass@k` 平行的指标，将输入表示多样性正式纳入评估。
- **多维度分析**：同时考察内部表示（隐藏层位移）、行为表现（`pass@retok`）、结构多样性（AST）、计算成本，提供了全面的理解。
- **训练阶段追踪**：利用 OLMo-2 公开检查点，揭示对称性在预训练和后训练中如何逐步涌现。
- **公平对比**：对 MMLU 的特殊处理（使用规范概率而非采样）避免了误导性结论。
