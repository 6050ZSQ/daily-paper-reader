## 摘要
大型语言模型（LLM）在推理方面取得了显著进展，特别是在演绎推理领域，这对于高风险决策至关重要。随着模型性能的提升，评估基准也应相应发展。然而，现有基准缺乏对逻辑复杂度的细粒度控制，并且在语义多样性与逻辑一致性之间难以平衡。为解决这些问题，我们提出了QMFOL，一个可量化和可控复杂度的单子一阶逻辑推理任务自动生成框架。该框架利用合取与析取模式构建形式化逻辑结构，从而精确控制推理深度、宽度、标签类型和干扰项。随后，这些结构通过LLM转换为自然语言，并借助外部证明器进行往返验证以确保逻辑一致性。基于该框架，我们构建了QMFOLBench，一个包含2880个实例、960种配置的基准，覆盖多样化的逻辑和语义维度。对六个大型推理模型（LRM）和两个LLM的评估显示，随着逻辑复杂度增加，模型性能下降且计算开销上升。模型在处理标记为True的任务时表现优于False或Unknown任务，并对语义变化表现出敏感性。总体而言，QMFOL为构建复杂度可控的演绎推理基准提供了一种可扩展且可靠的方法，能够更精确地评估现代语言模型的推理能力。

## Abstract
Large Language Models (LLMs) have made significant progress in reasoning, particularly in deductive reasoning, which is crucial for high-stakes decision-making. As models improve, evaluation benchmarks should evolve to keep pace. However, existing benchmarks lack fine-grained control over logical complexity and struggle to balance semantic diversity with logical consistency.   To address these issues, we propose QMFOL, an automated framework for generating monadic first-order logic reasoning tasks with quantifiable and controllable complexity. It constructs formal logical structures using conjunction and disjunction patterns, enabling precise control over reasoning depth, width, label types, and distractors. These structures are then translated into natural language via LLMs, with logical consistency ensured through round-trip verification using an external prover. Based on our framework, we build QMFOLBench, a benchmark comprising 2880 instances with 960 configurations across diverse logical and semantic dimensions. Evaluations on six large reasoning models (LRMs) and two LLMs show that performance degrades and computational overhead increases with rising logical complexity. Models perform better on True-labeled tasks than on False or Unknown ones, and exhibit sensitivity to semantic variation. Overall, QMFOL offers a scalable and reliable approach for constructing deductive reasoning benchmarks with controllable complexity, enabling more precise evaluation of reasoning capabilities in modern language models.

### 方法论

- **核心思想**：基于单子一阶逻辑（MFOL，仅含一元谓词）和合取/析取模式，自动生成具有预设深度、宽度、标签类型和干扰项数量的形式化推理任务，再通过LLM将其翻译为自然语言，并利用外部定理证明器进行往返验证，确保逻辑结构在转换过程中不变。
- **关键技术细节**：
  - **逻辑构造模块**（§3.1）：
    1. **基础规则构造**：从初始谓词节点出发，先进行深度扩展（增加链式蕴含规则），再进行宽度扩展（随机选择已有规则，在其左部添加合取项或右部添加析取项），生成基础规则集 \(R_{basic}\)。
    2. **隐式规则与事实-结论对生成**：将 \(R_{basic}\) 合并为一条隐式规则 \(R_{imp}\)（左部为所有入度为零的节点合取，右部为所有出度为零的节点析取）。基于 \(R_{imp}\) 生成三种标签的样例：
       - **True**：给定事实使 \(R_{imp}\) 左部部分成立、右部部分排除，结论为简化后的隐式规则。
       - **False**：事实使 \(R_{imp}\) 左部成立但右部全为假，结论为左部成立且右部全假。
       - **Unknown**：两种策略：左部满足但右部不确定（选一个析取支作为结论）；或右部满足但左部不确定（对称处理）。
    3. **干扰规则生成**：通过两种策略（替换规则中的某个谓词节点，或基于现有节点构建新规则但不改变推理路径）生成干扰规则集 \(R_{distract}\)，用于增加任务难度。
  - **FOL2NL模块**（§3.2）：
    1. **翻译**：使用LLM（论文采用DS-V3.2-Think），给定主题关键词（如Food, Animal, University, Mathematics），将MFOL公式映射到该主题下的语义，生成自然语言句子。要求谓词含义互不依赖、无隐含关系。
    2. **逻辑一致性验证**：将生成的NL再通过LLM翻译回FOL（NL2FOL），并用ATP工具（Vampire）判断标签是否与原始标签一致。若不一致则重新生成，最多尝试次数后丢弃。
- **算法流程**（文字描述）：输入参数（深度 \(D\)、宽度 \(W\)、标签类型、干扰项数量、主题） → 按算法1构造 \(R_{basic}\) → 根据标签生成事实与结论 → 按算法2生成 \(R_{distract}\)（如指定） → 合并为形式化任务 → LLM翻译为NL → 往返验证 → 输出最终任务。

### 主要结论与发现

1. **总体性能**：Gemini-3.1-Pro准确率最高（99.03%），GPT-5.4-High在性能-开销权衡上最优（97.40%，平均耗时57.46s，token 2732）。Qwen3.5-27B虽参数较少但性能强劲（92.19%），超越DeepSeek-V3.2-Thinking（90.87%）。Claude-S-4-6仅80.03%。
2. **逻辑复杂度影响**：随着深度和宽度增加，性能非线性下降，且计算开销（时间、token）显著上升。GPT-5.4-High和Gemini-3.1-Pro在最高复杂度子集（D20-W20）仍保持稳定，其他模型下降明显。
3. **标签影响**：所有模型在True任务上表现最好，False次之，Unknown最差。错误大多是将True/False误判为Unknown，源于“推理不充分”。
4. **鲁棒性**：干扰项增多导致准确率下降。Gemini-3.1-Pro下降最小（~0.87%），Qwen3-32B下降最大（26.39%）。消融实验确认性能下降主要由干扰规则引起，而非文本长度。
5. **语义依赖**：即使在相同逻辑结构下，模型在不同主题上表现不同。University主题得分最高，DeepSeek系列在Mathematics主题上大幅下降（DS-V3.2-Think下降12.95%），因为其引入了外部数学知识而非仅依赖前提。

### 优点

1. **可控性**：首次实现对推理深度、宽度、干扰项数量、标签类型和语义主题的独立、量化控制，便于诊断模型在单一维度上的弱点。
2. **逻辑一致性保证**：通过“FOL→NL→FOL”的往返验证，结合外部ATP工具，确保转换后任务标签正确，有效避免了LLM翻译幻觉。
3. **可扩展性**：框架可自动化生成大量实例（2880个），且支持按需配置参数，易于后续扩展（如引入更多维度、谓词元数等）。
4. **全面评估**：覆盖多种主流LRM和LLM，从准确率、开销、鲁棒性、语义偏差等多角度分析，实验设计细致（消融、错误分析）。

### 不足与局限

1. **形式化限制**：当前仅支持一元谓词（MFOL），无法处理多元关系推理（如“x是y的父亲”），限制了逻辑表达能力的丰富性。作者提及可扩展到全FOL，但未实现。
2. **话题覆盖有限**：仅包含四种主题（Food, Animal, University, Mathematics），可能无法完全反映真实世界任务的多样性。模型在University上表现较好可能存在熟悉度偏差。
3. **翻译模型依赖**：FOL2NL和NL2FOL均依赖特定LLM（DS-V3.2-Think）。作者指出使用GPT-4o或Qwen3-32B时出现频繁的语义映射偏差，说明当前结果对翻译模型质量敏感。
4. **潜在验证失效**：可能存在FOL2NL和NL2FOL错误相互抵消的情况，虽手动抽查50例未发现，但未能完全排除。作者承认存在此风险。
5. **长上下文影响未完全剥离**：虽然消融实验表明干扰项是主要因素，但高维任务上下文更长，可能仍有细微影响。论文指出平均最大token约1380，远低于模型窗口（32K~1M），故影响有限。
6. **推理模型未作归一化**：不同模型使用不同的推理配置（如reasoning_effort high vs 默认），且DeepSeek系列不支持调整temperature，可能引入比较偏差。但论文尽力遵循官方推荐设置。
