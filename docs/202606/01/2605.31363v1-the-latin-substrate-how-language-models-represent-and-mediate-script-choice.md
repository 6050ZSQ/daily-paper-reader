## 摘要
许多语言使用多种文字书写，这要求大型语言模型（LLMs）以不同的正字法形式生成等价的语言内容。尽管先前的研究表明LLMs通过共享的潜在表征路由信息，但它们内部如何中介文字变异仍知之甚少。我们通过首先使用对数几率透镜检查逐层输出分布来研究这一问题，揭示了转写过程中一致的潜在拉丁化，然后通过文字生成的表征性和机制性分析。在表征层面，我们展示了同一语言的不同文字在层间变得越来越可分离，并且一个简单的线性引导方向可以翻转模型的输出文字，同时基本保持语义内容。该向量对构建过程中未见过的文字系统具有不对称的泛化能力，能可靠地将非拉丁输出转为拉丁，但将拉丁输出映射为多种非拉丁文字。在机制层面，我们定位了一小组因果中介文字选择的晚层注意力头。这些头在不同无关语言和文字系统间转移，表明文字路由由语言无关组件实现。在两项分析中，我们观察到一致的方向不对称：非拉丁输出由一个紧凑、可识别的门产生，而拉丁文字输出则来自网络中分散的贡献。总体而言，我们的发现暗示LLMs围绕共享的潜在表征组织文字变异，同时展现出对拉丁文字的优先基底。

## Abstract
Many languages are written in multiple scripts, requiring large language models (LLMs) to generate equivalent linguistic content in distinct orthographic forms. While prior work suggests that LLMs route information through shared latent representations, how they internally mediate script variation remains poorly understood.   We study this question by first examining per-layer output distributions with the logit lens, which reveals consistent latent romanization during transliteration, and then through representational and mechanistic analyses of script generation. At the representational level, we show that scripts of the same language become increasingly separable across layers and that a simple linear steering direction can flip a model's output script while largely maintaining semantic content. The vector generalizes asymmetrically to writing systems unseen during construction, flipping non-Latin output to Latin reliably, but mapping Latin output into varied non-Latin scripts. At the mechanistic level, we localize a small set of late-layer attention heads that causally mediate script choice. These heads transfer across unrelated languages and writing systems, suggesting that script routing is implemented by language-agnostic components. Across both analyses, we observe a consistent directional asymmetry: non-Latin output is produced by a compact, identifiable gate, while Latin-script output emerges from diffuse contributions across the network. Collectively, our findings hint that LLMs organize script variation around shared latent representations while exhibiting a privileged substrate toward Latin script.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
通过三个层次的分析验证假设：
1. **逐层输出分析**：使用logit lens观察转写过程中间层预测的分布，量化“潜在拉丁化”程度。
2. **表征分析与引导**：验证文字在隐藏状态空间中是否线性可分离，并构造线性引导向量翻转输出文字。
3. **机制性定位**：通过因果介入（激活修补）定位因果参与文字选择的注意力头。

### 关键技术细节
- **Logit Lens**：对每一层隐藏状态施加语言模型头（unembedding matrix）和softmax，得到中间层的下一token预测分布。观察拉丁化子词（romanized subwords）的出现概率。
- **潜在分数（Latent Fraction）**：在生成时间步中，若拉丁化子词以概率 > 0.1 出现在top-1预测中，则记为1；平均所有样本和时间步，得到该层的潜在分数。
- **表征可分离性**：采用三种互补度量：
  - 线性探针（linear probe）分类拉丁 vs. 非拉丁句子。
  - 层内余弦相似度（同句不同文字表示之间的相似度）。
  - Fisher判别比（类间方差 / 类内方差）。
- **线性引导向量**：对给定层 `l`，计算拉丁和原生句子平均隐藏状态的单位化差分向量 `v_l = (h̄_lat - h̄_nat) / ||...||`。推理时同时向所有层的残差流添加 `α·v_l`（α为强度系数）。
- **因果注意力头定位**：使用反事实激活修补（counterfactual activation patching）。对一对原生/拉丁句子，先运行两次模型缓存每个注意力头在最后一token的预投影激活；然后在目标句子的前向传播中替换该头激活。测量修补后下一token的脚本边际变化 `Δm = log Σ_{t∈V_nat} e^{z_t} - log Σ_{t∈V_lat} e^{z_t}`。修补方向分两种：`lat2nat`（将原生激活补入拉丁运行）和`nat2lat`（反之）。
- **门控验证**：对定位到的top-k头进行零消融、首token修补、持续修补等干预，测量生成脚本翻转成功率。

## 6. 论文的主要结论与发现

1. **潜在拉丁化广泛存在**：转写任务中，模型在上层（最后10层）以非平凡概率预测拉丁化子词，且比例高于翻译、重复等任务。这支持拉丁文字作为共享中介表征的假设。
2. **文字表征在后层逐渐分离**：线性探针准确率从底层接近随机升至上层接近完美；同语言不同文字表示的余弦相似度随层下降；Fisher比在上层达到峰值。表明文字信息在后层变得可区分且可控。
3. **线性引导有效翻转输出文字**：一个简单的全层叠加引导向量能可靠地将输出从原生翻转为拉丁（lat2nat），强度较低即可达近100%成功率。反向（nat2lat）成功率较低但仍在较高强度时有效。
4. **引导方向不对称且跨语言泛化**：
   - `nat2lat`方向能将多种未见非拉丁文字系统的输出可靠转成拉丁。
   - `lat2nat`方向则将拉丁输出转成多种不同的非拉丁文字（如波兰语→西里尔文、印尼语→泰文），并非单一目标脚本。
   - 这表明学习到的方向编码的是粗粒度的“拉丁 vs 非拉丁”区分，而非语言特定的转写映射。
5. **因果注意力头定位**：原生（非拉丁）输出依赖一小簇晚层注意力头（如Llama-3.1-8B中的L30H20、L30H23、L26H7、L20H18、L24H1），而拉丁输出由分散的、小幅度贡献的头共同产生。
6. **头门控跨语言通用**：使用印地语或阿拉伯语识别的头，通过持续修补能成功翻转俄语（西里尔文）、希腊语、马拉地语、乌尔都语、日语等未参与定位的语言的输出脚本。随机头控制组失败，说明这些头实现的是语言无关的文字路由机制。
7. **一致的不对称性**：非拉丁 → 拉丁的翻转更可靠、所需头更少、引导方向更健壮；拉丁 → 非拉丁则更困难、需要更多头、引导效果不稳定。这符合“拉丁为默认输出基底”的假设。

## 7. 优点：方法或实验设计上的亮点

1. **多层级、多角度分析**：将表征分析（线性分离、引导）与机制分析（因果修补）结合，从“是什么”、“能否操控”、“在哪里”三个层面回答问题，逻辑严谨。
2. **量化与可视化结合**：引入“潜在分数”定量描述层间拉丁化程度，并用Logit Lens热力图定性展示；使用热力图直观呈现注意力头贡献分布。
3. **严格的因果验证**：通过反事实激活修补直接证明特定头的因果作用，而非仅依赖相关性。并设计了多种头子集和修补策略（首token vs 持续）确认门控的持续性。
4. **跨模型、跨语言泛化验证**：覆盖两个家族四种规模模型，测试多种语言和文字系统，提高了结论的鲁棒性。
5. **引导向量的不对称性揭示**：发现了拉丁方向的特权地位，并利用这一发现验证了模型内部组织原则（紧凑门 vs 分散贡献），而非停留于表面现象。
6. **避免评估泄漏**：构建引导向量和定位头的训练数据与评估数据完全分离（FLORES-200 vs CLaS-Bench），保证实验公正性。

## 8. 不足与局限

1. **模型范围有限**：仅分析四个开源指令微调模型（Llama、Aya），未覆盖闭源模型（如GPT-4、Gemini）或不同架构（如编码器-解码器）。不同训练数据、强化学习策略的模型可能表现出不同机制。
2. **语言覆盖不足**：引导向量和头定位仅使用印地语（天城文）和阿拉伯语（阿拉伯文）。虽然测试了跨语言转移，但所有测试语言均有明确的罗马化形式且在预训练中大概率存在。语言如缅甸语、埃塞俄比亚语、高棉语等罕见文字或罗马化不规范的语种未涉及，可能表现不同。
3. **未深入挖掘底层电路**：定位到的注意力头可能属于更大的电路（如与MLP、残差流其他组件交互），论文未探索完整电路结构（作者将这一点列为未来工作）。
4. **未讨论训练时间影响**：模型已预先训练好，本文仅分析推理时行为。不同训练步骤、数据混合比例对文字表征结构的影响未知。
5. **引导向量构建依赖平行数据**：需要同句子的原生和拉丁对照，实际应用中获取此类数据成本较高，且限制了向量的即时构建能力。
6. **实验资源未报告**：尽管推理开销不大，但未提供GPU小时数等硬件信息，不利于复现者估计需求。
7. **评估指标有限**：主要使用脚本翻转率（基于字符编码或工具识别），未系统评估翻转后语义保留程度（仅定性示例显示基本保留）。可能存在内容质量下降的风险。
