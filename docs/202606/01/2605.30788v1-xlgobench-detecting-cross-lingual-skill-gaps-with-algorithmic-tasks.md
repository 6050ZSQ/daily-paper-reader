## 摘要
我们引入了一组合成算法任务，用于检测大型语言模型在跨语言能力上的差距。我们的基准测试在不同语言之间具有可比性，因为它要求模型在不同语言中执行相同的底层任务；可扩展，因为每个任务可以以不同复杂程度生成，从而适应具有不同能力的模型；可量化，因为每个任务都允许客观的正确性概念；透明，因为任务是从简单的模板生成的，可以轻松审计翻译错误。由于我们的基准测试侧重于算法任务，因此差异性能是跨语言差距的充分但不必要条件。尽管如此，我们通过广泛实验证明，我们的基准测试暴露了多个最先进模型中存在的持久跨语言差距。

## Abstract
We introduce a set of synthetic algorithmic tasks to detect cross-lingual gaps in the abilities of large language models. Our benchmark is commensurate across languages, since it requires models to perform the same underlying task in different languages; scalable, since each task can be generated at varying levels of complexity allowing it to be adapted to models with different capabilities; quantifiable, since every task admits an objective notion of correctness; and transparent, since tasks are generated from simple templates that can be readily audited for translation errors. Because our benchmark focuses on algorithmic tasks, differential performance is a sufficient -- but not necessary -- indicator of cross-lingual gaps. Nevertheless, we show through extensive experiments that our benchmark exposes persistent cross-lingual gaps in multiple state-of-the-art models.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：大型语言模型（LLMs）在现实应用中展现出显著的跨语言能力差距，特别是在非英语语言上表现更弱。尽管已有多种多语言评测基准，但这些基准往往存在翻译错误、难以扩展、无法量化、以及任务在不同语言之间不可比等问题，导致跨语言差距的检测不够可靠。
- **动机**：为了弥补这一不足，作者提出了一种新的合成算法评测基准 XLGoBench，旨在**在相同任务上公平比较模型在不同语言下的能力**，从而暴露和量化跨语言技能差距。
- **整体含义**：该基准通过简单算法任务的差异性能（differential performance）作为**充分但不必要**的跨语言差距指标。如果某模型在某一语言下算法任务表现明显更差，则说明存在真实差距；反之，即使算法任务表现一致，也可能在更微妙的语言任务（如创意写作）中存在差距。因此，该基准提供了一种**低门槛、可量化**的检测工具，是迈向消除跨语言不平等的第一步。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 使用**一组可扩展的合成算法谜题**，每个谜题由少量模板构成，模板翻译为多种语言后，生成不同复杂度的具体问题。
- 通过**复杂度-准确率曲线**的差异来检测跨语言差距。所有语言任务本质等价，只是表面语言不同。
- 引入 **Signed Max Divergence (SMD)** 作为单一的跨语言差距度量，它衡量在复杂度中间区域，英语与目标语言之间准确率的最大差异。

### 关键技术细节
- **谜题类型**：共5种，分为图遍历（Graph Walk）和图搜索（Graph Search）两大类：
  - Sequential Linear Transforms (SLT)：根据打乱的交易记录重建顺序并计算最终财富。
  - Discrete State Automaton (DSA)：在确定性状态机上根据键序列移动，输出最终状态。
  - Probabilistic Discrete State Automata (Pr-DSA)：与DSA类似，但状态转移是概率性的，要求输出概率最高的8个最终状态。
  - Graph Shortest Path (Graph SP)：在无向图中寻找两点之间的最短路径。
  - Tournament Ranking (T-Rank)：根据有向循环的比赛结果，给所有选手进行拓扑排序。

- **复杂度定义**：
  - SLT：交易次数（链长度）。
  - DSA：状态数（房间数）。
  - Pr-DSA：状态数（固定15次动作）。
  - Graph SP：边数。
  - T-Rank：边数。

- **模板化及翻译验证**：每个谜题由平均5个模板组成，模板先由母语者翻译并审核，确保语义等价且自然。之后所有具体问题由模板随机组合生成，避免了逐句翻译错误。

- **答案验证**：要求模型输出JSON格式，通过自动精确匹配验证答案（Pr-DSA采用集合匹配），无需LLM作为评判者。

- **数学建模**：使用**不完全Gamma函数**拟合准确率\(f_\ell(c)\)与复杂度\(c\)的关系：
  \[
  f_\ell(c) = \frac{1}{\Gamma(q_\ell/2)} \gamma\left(\frac{q_\ell}{2}, \frac{q_\ell}{2} r_\ell c^2\right)
  \]
  其中\(r_\ell, q_\ell\)为语言相关参数。基于此计算SMD：
  \[
  \text{SMD}(\ell) = f_{\text{En}}(c^*) - f_\ell(c^*), \quad c^* = \arg\max |f_{\text{En}}(c) - f_\ell(c)|
  \]

## 3. 实验设计

### 使用的模型
- **四个前沿模型**：Gemini-3-Flash (Deepmind)、Gemini-3.1-Flash-Lite (Deepmind)、Gemma-4-31B (Deepmind)、GLM-5.1 (Z.AI)。覆盖闭源和开源、不同国家开发模型。

### 语言
- **七种语言**：英语(EN)、阿拉伯语(AR)、印地语(HI)、日语(JA)、中文(ZH)、泰米尔语(TA)、泰卢固语(TE)。覆盖不同语系和文字系统。

### 复杂度设置
- 每个谜题选择20个复杂度水平，范围使英语从接近100%准确率降至接近0%。
- 例如SLT：链长度100~600；DSA：状态32~2090；Graph SP：边70~720；T-Rank：边100~400。Gemini-3.1-Flash-Lite因其较小规模，单独选了更简单范围。

### 采样
- 每个复杂度水平随机生成50个问题，语言之间复用随机种子。总共约4个模型 × 20配置 × 50问题 × 7语言 × 5任务 = 140,000提示。

### 对比方法
- 无外部基线对比：该基准本身是评测方法，主要对比不同语言下同一模型的准确率差异。通过SMD值显著性与0比较来判断是否存在跨语言差距。

## 6. 主要结论与发现

1. **存在显著跨语言差距**：所有评估模型在至少几个任务上都表现出显著的SMD（英语优于目标语言）。例如，Gemini-3-Flash在DSA任务上，印地语SMD达53%，泰卢固语达45%。
2. **差距出现在中等复杂度**：在低复杂度时所有语言准确率接近100%，高复杂度时都接近0%，差距仅在中间区域显现。这说明静态基准（如只有固定难度）可能错过这些差距。
3. **不同模型表现模式不同**：
   - Gemma-4-31B 总体上跨语言差距最小，与其宣称的多语言关注一致。
   - GLM-5.1 在中文上甚至胜过英文（Graph SP），与其中文训练重点相符。
   - 泰米尔语和泰卢固语通常差距最大，可能由于其训练数据相对稀缺。
4. **不是所有任务都暴露差距**：例如Pr-DSA和Graph SP在某些模型上差距不明显，而T-Rank几乎在所有模型和语言上都显著。
5. **反向翻译验证**：将表现最差语言模板反向翻译成英语后，准确性无显著变化，排除翻译错误。
6. **思考长度与差距相关性弱**：Spearman秩相关分析显示，思考长度（thinking tokens）与SMD之间无明显负相关，表明差距不能简单归因于模型在非英语语言上思考不足。

## 7. 优点

- **透明性**：模板可审计，翻译错误可控。
- **可扩展性**：复杂度可调，适应未来更强大的模型，不易饱和。
- **可量化性**：自动化验证答案，客观统计显著。
- **任务可比性**：所有语言执行相同的抽象任务，避免文化或语体差异。
- **无需LLM裁判**：避免引入额外偏差。
- **提供单一指标SMD**：便于比较不同模型/语言/任务。
- **低门槛**：模板化生成大量唯一实例，防止记忆化泄漏。

## 8. 不足与局限

- **与现实任务脱节**：算法任务不能完全反映真实世界中对细微差别和创造性的需求。模型在算法任务上表现一致，仍可能在写作、文化理解等方面存在差距。因此，本基准的差距是**充分不必要**指标。
- **评估成本高**：由于需要在高复杂度区域进行大量推理，成本可达数千美元。虽然可以通过只采样关键复杂度来降低，但仍是实际障碍。
- **语言种类有限**：仅覆盖7种语言，未来可扩展。
- **未充分分析tokenization影响**：作者指出不同语言的token化效率不同可能影响结果，但初步观察未发现明显相关，仍需深入研究。
- **仅涉及推理能力**：未覆盖生成、翻译、代码等能力。
- **可能存在的偏差**：尽管进行了反向翻译验证，但模板语言本身（如“friend”等英文文化概念）可能在其他语言中无完全等效，但作者使用字母数字ID避免了部分问题。
- **实验仅在特定模型上测试**：结果不能直接推广到所有LLMs，但覆盖了前沿代表性模型。
