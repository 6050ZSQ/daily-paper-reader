## 摘要
尽管大型语言模型（LLM）能够生成流畅的阿拉伯语文本，但其可靠地控制文本可读性水平的能力仍不明确。我们提出了一种面向欧洲语言共同参考框架（CEFR）可控阿拉伯语文本生成的多维评估框架，以评估遵循指令的LLM能否作为自适应语言学习的可靠生成器。该框架整合了受控提示、使用经过验证的Taha-19模型进行自动可读性预测、词汇约束验证以及句法复杂度分析。结果表明，结构化提示显著提高了与CEFR的对齐程度。特别地，带有词汇约束的CEFR引导提示在参考语言特征符合度上达到了最高（余弦相似度0.91），并且与预测可读性水平几乎完全一致（0.99），而无约束提示则表现出较弱的控制力。这些发现为将可读性感知的阿拉伯语文本生成集成到自适应教育系统中奠定了实证基础。

## Abstract
While Large Language Models (LLMs) can generate fluent Arabic text, their ability to reliably control readability levels remains unclear. We propose a multi-dimensional evaluation framework for Common European Framework of Reference for Language (CEFR)-controlled Arabic text generation, assessing whether instruction-following LLMs can serve as reliable generators for adaptive language learning. Our framework integrates controlled prompting, automatic readability prediction using a validated Taha-19 model, lexical constraint validation, and syntactic complexity profiling. Results show that structured prompting substantially improves CEFR alignment. In particular, CEFR-guided prompting with lexical constraints achieves the highest conformity to reference linguistic profiles (0.91 cosine similarity) and near-perfect agreement with predicted readability levels (0.99), while unconstrained prompting exhibits weak control. These findings establish an empirical foundation for integrating readability-aware Arabic text generation into adaptive educational systems.

## 1. 核心问题与整体含义（研究动机与背景）

大型语言模型（LLM）能够生成流畅的阿拉伯语文本，但在教育场景中能否可靠地控制文本可读性（如按CEFR水平生成适配学习者能力的文本）仍不清楚。现有研究多集中于英语，且仅依赖单一可读性指标，未能捕捉阿拉伯语的丰富形态、灵活语序和句法变异性带来的挑战。本研究首次提出针对CEFR可控阿拉伯语文本生成的多维评估框架，旨在验证遵循指令的LLM能否作为自适应语言学习系统中的可靠生成器，从而为个性化教育内容生成提供实证基础。

## 2. 方法论

### 核心思想
- 将CEFR（A1-C2）与精细的阿拉伯语可读性等级Taha-19（19级）对齐，构建CEFR级别的语言特征画像（词汇、句法、结构复杂度）。
- 设计五种从无约束到高度约束的提示策略，分别控制是否指定CEFR级别、是否加入句法约束、是否加入词汇约束。
- 使用自动可读性预测模型BAREC评估生成文本的难度，并通过余弦相似度衡量生成文本特征向量与参考画像的对齐程度。

### 关键技术细节
1. **CEFR-Taha-19对齐**：利用ZAEBUC和ARWI语料库中CEFR标注的作文，通过BAREC模型推断每篇作文的Taha-19可读性分数（句子级平均），分析相关性（Spearman ρ=0.84）。
2. **句法画像构建**：使用CamelParser提取POS标签、依存关系、依存-POS组合共72种特征，筛选出29个随CEFR呈单调变化的特征，并计算平均依存树深度。
3. **词汇画像构建**：包括总词数、平均句长、唯一词数、词长、音节数、唯一词元数等。同时构建CEFR对齐的词汇列表，使用SAMER可读性词典进行过滤。
4. **五种提示条件（P1-P5）**：
   - P1：不指定可读性（无约束基线）。
   - P2：仅指定目标CEFR级别。
   - P3：指定句法约束（如总词数、句长、形容词数、主语数、依存深度等）。
   - P4：指定CEFR级别+词汇约束（要求包含特定词汇列表）。
   - P5：同时指定句法+词汇约束。
5. **词汇列表自动生成**：先由GPT-4o按主题生成候选词，经SAMER验证和语义相关性过滤，确保每个主题有足够且匹配的词汇。
6. **评估指标**：余弦相似度，计算生成文本特征向量（经z-score标准化）与CEFR参考画像的相似度，分别在整体、特征簇、各CEFR级别、单个特征粒度计算。

### 公式与算法流程（文字说明）
- 余弦相似度公式：cos(θ) = (Σ P_i Q_i) / (√(ΣP_i²) · √(ΣQ_i²))，其中P为参考画像特征向量，Q为生成文本特征向量。
- 评估流程：生成文本 → 提取所有特征（表面、依存、POS、DepPOS、树深度）→ 按CEFR级别平均 → 计算与参考画像的余弦相似度 → 汇总报告。
