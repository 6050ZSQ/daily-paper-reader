## 摘要
随着大型语言模型在高风险场景中的部署日益增多，对能够审计模型输出以及产生这些输出的内部计算工具的需求也在增长。电路分析是机制可解释性的核心方法，但它通常以目标为条件，解释单个提示与所选补全的配对。这种目标条件设置可能掩盖模型续写分布中的异质性。我们引入了分布级别的无监督特征发现，该方法使用语义内容和序列级别的机制归因对采样续写进行聚类，无需手动指定目标输出。我们的方法为每个续写表示一个语义嵌入和一个前缀到续写的归因签名，然后优化一个在语义连贯性、机制一致性和聚类粒度之间权衡的率失真目标。在聚类和引导分析中，所发现的聚类揭示了单视图基线遗漏的续写模式，并提供了干预证据，表明聚类签名对应于可操作的机制因素。总体而言，我们的方法通过提供对模型续写分布背后机制的可扩展审计，补充了电路分析和行为评估。

## Abstract
As large language models are increasingly deployed in high-stakes settings, there is a growing need for tools that audit not only model outputs but also the internal computations that produce them. Circuit analysis is a central approach in mechanistic interpretability, but it is typically target-conditioned, explaining a single prompt paired with a chosen completion. This target-conditioned setup can obscure heterogeneity across a model's continuation distribution. We introduce distribution-level unsupervised feature discovery, which clusters sampled continuations using both semantic content and sequence-level mechanistic attributions, without manually specifying target outputs. Our method represents each continuation with a semantic embedding and a prefix-to-continuation attribution signature, then optimizes a rate-distortion objective that trades off semantic coherence, mechanistic consistency, and cluster granularity. Across clustering and steering analyses, the discovered clusters expose continuation modes that single-view baselines miss and provide interventional evidence that cluster signatures correspond to actionable mechanistic factors. Overall, our approach complements circuit analysis and behavioral evaluation by providing a scalable audit of the mechanisms underlying a model's continuation distribution.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
对给定前缀（prompt）采样多个续写，为每个续写构建**语义嵌入**（表征“说什么”）和**机制嵌入**（表征“如何计算”），然后通过**率失真（rate-distortion）聚类**联合优化，使聚类在语义和机制两个视图中都保持一致性，自动发现隐式的续写模式。

### 技术细节
- **三阶段流程**：
  1. **续写采样**：使用核采样生成N个不同续写，并计算长度归一化概率权重。
  2. **双重表示**：
     - 语义嵌入：通过预训练句子编码器（如EmbeddingGemma）获取续写的语义向量。
     - 机制嵌入：使用**transcoder**（稀疏字典学习）分解MLP计算，计算每个前缀特征对续写每个token的对数偏置的线性归因（direct linear attribution），然后取序列平均，得到前缀到续写的归因向量。
  3. **联合聚类**：
     - 目标函数：$L_{RD} = H(C) + \beta_e D_e + \beta_a D_a$，其中$H(C)$是聚类分配的熵（率），$D_e$和$D_a$分别是语义和机制的加权失真（L2和L1距离）。
     - 参数$\beta$控制率-失真权衡（$\beta \to 0$聚类数为1，$\beta \to \infty$聚类数为N），$\gamma$平衡两个视图（$\beta_e = \gamma\beta$, $\beta_a = (1-\gamma)\beta$）。
     - 优化：交替最小化（E步分配，M步更新中心），并自适应执行**分裂**（split）和**丢弃**（junk）操作，动态调整聚类数K。
     - 分裂准则：当分裂后失真降低超过率增加时接受。
     - 丢弃准则：当删除一个集群提升率大于失真增加时执行。

## 6. 论文的主要结论与发现

1. **联合聚类优于单视图**：相比仅语义或仅机制聚类（率匹配），RD获得更低的混合失真，避免任一视图的互补失效。
2. **率失真参数提供可解释控制**：$\beta$能发现不同粒度的续写模式（从粗粒度风格到细粒度身份/事实），$\gamma$平衡机制一致性和语义连贯性。
3. **自适应操作有效**：分裂操作发现隐藏子簇，丢弃操作去除噪声簇，改善率-失真权衡。
4. **聚类特征具有因果效力**：RD中定义的类原型（通过medoid）引导方向能在正负方向上调整个集群的似然，且比单续写方向或语义K-means方向更一致、更强。
5. **推理步骤间机制异质性**：不同推理步骤对后续步骤的聚类影响不同，早期步骤主导，后期步骤可能分离或抵消。

## 8. 不足与局限

1. **计算开销高**：需要为每个续写计算语义嵌入和完整前缀到续写的归因（后向传播），对长前缀和长续写场景昂贵。

5. **依赖预训练组件**：语义嵌入和transcoder的质量直接影响聚类结果，且归因基于一阶线性近似，可能遗漏非线性交互。
6. **可能被滥用**：引导方向可用于放大不良行为，论文仅将其定位为诊断工具而非部署推荐。
