## 摘要
大型语言模型（LLM）的最新进展为生成无训练文本嵌入开辟了新途径。然而，仅解码器LLM中的因果注意力机制阻止了较早的token关注未来的上下文，导致上下文表示存在偏差。在这项工作中，我们提出了具有显式单词限制的反向提示（ReverseEOL），这是一种简单而有效的方法，用于增强冻结LLM的表征能力。ReverseEOL通过从反转的输入文本中获取额外的反向嵌入来增强标准前向嵌入。由于反转输入使每个token能够访问原始顺序中无法获得的上下文，因此得到的反向嵌入有效地为原始嵌入提供了补充信息。因此，结合前向和反向嵌入可产生更丰富的最终表示。在STS和MTEB基准上的全面实验表明，ReverseEOL显著提升了现有无训练基线在具有不同架构和规模的广泛LLM上的性能。大量的消融和分析进一步证实了我们的反转机制的必要性。

## Abstract
Recent advances in Large Language Models (LLMs) have opened new avenues for generating training-free text embeddings. However, the causal attention in decoder-only LLMs prevents earlier tokens from attending to future context, leading to biased contextualized representations. In this work, we propose Reverse prompting with Explicit One-word Limitation (ReverseEOL), a simple yet effective method for enhancing the representational capability of frozen LLMs. ReverseEOL augments the standard forward embedding with an additional reversed embedding derived from the reversed input text. Since reversing the input exposes each token to context inaccessible in the original order, the resulting reversed embedding effectively provides complementary information to the original one. As a result, combining the forward and reversed embeddings yields a richer final representation. Comprehensive experiments on STS and MTEB benchmarks demonstrate that ReverseEOL significantly improves the performance of existing training-free baselines across a broad range of LLMs with diverse architectures and scales. Extensive ablations and analyses further confirm the necessity of our reversal mechanism.

# 论文总结：ReverseEOL: Improving Training-free Text Embeddings via Text Reversal in Decoder-only LLMs

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：解码器-only 的大型语言模型（LLM）在生成无训练文本嵌入时，因果注意力机制导致较早的 token 无法访问未来的上下文，使得从最后一个 token 提取的嵌入仅能编码部分语义信息，产生有偏的表示。尽管已有 PromptEOL 等方法通过“一词限制”（one-word limitation）提示来压缩语义，但因果注意力的根本瓶颈未解决。
- **背景**：训练-free 文本嵌入方法无需参数更新，可直接应用于冻结的 LLM，具有实际吸引力。然而，现有方法（如对比提示、令牌预置）需要模型内部干预且改进有限。本文提出一种简单且模型无关的方法——ReverseEOL，通过反转输入文本获取互补信息，提升嵌入质量。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：由于因果注意力下每个 token 只能访问其左侧的上下文，反转输入文本可以让同一个 token 获取原始顺序中无法获得的上下文信息。因此，将正向嵌入与反向嵌入融合，可得到更丰富的表示。
- **关键技术细节**：
  - **正向嵌入**：使用标准的一词限制提示（如 PromptEOL）从冻结 LLM 的特定层提取最后 token 的隐藏状态作为正向嵌入，记为 \( e_{fwd}^x \)。
  - **反向嵌入**：对输入文本 \( x \) 进行文本级反转（保持单词单元），得到 \( x_{rev} \)，并适配提示模板为“This reversed sentence: '[REV_TEXT]' means in one word:"，提取反向嵌入 \( e_{rev}^x \)。
  - **融合**：取两个嵌入的平均值作为最终表示：\( e_{out}^x = \frac{1}{2}(e_{fwd}^x + e_{rev}^x) \)。
- **算法流程**（文字描述）：
  1. 对原始文本 \( x \) 应用前向提示模板，输入 LLM，获取指定层的最后 token 嵌入 \( e_{fwd} \)。
  2. 将文本 \( x \) 反转（保持词序颠倒），应用反向提示模板，输入 LLM，获取相同的最后 token 嵌入 \( e_{rev} \)。
  3. 计算两个嵌入的逐元素平均值作为最终文本嵌入。
- **无需复杂提示工程或内部模型干预**，可直接集成到现有训练-free 方法中。

## 3. 实验设计：数据集 / 场景、benchmark、对比方法

- **Benchmark 与数据集**：
  - **STS（Semantic Textual Similarity）**：包含 STS 2012–2016、STS-B、SICK-R 共 7 个数据集，评估句子对相似性（Spearman 相关系数）。
  - **MTEB（Massive Text Embedding Benchmark）**：包含 32 个数据集，覆盖 5 个任务类别：检索（9 个）、重排序（3 个）、聚类（10 个）、句子对分类（3 个）、分类（7 个）。评估指标分别为 nDCG@10、MAP、V-measure、AP、Accuracy。
- **对比方法**：
  - **训练-free 基线**：PromptEOL、ECHO、Pretended CoT、Knowledge、MetaEOL、Prompt A/B（来自 Li & Li 2023/2024）。
  - **内部模型干预方法**：Contrastive Prompting (CP)、Token Prepending (TP)。
  - **消融实验**：比较不同排列策略（随机洗牌、token 级反转等）、不同嵌入组合（前向 + 前向 vs 前向 + 反向）。
- **LLM 模型**：涵盖 10 多个系列，包括 LLaMA-2 (7B/13B)、LLaMA-3-8B、Mistral-7B、Qwen2/2.5 系列 (0.5B~32B)、Gemma-2-2B，以及混合专家模型（OLMoE-1B-7B、MiniCPM-MoE-8x2B、Deepseek-MoE-16B、Qwen1.5-MoE-A2.7B、Qwen3-30B-A3B）。

## 4. 资源与算力

- 论文明确说明使用 **单张 NVIDIA A100 80GB GPU** 进行所有实验。未提及训练时长，因为方法无需训练（仅为推理）。最大输入序列长度设为 512 tokens。推理时间分析显示 ReverseEOL 约为基线方法的 1.96 倍（因额外一次前向传播）。

## 5. 实验数量与充分性

- **实验数量丰富**：
  - STS 实验：覆盖 10 多种 LLM，每种 LLM 对多个 prompt 变体（如 PromptEOL、Pretended CoT 等）应用 ReverseEOL，总计数十组结果。
  - MTEB 实验：在 LLaMA-2-7B、13B、Mistral-7B 上完整评估 32 个数据集，并报告分层任务的平均分。
  - 消融实验：包括不同排列策略（文本级反转/随机、token 级反转/随机）、不同 embedding 组合（前向+前向 vs 前向+反向）、不同池化策略（last-token/mean/weighted mean）、不同退出层、不同权重系数 α、不同模型规模（Qwen2.5 0.5B~32B）、不同 prompt 设计（6 种提示）等。
- **公平性与客观性**：所有方法使用相同的退出层设置和评估流水线；对比时确保同一 LLM 的相同层。性能提升在多个模型、多个数据集上一致，且统计量（Spearman 相关系数）为常规指标。实验设计较为充分。

## 6. 论文的主要结论与发现

- **主要结论**：ReverseEOL 通过融合正向和反向嵌入，显著提升各种训练-free 文本嵌入方法的性能，在 STS 上平均提升 2.56–8.09 分，在 MTEB 上平均提升 4.18–5.34 分。该方法适用于多种架构和规模的 LLM（密集模型和 MoE 模型）。
- **关键发现**：
  - 反向嵌入提供与正向嵌入互补的信息，CKA 相似度低于 0.7，而不同正向提示之间的相似度高于 0.9。
  - 文本级反转优于 token 级反转或随机洗牌，因为保留了语义单元。
  - 最优权重 α 在 0.5–0.6 之间，平均化参数高效的基线。
  - 该方法对退出层、池化策略、模型规模均稳健。

## 7. 优点

- **简单有效**：仅需反转输入文本并修改提示词，无需训练或模型内部改动。
- **模型无关**：可无缝集成到各种 LLM 和现有训练-free 方法中。
- **广泛验证**：在 10 多个 LLM 家族、多种架构（密集/MoE）、多个尺度（0.5B–32B）上均取得一致改进。
- **消融充分**：通过 CKA 分析、下一词预测重叠、注意力分布等机制分析证实了反转带来的互补信息。
- **性能-效率权衡良好**：相比 MetaEOL 的 8.17 倍开销，ReverseEOL 仅需 1.96 倍时间，但性能更优。

## 8. 不足与局限

- **性能差距**：与经过对比学习训练的专业嵌入模型（如 E5-Mistral、KaLM-Embedding）仍有差距，未达到 SOTA 微调方法的水平。
- **语言覆盖**：仅针对英文数据集评估，未扩展至多语言场景。
- **推理成本**：额外一次前向传播导致推理时间翻倍，在延迟敏感场景中可能受限。
- **偏差风险**：由于基于冻结 LLM，基础模型中的偏见或幻觉风险会传播至嵌入中。
- **未考虑 prompt 优化**：方法依赖于已有的一词限制提示，不同提示的性能差异较大（见表 13），未探索如何自动选择最优正向/反向提示对。
