## 摘要
精细的形态句法错误标注在临床和发展性语言研究中至关重要，然而它既劳动密集、依赖专家，又难以规模化。我们提出了TalkTag，一个基于LLM的轻量级工具，经过微调可自动对口语转录文本进行CHAT风格的错误标注。该系统在极端数据稀缺条件下利用儿童叙事数据开发，展示了低资源环境下语言分析的可行性。我们的评估表明，TalkTag能够生成令人鼓舞的精确标注，同时有效识别语言歧义使自动标注变得真正复杂的情况。总之，通过TalkTag，我们提供了一种可扩展的替代人工错误标注的方案，并为形态句法错误标注提供了实际可行的支持。

## Abstract
Fine-grained morphosyntactic error annotation is important in clinical and developmental language research, yet it is labour-intensive, expert-dependent, and difficult to scale. We present TalkTag, an LLM-based lightweight tool fine-tuned to automate CHAT-style error annotation in spoken-language transcripts. Developed under conditions of extreme data scarcity using children's narrative data, the system shows the feasibility of linguistic analysis in low-resource settings. Our evaluation demonstrates that TalkTag produces encouragingly precise annotation while effectively identifying instances where linguistic ambiguity makes automated tagging genuinely complex. In summary, with TalkTag, we provide a scalable alternative to manual error annotation and practically viable support for morphosyntactic error annotation.

## 2. 论文提出的方法论

- **核心思想**：将 CHAT 形态句法错误编码视为一种受约束的结构化生成任务，利用大语言模型（LLM）进行指令微调。模型输入原始转录语句，输出带有正确错误标签的同一行注释，保留所有原始语序、拼写、标点、不流利标记和 CHAT 符号。
- **关键技术细节**：
  - **模型基础**：使用 Meta-Llama-3.1-8B-Instruct，以 4-bit 量化（bnb-4bit）加载，通过 Unsloth 框架进行参数高效微调。
  - **微调方法**：LoRA（rank=32, α=64, dropout=0.05），冻结基础模型权重。
  - **词汇扩展**：将 tokenizer 扩展为包含 CHAT 标签的可复用组件（如括号、域指示符、子类型片段），而非完整标签字符串，鼓励模型组合生成合法标签。
  - **数据增强**：由于真实标注数据极度稀缺（4585 条语句，其中大多数为无错误语句），使用从错误条件提示中生成的合成数据扩充，手动审核后加入训练集，确保每个标签至少有约 100 个样本。

- TalkTag 在真实测试集上达到 93.6% 的精确匹配率，微平均 F1 为 80.4%（如果仅考虑有错误标签的语句，F1 为 82.7%）。在合成支持集上 F1 为 93.2%。

- 模型更适合作为预标注辅助工具，而非完全替代专家。

- **临床相关性**：模型在一致性错误、过度规则化过去式等临床重要类别上表现良好，具有实际应用价值。
