## 摘要
稀疏自编码器已成为从语言模型中提取可解释特征的有用工具。然而，标准的稀疏自编码器架构针对单个token激活进行操作，这意味着活跃特征的数量随上下文长度线性增加，使得研究长模型转录变得困难。我们引入了回合平均稀疏自编码器，通过学习重建整个回合的平均模型激活，以固定数量的特征表示单个人类或助手的回合。我们发现，当由大语言模型评估时，回合平均特征比逐token特征更完整地描述了单个回合的高层特征。我们还展示了回合平均稀疏自编码器大大简化了常见的下游用途，如归因图。总体而言，回合平均稀疏自编码器使得可解释性技术在长上下文长度下变得实用。

## Abstract
Sparse autoencoders (SAEs) have become a useful tool for extracting interpretable features in language models. However, standard SAE architectures operate on individual token activations, meaning that the number of active features scales linearly with context length, and studying long model transcripts becomes difficult. We introduce turn-averaged SAEs, which represent a single Human or Assistant turn with a fixed number of features by learning to reconstruct the average model activation across the turn. We find that turn-averaged features describe a single turn's high-level characteristics more completely than per-token features when judged by an LLM. We also demonstrate that turn-averaged SAEs greatly simplify common downstream uses of SAEs like attribution graphs. Broadly, turn-averaged SAEs make interpretability techniques practical at long context lengths.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：标准稀疏自编码器（SAE）对每个 token 的激活单独建模，导致活跃特征数量随上下文长度线性增长。这使得分析长文本或多人对话记录变得困难，且难以捕捉跨越多个 token 的高层语义特性（如主题、风格、安全性）。
- **动机**：现有的 temporal SAE 或 Matryoshka SAE 虽然引入了时序或多尺度结构，但并未从根本上解决 token 级特征在长上下文下的扩展瓶颈。研究需要一种能够在固定特征预算下表征整个语块（如对话回合）高层特征的方法。
- **整体含义**：通过将 SAE 的训练输入从单个 token 激活改为整个回合的平均激活，可以迫使特征专注于描述回合级别的宏观特征，从而显著简化下游分析（如归因图），使可解释性技术在实际长上下文场景中变得可行。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：利用平均操作作为低通滤波器，保留 token 序列中的低频成分（即跨位置一致的语义概念），滤除高频的逐 token 细节。通过训练 SAE 重构回合平均隐藏状态，使特征能够描述回合的整体属性。
- **关键技术细节**：
  - **Turn-averaged SAE**：给定一个回合 token 集合 T，计算隐藏状态的平均向量 \(\bar{x} = \frac{1}{|T|} \sum_{t \in T} x_t\)，然后使用标准 SAE 结构（BatchTopK，\(d_{\text{sae}}=32768, k=128\)）训练重构 \(\bar{x}\)。
  - **Decoupled SAE**：将逐 token 激活分解为平均值和残差，分别训练两个独立的 SAE（一个用于平均值，一个用于残差），但存在参数浪费和因果断开的问题。
  - **Nested SAE**：在单个 SAE 内划分内层（[0:h]）和外层（[h:\(d_{\text{sae}}\)]）分区，使用类似 Matryoshka 的损失函数：\(\mathcal{L} = \sum_t \|\text{dec}(\text{enc}(x_t)) - x_t\|^2 + \alpha \|\text{dec}_h(\text{enc}(\bar{x})_{[0:h]}) - \bar{x}\|^2\)，其中 \(\alpha=1.0\)，\(h=16384\)。这使得同一模型可同时学习回合级和 token 级特征。
- **归因图适配**：将每位特征在回合上的激活视为常数（turn-averaged）或加权平均（per-token），边缘权重使用一阶梯度近似计算，并正则化以消除回合长度影响。

## 6. 主要结论与发现

- **回合平均 SAE 能有效学习高层特征**：定性案例显示 turn-averaged 特征能识别“错误检测”“热情技术风格”“法规合规”等行为属性，而 per-token 特征常停留于词汇/句法模式。
- **覆盖度优于 per-token**：在配对排名（87.9% 胜率）、5-way 排名（平均排名 2.03，第一比例 44%）和嵌入相似度（0.663 vs 0.617）上均表现最佳；而 per-token max 在辨识力（10-way 匹配 95%）上占优，形成辨识力与覆盖度的权衡。
- **嵌套架构在归因图上表现最优**：尽管 per-token nMSE 略高（0.167 vs 0.162），但完整性和替换充分性得分最高，说明其联合学习的特征更适合回合级归因。
- **跨长泛化能力**：在 24K-32K token 的长文档上，turn-averaged 特征能正确识别金融、计算机图形学等主题，尽管从未在相似长度上训练。
- **归因图有效**：干预验证显示边缘权重与真实干预效果高度相关（Spearman ρ>0.8, Pearson r~0.7, 符号一致性>95%）；逐段落归因中目标段落的归因份额平均增加 0.3-1.9 个百分点，证明方法有效。

## 7. 优点

- **方法简洁高效**：仅需在输入层做平均，无需修改 SAE 架构或训练代码，计算开销低。
- **直觉清晰**：平均操作的低通滤波特性符合“概念特征应为低频”的直觉。
- **统一多尺度特征**：嵌套架构在同一模型内联合学习了回合级和 token 级特征，避免分叉训练。
- **实用性强**：大幅压缩归因图节点数量（从逐 token 变为逐回合），使长上下文分析变得可行；在安全性监控（如对抗性提示检测）方面有直接应用。
- **验证充分**：结合 LLM 判断、确定性嵌入指标、干预实验、完整性与替换度量等多种评估手段，结论较可靠。

## 8. 不足与局限

- **规模限制**：实验仅在 7B 模型和 32K 宽度 SAE 上进行，未验证在更大模型（如 70B+）或更大词典（如 1M）上的效果。

- **回合定义假设**：方法依赖于对“回合”的预分割，实际应用中可能不明确（如交替式或混合角色对话）。长文本场景需先分段。
